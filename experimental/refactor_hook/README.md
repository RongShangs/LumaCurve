# HyperLux 2.0.4 · 正式版

构建 `release-2.0.4-r1`，版本代码 `20004`。

按主屏实际控制器识别 Refactor 或传统物理映射，以当前设备的完整本地曲线作为默认基准。四个编辑点初始均为 100%；传统映射保留原节点、分类修正和曲线元数据。状态读取实际曲线，日志页区分 Root、LSPosed 注入和曲线连接；未知接口保留系统行为。

覆盖安装并重启一次。首次核对新机制时建议保持系统默认曲线与高级选项关闭，保存并应用，再逐项编辑。正式说明见 [2.0.4 更新说明](../../docs/releases/2.0.4.md)，机制研究见 [研究记录](../../docs/releases/2.0.4-test01.md)。本地模型和固件接口检查不等于所有设备的实机验证。

继续使用 Root + LSPosed 的系统曲线接入，不引入独立亮度 daemon、Java broker 或额外光感采集。包名、图标与签名保持不变，可覆盖安装；LSPosed 保持「系统框架」作用域，**更新后重启一次**。

新增五组可选设置，共 14 个数值参数，默认全关闭：

- **变化阈值**：正常变亮、变暗、微小变亮倍率，最低亮暗照度差及适用照度上限。
- **辅助光感确认**：辅助侧的变亮、变暗、微小变亮独立等待。
- **过渡动画**：自动亮度新过渡时长，亮暗分别调整，保留系统感知坐标。
- **手动模式阳光屏**：进入、退出确认时间；不是自动 HBM 冷却时间，不强制增强。
- **触摸遮挡保护**：手指移开后 0～5 秒等待；仍在遮挡区域时保留系统保护。

修正确认时间与采样窗口不匹配、暗光稳定越窗后整段加长失效等问题。核对主屏、自动/手动、屏幕、HDR、闲置与驾驶条件，不支持时保持系统。设置显示累计改写次数、历史窗口及最近实际主确认时间。

保留曲线编辑、预设、系统手动锚点记忆、显示层温控与原有响应设置。手动记忆不是本应用独立的无限长期学习，不保证所有锚点跨重启保存。

状态页曲线内分支入口的左右、下边距统一为 12dp。设置按亮度与偏好、环境变化与过渡、场景与保护、运行状态与界面排列。

亮度分支新增触摸、距离、夜间唤醒/驾驶、反射、运动、辅助重置、手动阳光屏、HBM、HDR/杜比条件。字段未取得不代表关闭。分析包增加 180 秒总体采集预算，记录缺失、超时、截断及校验结果。亮度 Settings 直接通过 SettingsProvider 读取主用户 0，避免 shell 命令事务失败，保存原始值及正常 / 未设置 / 错误状态。

研究依据、14 个参数范围、未开放机制、审查结论与逐项测试方法见源码包 **[发布前研究记录](../../docs/releases/2.0.3-test01.md)**，正式更新见 **[2.0.3 更新说明](../../docs/releases/2.0.3.md)**。本地逻辑、回调模型及两份固件静态检查不等于实机验证；新增效果、布局和资源开销仍待测试。
