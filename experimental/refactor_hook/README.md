# HyperLux 2.2.0 · 正式版

构建 `release-2.2.0`，版本代码 **22000**，APK 为 `HyperLux-2.2.0.apk`。保持原包名、图标和签名，可覆盖此前正式版与同签名测试版。适用于 HyperOS 4，需要 Root、LSPosed 的「系统框架 / Android 系统」作用域，更新后重启一次。

设置优先展示分类预设、曲线图与主要开关，详细参数默认折叠。支持系统深色模式；手动记忆可保存、按相近场景在亮屏后恢复，并按本机原生容量控制数量。新增暗光阈值和可选辅助稳定闸门：有限观察、证据不足即放行，不修改光感值或直接锁定背光。

默认曲线来自当前设备。四个基础编辑点继续保留；手动锚点与基础点不同，保存上限不增加编辑点。户外增强、温控与暗光稳定默认关闭，已有设置继续保留。手动记忆保存默认开启，支持单独关闭。

详见 [项目 README](../../README.md) 和 [2.2.0 更新说明](../../docs/releases/2.2.0.md)。本机主机逻辑、回调模型和固件静态检查不等于本版已完成长期实机验证。

完整包 `LumaCurve-2.2.0.zip` 包含 APK、源码、恢复脚本与 helper，**不是 KSU 模块**。出现异常可「停用并恢复」，或取消 LSPosed 勾选并重启。终端恢复可在解压目录运行：

```sh
su
sh ./restore_refactor_hook_android.sh
```

构建：`python tools/build_refactor_hook_test.py`；没有本地私有固件资料时加 `--skip-device-fixtures`，运行时兼容检测仍保留。JDK 17 / Android SDK 37 / Xposed API 82。源码不含固件、采集包或签名私钥；自行构建请使用自己的签名。
