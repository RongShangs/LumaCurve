# 3.0.0 正式版审阅

构建 `release-3.0.0 / 30002`，2026-10-10。用户明确要求修复温度标红与测试贡献排列后正式推送；保留原包名与原签名。以 2.4.0 r18 为代码基线，延续其恢复时序与状态写入隔离修复。

## 状态页

- 场景使用直接可点击的蓝色文字，没有独立背景。r1 的 wrap_content 三行被固定容器裁切；r2 将三行按剩余高度分配，并为所有行开启按空间适配字体与字体留边，避免最后一行被挤掉。
- 融合区域为 88 dp，普通间距 16 dp，阈值行 32 dp，保护区域 108 dp。主辅与屏幕读数为 80 dp。将保护区域节余分给三行融合内容，最小高度保持 588 dp；不随实时状态变高。
- 温控下方只留状态词。当前温控实际降低输出或温度阻止户外高亮、且温度读数有效时，数值和单位显示主题红色；“正在限亮”和“温度阻止高亮”均覆盖，单独的“高温保护”标签不凭空标红。缺失读数或过期证据取消标红。
- 修复本地化 TextView 在 setText 中将富文本转成字符串、丢失颜色的行为：已经构建的 Spanned 保留样式，普通字符串继续翻译。

## 设置与关于

- 两个高亮范围/画面限亮开关移出详细参数，紧跟户外主开关，按“提高目标—开放范围—放宽画面限亮”排列。
- 简要说明各自效果，不再标记实验选项；保留共同的温控、电量与 HBM 预算说明。开关依赖、兼容性判断、默认值及运行逻辑保持原样。
- “感谢名单”“测试贡献”“代码贡献”分别使用独立卡片。测试贡献为左对齐的一行“勿忘 灭”，用空格分隔，不再均分两列或显示简介；代码贡献说明保留。名单 JSON 不变。

## 核对范围

- 状态几何回归 5191 项通过：覆盖不同密度、字号、窗口、实际测量与摆放的一致性。
- 实际文字渲染方法回归 978 项通过：包含普通/实际限亮/仅阻止高亮/失效状态、中文/英文、温度及单位变色、状态恢复、未知温度、跳转及本地化 TextView 保留样式。
- 完整构建运行已有主机回归、固件静态核对、原签名校验及原生组件打包核对，结果随交付 build-info 记录。
- 未安装或操作连接手机；无 3.0.0 真机渲染或故障机型验证结论。K90PM/K80PM 的偶发解锁卡死根因仍未确认，版本号升级不代表已解决。
