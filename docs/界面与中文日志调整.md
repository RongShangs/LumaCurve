# 界面与中文日志调整 · 2026-09-29

版本保持 0.0.1 / 00001，仅本地开发和打包，未推送或发布 GitHub。

## 界面

- 阳光增强未触发时显示「未触发」，详细读数同步使用同一措辞。
- 屏幕背光区统一网格对齐，更新时间与标题同行；目标与进度集中展示，下方保留小号「详细读数」与状态说明。四个手机尺寸保持固定页面，无底栏遮挡。
- 关于页进入时自动检查更新，单行结果位于官网、仓库链接上方；移除手动检查按钮，发现新版本后显示下载链接。保留超时、版本格式和仓库下载地址校验；尚未发布时如实提示，安装仍由模块管理器完成。
- 原更新区域改为自愿打赏，明确模块永久免费。微信、支付宝分别打开本地收款码弹窗，支持关闭和 Escape，关闭后恢复按钮焦点。
- 两张收款码按原始字节复制，微信为带绿色对勾的图片，不重绘、不裁切。新增素材同步加入两份安装脚本的提取和权限列表。
- 移除工程和模块根目录 NOTICE.md。关于页保留上游贡献署名，新增算法说明改为现有双光感和时域策略由维护者独立开发；恢复基础代码的来源仍记录于「来源与许可证.md」，GPL-3.0 完整协议保留。

## 日志与光感静默

56 类核心日志模板改为中文，通过统一打印入口映射，保持 printf 占位符数量、类型、顺序与参数数值不变；状态文件的机器字段不翻译。服务、升级快照的自然语言日志也改为中文，事务阶段及错误标识保留用于诊断。历史日志不改写，新进程开始输出中文，复制和导出取得实际日志内容。

确认 NDK reporting mode 为 on-change 的光感，在启用且已有有效真实样本时允许事件静默沿用读数。这是此前双光感优化已有的逻辑，本次保留。普通 event_age 静默不再输出反复的过期警告；仍保留 sensor_stale 等诊断字段。未知/连续模式仍保留超时保护，没有伪造事件时间戳或样本数。未找到传感器、唤醒无有效样本、首次等待超时等异常诊断保留。
