# 高亮增强页面统一样式与固定模式范围复审

基于本地Beta13，交付目标4.5.0-beta14 /45014、beta-4.5.0-14。只修改页面、文案、版本及对应维护/验证记录；普通曲线、深浅色学习、配置协议、运行控制器、节点恢复、测试后端逐字节不变。

## 布局

使用MainActivity.card既有18/17dp内边距、12dp卡片间隔，功能标题统一18sp。顶部独立激发测试卡片，参数为两列浅底区块，开始/停止操作为下方标准全宽48dp按钮。状态/结束原因在标题旁，测试中显示真实照度与剩余时间，不再有底部常驻灰字。

预设/增强方式、高亮准入、目标曲线各用既有卡片容器。四个方式两列单选，不附加或展开说明，设置不进入选择项。准入展开编辑器保留内边距，名称与数值分栏，滑块独立，保留所有原参数与零预算隐藏行为。曲线后保留增强保护、最终上限及原条件查看入口，手动阳光屏独立逻辑不变，仅其标题同步18sp，其余场景标题样式不变。

## 曲线含义

各方式共用纵轴0至本机物理映射最大nit，蓝线始终显示相同存档目标；不会因当前原生瞬时范围、光照、HBM是否激发、HDR或快照新旧改变坐标。常规增强仅将本方式未额外开放的普通上限以上标灰；开放范围/放宽画面限亮不画该模式灰区。沿用系统可只读看同一曲线，并明确不参与调节。灰区不是当前实际准入或输出状态，不能从它推断系统当前峰值；实际输出仍服从原生准入与保护。

图高235dp与基础曲线编辑页一致，收紧轴边距并减少照度轴空尾部，保持四点拖动、单调联动、上限线、小型恢复、旧多点显式简化及取消/过期手势保护。读图或切换模式不裁写保存目标。原普通曲线蓝色基础/绿色学习语义保持不变。
