# 4.2.0 Beta06 复审与交付

用户要求简化旧映射选项和已保存提示，映射块移至主屏手动亮度上方；新增分区、一秒内独立二次上滑和返回策略，明确记忆边界。累计公开4.2.0之后Beta 01—06。仅本地，保留365份既有APK/ZIP。

## 设计与检查

实际普通边界读取集中在ControlCenterPartition，首笔/松手/二次上滑状态按控件绑定隔离；接口错误只使分区不可用，不删除完整节点和既有路线。共享原raw_panel，不复制守护程序。mode=4和返回自动选项独立保存，0/1/2/3不改变含义；旧1/2仅从当前UI隐藏。

普通区间执行原回调，超出节点区间不执行用户学习回调；完整模式同样不学习。返回自动选择只在实际退出自己持有的分区节点租约后执行；继续手动不自动开启自动亮度。已有记忆不额外删除，跟随原保持策略。

专项回归覆盖实际DDC/正常上限路线及坏ABI拒绝、一秒截止、同一笔不授权、返回与重试、两种返回状态、低段原回调/高段不调用、旧设置、Root绑定、上下边距和旧UI去除。完整主线编译与检查后再核对签名、APK/源ZIP/恢复包、原生资产和全部旧交付哈希，回执build/beta-4.2.0-beta06/final-audit.json。

没有真机、视觉渲染或功耗结果，不对不满足实际边界与SystemUI接口的设备声明支持。没有发布或安装授权。
