# 快速设置复审

用户要求设置页增加问答式快速设置和首次邀请。仅修改源码并验证，不重打已交付 Beta 04，不发布、不部署、不安装。需求、预设数值及所有权范围见 [快速设置说明](../guides/quick-setup.md)。

采用独立界面和纯预设组合器，生产源码已登记 source-map；没有新增兼容探测或删除路线。读本机现有能力报告，不按型号或系统版本决定功能。问题依次覆盖响应、基础曲线、保持、暗光、户外和温控，每题含保留当前项；选项换页不会提交，最终先刷新实际设备状态，再组合并按原配置协议处理；取消刷新中的操作、基准变化或能力消失均不提交。

邀请独立记录且非强制，等待欢迎教程和其他对话框结束，仅在设置首页且曲线就绪时显示；取消后仍可从入口进入。问答界面暂停原界面刷新，返回恢复；步骤和答案随实例状态保存。退出不丢原有草稿；基准变化不恢复旧选择。汇总明确已有草稿一起应用、户外预设关闭原强制节点增强但保留数值上限；全部保留时不发起保存。实际保存成功 / 失败沿用原异步回执，不能把生成草稿当成设备应用成功。

专项主机回归包含8000种完整组合，逐一使用生产配置与曲线校验；专项共40126项主机断言，96条新文案英语检查；另核对能力暂缺、能力在确认前变化、独立设置保留、关闭学习后选择保持、默认与最大温控保护、单选与退回、取消、一次邀请、组件重建、基准变化和最终提交次数。完整结果记录在私有 `build/quick-setup-tests/verification.log`；静态 / 主机替身不能替代 Android 布局、辅助功能或真实亮度体验验证。

生产逻辑不新增线程、Hook、进程、传感器监听、网络请求或周期任务。完整回归通过后核对已有274份 APK / ZIP 字节未变化。真实手机界面与功耗未测。
