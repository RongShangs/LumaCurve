# 4.1.1 正式发布复审

相较已公开4.1.0-r1，合并4.1.0 Beta 01—02并将设置首页未保存提示改为整行居中。用户明确授权正式发布并要求简要更新保留4.1.0五条后追加两项。

## 实现与兼容

- UI只修改unsavedHint重力为CENTER，保留全宽布局、可见性和草稿保存逻辑；二级页布局及已存设置不变。
- 分段系数路线、读写消费者、数组与标量回滚和原生手动学习边界沿用Beta 01；记录见review-4.1.0-beta01.md。拒绝将未经核实的用户虚拟拟合点导出/回写，单独暂停高级保持和记忆转基础，不删除用户偏好。
- OPR实际包络只约束本模块额外放宽，旧无表路线、新完整表及残缺拒绝分开；记录见review-4.1.0-beta02.md。按实际接口与表而非型号/系统版本判断，保留HDR、隐私、温控、电量、HBM与手动接管保护。
- APP nit为设备换算值，不能宣称光学实测。此前状态记录的10000端点与原生OPR4500最高档确实存在差异，但红色偏色硬件机制及新版改善仍待目标设备反馈。简要日志按用户指定，详细日志明确验证边界。

## 发布门槛

完整回归覆盖旧/新/负向路径，重新编译正式41100并使用原签名。核验源码、APK、完整包和版本一致；所有既有交付物哈希不变。源码包排除私有诊断、固件、签名、认证、未发布工作流及独立研究。

随后同步GitHub v4.1.1、LSPosed 41100-4.1.1和官网，核验正式非预发布状态、实际下载字节、JSON/JS、首页摘要、当前名单与证书。三渠道全部完成核验后方可在对话中报告发布完成，私有审计与回执保存在build/release-4.1.1-publish/。
