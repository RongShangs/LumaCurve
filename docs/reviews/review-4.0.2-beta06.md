## 调整与边界

原选项在一个RadioButton中混排标题、缩小字号说明及多行文本，难以独立控制间距和对齐。现在每张选项卡使用独立标题和说明TextView，两者均WRAP_CONTENT，无固定行数裁剪；卡片仅有最小高度，全文较长时自然增高。左右标记与占位宽度相同，文字在整卡宽度内居中；整卡负责点击、焦点和单选无障碍状态，原生单选标记只展示状态，避免双重焦点或父子点击竞争。

题目按语义换行，问题、注释、选项、汇总说明、底部灰字居中。导航标题左右使用相同宽度的控件 / 占位，保证真正居中。较宽高的内容区通过fillViewport与垂直重心协调留白，内容超出时自然滚动；按钮与灰字位于内容滚动区外。导航按钮使用最小高度与自适应文字高度，横向行统一高度，避免大字体时固定50dp裁剪或两按钮高低错位。

邀请使用26sp居中标题、44sp数字与21sp主说明，分层展示六题主题和“保留设置 / 最终确认”的说明。仅新增可传入标题View及最大宽度的通用dialog重载，现有String标题入口继续采用原20sp / 440dp参数，横屏仍至少520dp；各自实际宽度仍受窗口和安全边距约束。邀请最大宽度480dp，不设置整窗固定高度；沿原ResponsiveDialog的WindowMetrics、系统栏 / 刘海 / 输入法Insets计算最大高度，仅正文可滚动，标题和动作保留。邀请按钮单独提升为15sp、最小52dp并自适应等高，不改变其他弹窗按钮。

所有功能、预设、能力判定、邀请确认记录、答题恢复、取消与提交事务均保持Beta 05行为。没有重置首次邀请标记来强制已有用户再看，没有新监听、任务或进程。
