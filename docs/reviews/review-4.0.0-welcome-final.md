# 4.0.0 欢迎、教程与官网本地交付复审

当前有效授权为仅在本地打包，待用户安装确认后再决定发布；不推送、不部署、不安装手机。保持 4.0.0 / 40000 / release-4.0.0、原包名与签名。本次界面修订不修改亮度引擎、传感器、兼容选择与用户配置。

## 修改与边界

- 欢迎 Logo 居中，88 dp，圆角 26 dp，简短介绍居中；底部只有“下一步”。首次五页依次浏览，第 5 页完成后才记录欢迎完成；返回或退出不提前确认。已有完成记录不失效。
- 重看也从欢迎页开始；上一步可回到欢迎，系统返回可退出重看并恢复原设置视图、草稿与滚动。首次返回欢迎后继续返回则退出 APP，仍不确认。
- 原生 ObjectAnimator 使用 3.6 秒 / 4 dp 非线性轻浮动，仅欢迎页前台可见时运行；退后台、切页和销毁均取消并复位。恢复前台只重建一个动画；关闭系统动画时保持静止。页面切换继续使用原有方向淡入动画，不依赖完成回调导航。
- 第 5 页改为“遇到 BUG 或不兼容的情况”，提供导出分析包与后续反馈的文字说明，删除 Issues 外跳按钮。群号仍只维护于关于页。
- 官网文案精简约六成，靠前说明兼容范围持续扩展、已有移植包适配案例及按实际接口独立判断；保留功能、安装要求、反馈、下载、许可与感谢名单。预览明确待发布，不改线上网站。
