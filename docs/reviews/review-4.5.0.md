# HyperLux 4.5.0 正式发布核对

用户于2026-11-10明确授权发布4.5.0 /45000，同步官网、GitHub与LSPosed，并在完成后制作海报。上一公开正式版为4.4.5；其后的本地Beta没有创建公开Release。本版用户日志只采用用户提供的五条最终变化，不重述未公开Beta的中间实现与修订过程。

## 最终发布内容

- 生产基于已完整构建的Beta15，保留应用独立/分组亮度、旧暂停名单接续、名单选择、折叠节点映射、开机恢复和手动记忆界面。与Beta15相比，本轮生产Java仅修改版本标识及测试贡献名单，不再改动亮度逻辑。
- 版本为4.5.0 /45000、release-4.5.0，BETA/TEST/INTERNAL均关闭；保留原包名、legacy API82及原签名，原生raw12载荷不变。已有设置、旧适配路线和全部版本化历史交付保留。
- 合并官网、服务器、本机部署副本与仓库感谢名单，追加曼森原文；测试贡献追加曼森、𝓙𝓪𝓼𝓶𝓲𝓷𝓮、九辰、梅菜Crow、fresh，保留原有十位及代码贡献Github@fresh。感谢名单不写入更新日志。
- 公开源码只包含构建选入的生产、测试与文档，以及网站发布信息；独立API102/official_curve/uevent研究、原始诊断、凭据与签名材料不进入提交或产物。

完整主机回归继续覆盖控制器660项、名单页231项、独立接口117项、分组18项、节点映射启动195项及Root恢复30项，并执行已有兼容路线和私有固件静态检查。上述均不等于本次新增真机、重启、长测或功耗结果。

发布前核对188份编译Java指纹、正式版本/原签名、APK及对应源码/完整包、感谢JSON和测试贡献的实际入包。官网、GitHub与LSPosed使用同一套产物；只有逐渠道实际下载字节一致、官网JSON/JS/首页与LSPosed说明同步后才报告完成。未安装、重启或调整用户手机。

本轮私有检查、提交清单、渠道回执、哈希和下载结果保存在build/release-4.5.0-publish。通用恢复工具的新构建可更新同名本地入口，旧工具已单独备份，历史版本化APK/ZIP及其中的恢复工具保持原字节。
