# 4.3.3 Beta 05 复审

本轮新增独立默认关闭的应用亮度隔离，169份Java；累计公开4.3.3之后Beta01—05，本地43305。入口位于暂停自动亮度名单上方，原设置组索引保留，新组11；不改变暂停名单含义或增加作用域要求。

所有权归AppBrightnessIsolation适配器，UI只消费报告。完整新ABI匹配同步、消费、窗口接受、原因标签和主屏对象，采用5个Hook；三个同步入口同时缺失且原生窗口接口完整才是0 Hook原生路线。类型错误、部分新ABI或安装中途失败拒绝本项，并原子回滚。按真实Class/加载器缓存，不用系统版本或型号选择。

隔离仅作用于原生limitQRCodeBrightnessMax调用内，由实际窗口消费者已接受的来源标签、OVERRIDE原因、同屏用户和完全一致参数共同确认的requestBrightnessSync/updateOverrideDragMode(true)。返回值及下游限制继续原生；独立直接调用、错误原因/标签/参数、调用栈外都不拦截。不替换曲线计算，不读旧亮度强写恢复，不全局忽略设置、学习或动画。

有效控制中心临时亮度请求为用户操作证据，在该窗口会话内持续优先；NaN释放不取消优先，窗口释放/换来源重新确认。只对当前活动用户、亮屏BRIGHT、无其他控制者且非HDR生效；DIM、息屏、暗光、节点、暂停名单等均退让。窗口相同数值更新返回false时不作为新的已接受证据，来源不一致将退回系统，宁可暂不隔离也不误拦截。

新键app_brightness_isolation默认false，通过旧配置解析/原格式保存/JSON导入导出；sameOwnership不因本开关变化结束现有控制者。能力缺失只裁剪运行副本，磁盘保存值保留。默认关闭不会擅自解除其他功能。

实际生产适配器77项回归：原生路线0 Hook、部分新ABI/返回/字段类型拒绝、5步安装逐步失败回滚、来源、极低/零值、用户手动优先、NaN释放、HDR/DIM/off/用户/主副屏/其他控制者、嵌套及异常清理。独立自检398项、路线展示1602项、导航139项和旧配置2889项同时通过。另22项私有固件核验确认两个真实同步调用均位于窗口覆盖范围、getTag/request字段、原生消费者和旧结构无该同步链路。私有输入与反汇编不进入公开产物。

完整构建、签名/源包/旧包保护核验见build/beta-4.3.3-beta05/build.log、verification.json和local-audit.json。保留423份已有APK/ZIP、原签名与raw10。没有真机亮度、屏幕像素或功耗测试；不发布、安装或重启设备，官网仍43300。
