## 相较公开 4.0.0 的范围

对外日志按用户要求保留两项：暗光锁定默认关闭且已有设置不受影响；新增小米 18 Fold 折叠屏适配。实际实现包括：

- 保留标准 TYPE_LIGHT 路线；新增系统已选中的私有折叠主光感，以及实际 OEM FOV 选择器输入。按真实对象、签名、语义和单位选择，不按型号或 OS 版本放行。FOV 已换算照度与驾驶替代数据包分开处理，保留原辅助与移植空槽路线。
- 显示控制器、SensorManager、主辅句柄、配置槽、可读物理屏或面板配置变化时，释放旧监听、采样和锁定确认计时；监听代际拒绝旧队列数据。不新增其他逻辑屏控制权，系统默认屏内外映射跟随其真实对象。
- 状态读取改为只读，运行、自检共用 BrightnessSensorAccess，兼容页展示实际路线、配置源与选用源。兼容目录、manifest、源码职责和生成索引均更新，旧 baseline 不变。
- 新配置暗光锁定关闭，暗光小变化阈值构造值与缺省解析统一关闭。手动选择“睡前保持”仍明确开启；已保存的 true / false、阈值、记忆保持、曲线及名单均保留。手动记忆 100% 是原生输入直通，手动面板入口不会自动接管。

详细设计见 [折叠输入复审](review-4.0.0-beta01.md)、[默认行为排查](default-behavior-audit-20261019.md) 和 [默认矩阵](../guides/default-behavior.md)。此前 Beta 02 仅为拟定源码标识，未独立交付；相关修改全部合入本版。
