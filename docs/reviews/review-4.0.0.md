- WelcomeGuide 在原 Activity 内容之上显示独立欢迎 / 教程页面，不重建原设置页、滚动位置或未保存草稿。首次可跳过教程开始使用；重看直接进入教程，返回恢复原界面。
- TutorialContent 只提供本地文案；四页分别解释启用、基础与记忆、暗光与户外、状态与兼容。按钮固定在内容下方，长内容滚动；48 dp 操作高度与左右按钮对齐保留，中英文均覆盖。
- 首次介绍优先于 Root 请求、兼容提示和更新弹窗；介绍期间不启动 APP 状态轮询。关闭后按原流程核验接口，重看不清空自检时间。

- 旋转恢复页码、首次 / 重看语义和滚动；返回、后台、销毁、重复点击不会自动确认。陈旧的异步滚动恢复不影响新页面。旧包名、签名、配置 schema、存储名及所有亮度参数保持。
