# 状态页单次更新提醒与按钮布局复审

日期：2026-10-25。用户明确要求每次进入APP，仅在状态页自动提醒一次；之后页面切换不重复。未忽略的版本下次进入仍提醒，关于页保留更新提示，不再因进入该页自动弹窗。另要求重新检查底部按钮是否完整。

## 实现

- MainActivity保留已有发布源、版本比较、可信下载地址、忽略版本键及手动检查入口。状态页和关于页每次前台访问共用一次自动检查结果，关于页只更新文字和暂存结果；只有状态页允许自动弹出。
- updateOffered只在弹窗实际显示后置位，欢迎、快速设置、权限、旧模块提示、后台或其他页的延后不提前消耗机会。手动点击关于页检查仍可明确查看更新，包括主动查看已忽略版本。
- 页面导航和普通暂停不清除此状态；APP真正停止显示且非配置重建时才结束当前访问、关闭旧更新框并清理暂存。配置重建通过non-configuration实例仅保留已提醒标志，不写用户设置，不把进程死亡后的恢复当作旧访问。
- 忽略版本继续写入原偏好键；稍后不保存忽略。保存的曲线、保持范围、名单、欢迎及其他配置均不改变。没有后台周期更新检查或新增服务。
- 原弹窗布局已独立先测标题和两排按钮，仅日志使用滚动区，普通高度按安全范围82%限制，大字/短窗口必要时扩展至实际安全范围。此次确认按钮自身仍固定48dp，窄窗口大字可截断文字，因此只将更新框4个按钮改为WRAP_CONTENT，保留最小48dp、允许多行、取消省略并增加上下内边距。按钮内容增高后继续由现有外框优先预留高度。
