# HyperLux 3.1.1 发布复审

2026-10-16，以已发布 3.1.0 与本地 3.1.0 Beta 01 为基线。

## 范围

复核两种曲线后端、手动记忆及恢复、配置迁移与独立功能检查、场景与输出保护、户外及节点授权、应用/暗光/手动面板所有权交接、Root/原生程序、状态传输、界面导航、更新来源与分发。完整回归覆盖各现有测试，不通过机型或系统版本号替代实际能力检查。

## 本轮发现与修复

1. Beta 的主动自动亮度豁免仅保存一个包名。A、B 均可见时主动开启自动亮度，随后隐藏 A，会重新关闭自动亮度。改为保存当时可见的全部名单应用，逐个退出豁免；只要其中一个仍可见，就尊重用户选择。
2. 初次窗口查询尚未返回时，手动开启自动亮度没有已知包名可豁免；查询返回可能再次关闭自动亮度。新增待确认的主动选择，用本次新鲜结果完成豁免；清空名单或停用时清理。
3. 注册监听的全局锁内曾读取引擎资格和电源状态。改为锁外检查，只在锁内修改监听集合，避免阻塞 WM 回调；副屏控制器不订阅主屏任务。
4. 成功重新读取后清除过期的前台读取错误。异步查询期限和代际隔离继续执行，失败不把未知状态当成可见匹配；超时或停用后的旧结果不取消新请求的期限。

冻结 Beta 控制器执行新增回归，确认 case 343 失败；当前修复通过 357 项控制回归。锁内服务读取有主动断言，多窗口、初始异步读取、队列拒绝与晚到结果均有执行测试。

## 验证与边界

完整构建检查的所有结果以本版 build-info.json 为准。可见任务接口在两份用户框架及 TaskInfo 字段完成 29 项静态核对；固件、反汇编、设备日志、认证与签名私钥不纳入交付。

保留原包名和证书，正式 3.1.1 / 31100，能覆盖正式 3.1.0 / 31000 及 Beta / 31001。发布前核对源码归档、编译源摘要、原生组件、版本身份、三平台下载与校验和。

没有连接的 ADB 设备，本版未完成 Android 小窗/分屏、长时间解锁、驱动亮度或功耗实测。未改系统传感器采样率；新增任务查询按焦点/显隐事件执行，没有轮询、常驻应用服务或新进程。节点增强原有可选 Root 守护不属于应用名单新增开销。

更新仍使用 GitHub 最新正式 APK Release，按语义版本判断；3.1.0 可检测到 3.1.1。GitHub 网络不可达、限流及同版本重新打包不提示的既有限制未在本轮改动。
