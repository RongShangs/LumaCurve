# 应用选择页内容过渡复审

目标：本地4.4.5-beta15 /44515，构建beta-4.4.5-15。仅调整应用选择页过渡及其生命周期，亮度运行代码保持Beta14；不发布、安装或操作设备，保留全部历史交付与保存设置。

## 回访与判断

用户反馈进入应用选择页会闪黑，边缘还有黑边，与其他二级页不协调。源码确认Beta13的匹配仅复制了12dp和180/120毫秒数值：MainActivity对固定窗口内部的页面做动画，选择页却通过Activity过渡对两个整窗表面同时淡变、位移。后者会暴露任务背景，并进入ROM的窗口阴影和边角合成路径，与回访现象相符；本地没有Android画面录制，不能声称已在目标ROM逐帧复现或确定全部系统合成因素。

## 改动

- 选择页沿用不透明AppTheme，并显式将窗口背景设置为页面实际主题色；窗口保持静止和不透明，系统整窗进入/退出动画均设为0。Android[Activity过渡接口](https://developer.android.com/reference/android/app/Activity#overrideActivityTransition(int,int,int,int))支持为打开和关闭分别设置动画及底色。
- 只对窗口内部根内容执行180毫秒淡入/12dp归位，返回时120毫秒淡出/12dp离开，沿用其他页面的减速插值。系统关闭动画时直接呈现或完成返回，不动画整个窗口和任务背景。
- 每次过渡推进代次，取消旧动画、清除结束动作并归一透明度/位移。快速返回只提交一次选择草稿；进入中切后台取消动画，退出中切后台直接完成返回。旧结束动作即使延迟到达也不再次完成。根据[ViewPropertyAnimator约定](https://developer.android.com/reference/android/view/ViewPropertyAnimator#withEndAction(java.lang.Runnable))，被取消的结束动作不会执行，因此后台打断需要显式完成已提交的返回。
- 搜索、批选、迁移确认、分组和草稿保存规则不变。独立亮度、曲线学习保护、原生载荷及节点映射恢复代码不改。
