# 高亮增强状态容器与排版复审

基于Beta17，本地Beta18只变更OutdoorSettings、MainActivity显示调用、翻译和版本。增强状态在原主页卡片内有独立浅色容器：状态说明上置，下方三行两列的方式、实际亮度、最高亮度限制、系统门槛、增强/冷却余量及HBM预算估值。详情入口为浅蓝底蓝字，最高亮度限制入口删除灰色说明，点击范围规则保留。

新增只读展示从已有outdoor快照和顶层可靠读数取值，不读取草稿作为运行状态、不增加Hook/采样/轮询。时间戳、15秒新鲜度、引擎活动、数值类型和直接节点读数边界在展示端验证。HBM估值保持快照含义，不擅自消耗预算；缺字段保留未知。Controller、Options、物理曲线、学习、Root恢复和测试协议保持原字节。
