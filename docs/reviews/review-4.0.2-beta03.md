# 4.0.2 Beta 03 本地交付复审

2026-10-21。用户要求合入 MIX Fold 3 兼容修复、调整更新弹窗及暗光设置顺序，诊断资料改按机型归档，然后打包 Beta 03。仅本地交付，不发布、不部署、不安装手机。

## 功能与界面

MIX Fold 3 的接口证据、互斥选择、拒绝条件、单位、所有权和测试边界详见 [专项复审](review-mix-fold3-20261021.md)。保留此前 Beta 01 / 02 的折叠默认屏、StablePhysical 和切屏清理；在统一适配器新增非内核编号的原生显示端口分支与传统三参过渡入口，不以机型或 OS 版本放行，不修改用户配置键。

更新弹窗移除按字符数估算的 70—200dp 嵌套日志滚动区。更新日志直接进入 ResponsiveDialog 的单一滚动容器，字号 14sp、增加行距，320dp 期望阅读高度会受外层实际可用空间约束。下载行和稍后 / 忽略行移至同一个固定页脚，各行两按钮等宽；外层测量先预留标题、页脚、卡片内边距，再计算日志最大高度。当前窗口 WindowMetrics、系统栏、刘海与输入法 Insets 及 24dp 外留白继续参与上限计算，折叠或横竖屏变化沿用重新测量。未设置整窗固定像素高度，没有新网络请求或常驻任务。

更新仍只在关于页弹出；忽略版本、主动检查、下载地址与离页取消行为不变。“暗光稳定与锁定”只交换两个卡片的构建顺序，原开关、默认值、详细设置状态和已保存参数均不变。

## 私有资料整理

分析包目录改为 `diagnostics/packages/机型/原文件名.zip`，展开资料为 `diagnostics/unpacked/机型/分析目录`。版本、系统、采集时间仍保留为索引字段；移植系统不直接使用供体 ROM 型号冒充真实硬件，未知实际机型明确标注。

核对迁移时另发现此前索引遗漏的一个分析包及一个同内容备份：共 36 份原始 ZIP，35 份不同内容，10 个设备分组和 12 处展开资料。全部保留；原始包逐个核对 SHA-256 / ZIP CRC，展开内容逐文件核对；旧工作路径使用目录连接指向新位置，完整固件测试继续读取。迁移前索引备份及操作回执只留私有目录，不进入源码包。它是本地开发资料整理，不是 APP 新增功能，也不上传任何诊断输入。
