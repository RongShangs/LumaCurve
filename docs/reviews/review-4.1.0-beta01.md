# HyperLux 4.1.0 Beta 01 适配复审

日期：2026-10-22。依据用户确认的实际硬件“努比亚 Z80 Ultra”及本次私有分析包；系统上报的供体型号、指纹仅作为复现信息，不进入兼容选择条件。公开基线为4.1.0 / 41000 的r1修订。

## 根因与处理

系统已注入，但当前Refactor对象不存在锚点式 `mLuxSeg0` / `defaultAtLux`。该类使用9项系数、22项拟合状态及9项拟合数据，原钩子事务与运行后端分别因此失败。新增 `RefactorProfiles` 统一互斥选择及默认曲线方法签名，新增 `RefactorCoefficientsAdapter` 承担全部新结构反射、坐标、事务与清理；UI及Root不复制一套字段探测。

保留原 `RefactorAdapter` 与两类 `TraditionalAdapter`；任一旧式标记存在时不允许借备用路线绕过残缺旧结构。通用后端增加曲线生命周期接口，原实现行为不变；Refactor默认曲线钩子按真实返回类型区分float / double，保留原来主屏、线程、用户与普通输出门槛。

## 写入与控制权

- 原生消费者只读验证通过后才写系数；不替换物理输出、不绕过原生高光缩放或下游温控 / 电量 / HDR。
- 用真实系数和本机逻辑上限反解末端照度。拒绝未知形状、静态成员、别名容器、非有限值、不连续基准及零斜率基础编辑。
- 配置更新快照同时保存原生数组引用与内容，失败时恢复已替换的数组身份及标量。仅接管匹配基准，其他所有者改变基准时停止覆盖。原生学习形成的新系数不被“修复”回基础曲线。
- 新路线可验证最近一次手动输入，但未确认虚拟拟合点的完整导出 / 回放语义。独立关闭跨模式、锁屏、重启、永久保持及记忆转基础能力，保持所有原始偏好。原有路线继续提供原本能力。
- 不新增采样服务、轮询、后台进程或写节点守护；沿用既有钩子及显示线程。

## 验证边界

执行新系数消费者、原生重置、异常回滚、实例 / 类加载器隔离，以及原锚点与传统映射回归；同时检查配置迁移、独立自检、兼容路线标注及完整构建。精确计数与产物审计保存在私有 `build/beta-4.1.0-beta01/`；提供的固件与分析包不进入源码包。

固件静态证据确认了默认系数消费者、原生拟合方法、Handler异步手动更新、逻辑到物理输出转换及下游保护的存在，不代表Android / ART实际执行或目标用户机型测试已通过。本地交付后仍须核对新版运行报告，不能将Beta标为线上正式版。
