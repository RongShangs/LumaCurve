# 3.0.1 Beta 02：曲线固化与亮度所有权审阅

## 绿色曲线转基础曲线

SavedCurve 保存实际 current_anchors_lux / current_anchors_nit，不将绿色曲线拟合成四个点。Refactor 保留最多七个原生节点；传统映射保存完整绘图采样并继续交由系统样条处理。所有输入严格验证有限、非负、单调、端点和设备边界，并受 512 个保存点及配置 UTF-8 28000 字节上限约束；超出安全范围时明确拒绝，不截断或偷偷近似。

保存通过已有短命 Root 控制通道取得新鲜快照并提交；要求引擎启用、当前有手动点、普通曲线路径和已保存配置。操作前确认，保存失败回滚，保存成功后清除被吸收的当前/存档记忆，避免再次叠加。普通后续设置不重新固化或重置曲线。

保存的基础与系统原始参考分别展示。新增 applied_base_lux / applied_base_nit 状态分片；原有四个 active_logical_nit 编辑坐标保留兼容。配置和自定义曲线预设携带保存的基础，跨设备/基准导入保留本机基础；内置预设从设备原始基础出发。

Refactor 重置只恢复已验证原生数组/计数和纯浮点默认值，不在 OEM reset/getter 回调中做 provider/binder I/O。恢复幂等，配置失败时完整回滚；高照度端和原生数组容量约束仍有效。传统映射保留配置元数据与应用修正、短期模型超时等，系统/云端替换不被覆盖。

## 暗光锁定手动调整

dark_lock_manual_hold 默认为 false，原行为不变。开启时仅接纳当前系统手动亮度，不额外写亮度；150 毫秒合并调整，继续持有 dark 所有权与原光感监听，重新确认持续变亮后恢复自动。所有退出路径取消待执行手动任务；用户开启自动后不会被迟到的回调接管。无效读数交回系统。

## 应用名单与功耗边界

manual_brightness_apps 为去重精确包名集合，默认空，最多 64 项。通过已验证 ActivityTaskManagerService.setLastResumedActivityUncheckLocked 事件读取实际主屏/用户/包名；仅提取身份并排队，WM 锁内不访问 Settings、显示服务或查询任务。事件在现有显示 Handler 上合并 150 毫秒，避免转场中反复切换。

启用或息屏后重新订阅时查询一次 getFocusedRootTaskInfo；普通亮度/显示变化不会重复查询。空名单没有消费者；息屏、停用和销毁移除消费者与待执行任务。未新增进程、Android Service、无障碍服务、唤醒锁或周期性前台扫描。事件处理仍有必要的少量开销，不能据此声称零耗电或给出未测量的电量百分比。

只有原本开启自动亮度时才取得 app 所有权，退出只恢复自己暂停的模式；其他用户/显示器/未知前台退出所有权。用户主动打开自动时暂时豁免当前应用，豁免跨息屏保留，离开应用后清除。暗光锁定可交接给应用；手动面板/raw_panel 优先，显式恢复自动同时豁免当前应用。进程重启和断连接恢复识别 app 标记，不把它当作用户主动关闭。

能力识别失败时名单不可应用，其他功能仍可运行。应用选择只查询声明可见的启动器应用，其他应用可按包名添加，不申请 QUERY_ALL_PACKAGES。

## 验证与限制

主机模型覆盖原控制器实际回调、禁止 WM 回调读取慢服务、重复显示变化不查询、连续名单应用切换不重复写亮度、用户手动优先和跨功能所有权。保存曲线测试覆盖七点与密集曲线、原生重置幂等、失败回滚、配置/预设、蓝绿状态与传统配置元数据。已有 Beta 01 的互斥路径回归继续执行。

两份用户系统框架的前台回调 ABI 静态核对，原始固件/反汇编/取证仅保存在忽略 build。主机模型和静态检查不代替 Android/ART 真机运行；本轮 ADB 无设备，没有测量电池或安装/重启手机。当前只交付本地 Beta 02，正式线上文件不变。
