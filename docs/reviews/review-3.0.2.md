## 2026-10-15 复审补充

检查范围：前台应用监听及亮度所有权、暗光手动响应、Refactor/传统曲线保存和恢复、配置校验与导入、户外保护及钩子隔离、异步状态写入、UI/Root 进程生命周期、更新检查与分发身份。

### 已修复

- 前台查询竞态：启用名单的首次查询返回前，WM 可能已报告另一个应用。原查询会覆盖新事件，可能错误暂停或恢复自动亮度。新增真实控制器回归在查询中插入 WM 事件，原代码在第286项断言失败。通过递增事件代数拒绝过期查询结果与错误；同一身份的新事件、取消订阅也使旧查询失效。服务调用保持在锁外，WM 回调仍只读身份和排队。
- 息屏订阅：configure 在 screenOff 后无条件 attach，导致息屏保存名单时仍执行首次查询。上述修复后，新增回归在第290项断言复现。attach 现在校验引擎、名单与亮屏条件，息屏不订阅；亮屏恢复一次查询。没有新增定时器、进程或采样频率变化。
- 定向回归298项通过，覆盖新事件优先、同身份事件、查询失败、查询期间息屏取消、息屏保存和引擎关闭。完整回归结果见交付包 build-info.json。

### 保留的限制

- 更新检查仍仅请求 GitHub API，无官网备用查询；网络异常时可能显示暂时无法检查更新。同一语义版本的更高版本代码仍不作为更新提示依据。本次未扩展更新需求。
- 传统/新曲线与户外兼容经过模型回归和已有固件静态核对，不能据此宣称覆盖全部机型。本轮 ADB 未连接设备，无新增真机或实际功耗结果。

修复后的版本代码30009；先前本地30008交付文件备份在忽略目录 build/pre-3.0.2-review-30008，重新构建当前正式包，不推送或部署。
