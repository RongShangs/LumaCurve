日期：2026-10-22。基线：公开 4.0.2 / 40200；合入本地 Beta 01—08 的最终实现。用户明确授权正式打包并同步 GitHub、LSPosed 与官网。

## 范围与不变量

- 正式身份 4.1.0 / 41000 / release-4.1.0，原包名、原签名；legacy API 82，不合入 API 102 或官方曲线采集研究。
- 全部已有适配路径和用户设置保留；实际接口与屏幕身份决定能力，不按型号或系统版本放行。
- 快速设置只组合本机支持的已有预设，选择可撤销、确认前无写入；未选择分类、独立 nit / 节点目标及其他配置保留。保存前复核设备与基准，无选择时不提交。
- 折叠手动面板与户外增强各自独立绑定，保留普通节点和旧租约；切屏、双屏同亮、熄屏、身份不一致或保护条件下退出或等待，不能跨屏复用目标。
- 原生输出策略优先；只有确实缺失时才允许独立自动对象 / 原因路线，拒绝异常接口、非自动输出和不明确证据。
- 保留温控、电量、HBM、HDR、用户手动和系统接管保护；未新增快速设置后台进程、监听或轮询。

## 验证与产物

执行 tools/build_refactor_hook_test.py 的完整回归、兼容登记检查、主机状态组合及已有私有固件静态核验，再核对 APK 身份、原签名、源码对应、归档 CRC 与全部历史产物哈希。精确结果及摘要保存于私有 build/release-4.1.0-publish/，不把用户分析包、固件、签名材料或服务器认证带入源码及发布附件。

公开更新说明顶部仅写用户可理解的功能、设备适配和体验变化，下方详细说明兼容策略。正式推送同时核对官网首页、下载、SHA-256、update.json / update.js 与 GitHub、LSPosed 实际下载一致。

本轮不主动操作手机；主机与固件静态检查不代表目标折叠机型实际增强、连续切屏、长期稳定性或功耗已通过。沿用 Beta 审阅记录中的这一验证边界。
