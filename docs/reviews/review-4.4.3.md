# HyperLux 4.4.3发布复审

本轮将4.4.2之后Beta01—05合入4.4.3 /44300。具体实现与验证边界见[兼容复审](review-compatibility-20261103.md)及[重建曲线适配](review-4.4.2-beta05.md)；长期需求和选路统一见[功能文档](../features/README.md)，本记录不再复制规则。

## 发布核验

- 正式身份、原签名、raw10及旧交付文件核对。
- Beta05至正式版除身份外的生产Java保持；原配置/记忆实现与已有路线保持。
- 构建元数据从实际清单统计137个受保护功能/路线组合和82个登记测试入口，不再手写旧计数。
- 执行完整主线构建、既有固件与新增分支回归，记录实际源码、需求、清单与产物哈希。
- 源码包及公开提交排除私有分析包、固件、签名、认证和未授权独立研究；保留许可证与贡献来源。
- 官网、GitHub和LSPosed使用同一组最终APK/源码/完整包及累计日志，下载逐字节验证后报告完成。

用户授权公开发布，不等于所有新路线已经真机确认。本轮没有新增Android安装、物理测光、长测或功耗结论。最终完成状态与渠道证据仅保存在私有build/release-4.4.3-publish回执。
