# 高亮增强二级页、固定测试网格与点击容器复审

基于本地Beta14，目标4.5.0-beta15 /45015、beta-4.5.0-15。新增OutdoorDetailsPage，生产195份Java；改动限定页面、搜索、文案与版本。OutdoorOprCurveSettings及所有曲线/学习、控制器、节点恢复、原生读取和测试后端保持原字节。

## 导航与设置

主页只有激发测试、预设、四排增强方式、灰色详细入口。曲线、准入、时长/冷却、最终上限、增强状态和原手动阳光屏控件移入真实二级页，仍是MainActivity内同一实例和同一草稿。导航不提交；二级页顶栏沿用原返回、18sp标题、保存及未保存提示。使用同一transitionPage、背景与导航安全间距，没有新窗口或Activity。返回保留编辑和位置；旋转后在预绘制时恢复滚动，导航代次/销毁取消过期回调。保存入口使用与其他页相同的连接/忙碌门槛。

搜索区分主页面测试/模式与二级页曲线/准入/上限/手动阳光屏，按实际所属滚动容器定位。原截图蓝字为增强运行状态；旧查看准入与保护条件按钮实际打开全局亮度分支，名称/位置不适合精简主页。该入口移除，运行状态在二级页有标题的卡片内显示；全局日志诊断保留。

## 固定参数与点击

测试始终两行四格：模拟照度、剩余时长、当前亮度、本次/上次最高。真实照度只保留在原后端协议和诊断，不在此处展示；未开始20秒、测试中按快照余量扣除年龄、结束0秒，不增加参数格。可靠读数来源和过期处理不变。进入二级页按既有离开测试页面规则停止所属测试，20秒保护及结果采集不变。

四个增强方式、普通设置行、含说明的最终上限整块区域与详细入口，外层是唯一触摸/涟漪目标。内部文字按钮透明且不参与触摸或独立反馈，外层同步可用性及可访问说明；禁用时不继续响应。列表区域仍以每一行操作为边界，滑块保留自身交互。
