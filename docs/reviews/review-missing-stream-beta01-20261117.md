# 缺失流式距离输入尝试修复

4.6.0-beta01基于4.6.0正式版。样本显示旧Refactor曲线接口已连接，原生距离确认持续等待时转走mapping路径，曲线契约正确拒绝绘制非实际路径。用户确认导出前才关闭自动亮度，不能用包尾manual解释此前异常。

私有固件确认SceneDetector按33171005取流式输入，输入null时注册入口直接返回；场景更新仍可能设置距离等待位。设备枚举无33171005，有另一种中兴33181011，其载荷语义未核验，禁止直接替代。只提取接口事实，不公开固件或原始诊断。

修正放在SceneTuning既有适配边界，复用完整旧式共享Hook组，不新增传感器采样、轮询、线程或系统设置写入。额外成员逐项校验非static类型和方法返回值；原生Sensor字段null、管理器查找null、display0/state7且自动输入有效才处理。原生存在有效输入、查询失败、类型错误、残缺结构、初始化中、其他显示/用户、熄屏及停用均沿用旧行为。前置调用使用FieldOverride，正常/异常均恢复；后置判断不清原生等待位，只过滤已证实不能完成的距离项，保留AON和不符合两等待位OR的原生结果。原用户显式block功能保持。

SceneController仅新增诊断计数scene_control.stream_sensor_compatibility：admissions_avoided、waits_released和sensor_substitution=false。原场景选项、原配置键、保存解析和曲线/节点控制未变。兼容表登记待回访；未标记真机已修复。

验证涵盖原场景回调、字段恢复、异常、AON、有效/尚未绑定输入、查询失败、用户/线程/屏幕边界及错误ABI副本。完整构建、签名、最新感谢名单、源码/完整包及旧交付核验回执位于build/missing-stream-beta01-20261117。仅本地，不发布或安装设备。
