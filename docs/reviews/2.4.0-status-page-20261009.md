# 状态页布局与实时说明

当前为 `release-2.4.0-r8 / 24008`。完整场景与条件见 [机制梳理](2.4.0-brightness-scenes-20261009.md)，本文替代本轮之前的 r7 布局说明。

从上到下：主辅光感 → 融合与当前场景 → 当前实际曲线 → 高光/低光受阻 → 实际屏幕亮度。

- 主辅与输出行普通字号 64 dp，融合行 80 dp，纵向间距 14 dp。融合区域展示当前场景，点击查看 17 类触发/退出、影响与本机值。
- 曲线下蓝色容器 32 dp，仅一行实际曲线说明与句内蓝色设置入口，不含亮度分支入口。蓝色/绿色/灰色和未知说明由实际 CurveComparison.kind 统一决定。
- 下部卡片固定 116 dp，只放高光和低光两项。无当前限制也明确显示，没有空行和曲线介绍；实际多原因叠加，长内容内部滚动。
- 高度只由窗口/字体决定，最小页高 540 dp（字体 1），字体 2 为 720 dp，剩余空间给图表。图表至少 96 dp，蓝块与图隔 8 dp。短屏整页滚动。
- 当前原因只采纳新鲜证据，历史反射标记不等于当前 AON 降亮等待；普通距离策略未启用不会作为当前阻碍。

生产布局主机 2617 项、实际富文本与点击回调替身 684 项、光感/模式/分区 918 项检查。已在连接手机安装并重启新包，核对首页、场景弹窗、设置表单、草稿提示与顶部应用；手机原配置已恢复。详见 [真机记录](2.4.0-device-smoke-20261010.md)。
