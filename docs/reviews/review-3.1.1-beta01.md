# HyperLux 3.1.1 Beta 01 复审记录

基线：正式 3.1.1 / 31100。初始现代接口测试版 31101，界面修订 31102，当前 legacy 回退包 31103，均未发布。前面记录保留历史实测，当前入口以最后的回退记录为准。

## 实现与关键边界

- 更新检查启动与展示均限定关于页；网络结果返回时再次检查页面，离开页面关闭已有更新弹窗。
- Hook 核心改用模块自有适配接口，现代 API 102 与旧 API 调用隔离。现代拦截保留参数修改、提前返回、原方法异常、after 恢复及调用附加数据；旧回调每次注册使用独立数据槽，避免多个 Hook 相互覆盖。
- Hook 句柄集中登记，失败安装可注销；自动热重载关闭，回调返回拒绝。状态迁移、全部回调及线程退场尚未完成，不宣称已经支持免重启更新。
- 节点映射使用实际滑块范围与真实主屏上限。Root 重新发现节点并核验；SystemUI 不使用 su，系统显示回调不执行原生 socket 事务。
- 所有映射请求校验构建、系统进程启动身份、时效、手势、主屏、解锁和配置。旧手势及用户后来的自动亮度操作优先；确认晚到时重新检查当前会话。
- 节点守护由 Root 显式开启被动监听，绑定当前 system_server PID；只接受该框架进程产生的有效 cc_ 授权。保持原先 Root socket 写入限制，不开放 SystemUI 直接写节点。
- 暗光、应用名单、手动面板和户外增强继续通过现有所有权协调。常亮使用当前会话的屏幕 WakeLock，关闭弹窗后可继续生效，屏幕关闭或停用模块后释放，原熄屏设置不变。

## 已处理的问题

1. 旧接口适配回调初稿用了共用附加数据键，多个 Hook 可能覆盖。改为每次注册独立槽位。
2. 通用 SeekBar 不足以证明能识别小米控制中心。新增实际 MiuiBrightnessController 的用户回调，检查字段、参数及真实控件范围；存在该回调时避免重复发送通用触摸请求。
3. 系统进程重建时，旧的被动监听可能仍存活。守护报告绑定 PID，Root 发现身份不一致后重新启动；旧进程消失时守护自行退出。
4. 恢复自动亮度或配置回退时补齐控制中心守护的恢复协调，停用时清除公开给 SystemUI 的节点配置。
5. UI 请求与节点确认队列有界，确认结果按会话检查；跨线程关闭标记使用 volatile。

## 尚未证明的行为

没有据此证明所有现代/旧框架分支均能自动选择入口，或所有机型均使用同样的控制中心控件。旧入口尚无本轮设备执行证据。控制中心手动限定模式、节点保持会话的锁屏恢复及功耗仍需分别做设备验证；已有短时真机结果不能推广为全部路径通过。未知接口保留系统行为，不按机型名称伪造支持。

## 31104：长期双向映射（仅本地）

用户明确要求先本地实现，随后真机验证。本轮保留 legacy API 82，构建身份改为 beta-3.1.1-beta01-coordinate；不安装、不重启、不发布。

此前模式 2 拖动会取得原始节点所有权并关闭自动亮度。本轮移除该行为：SystemUI 将节点比例反解为系统原本接收的坐标，原始 onChanged 继续执行，跟踪、自动模式和结束标记不变；不发送节点请求。系统服务只异步读取纯转换函数并发布校准，不订阅旧手势请求，不调用 armRaw；Root 只验证节点身份并绑定映射表，不启动控制中心节点守护，退役旧空闲监听时保留正在使用的手动面板。

标准 gamma 与 OEM V1 分开处理。后者接收逻辑目标，不可视为标准亮度或直接节点。在经过实际固件签名核对的 UI 回显调用范围内转换坐标，保留 OEM UI 初始化与动画；异步动画捕获的数值已是节点坐标，不进行二次换算。配置或模式变更取消旧刻度动画，并请求 OEM 原有后台读数刷新，不模拟用户拖动。未知 ABI 安装回滚，缺少对应表、非单调数据、无效滑块范围或配置身份不符时保留系统行为。校准失败会主动撤销公开映射表，避免继续使用此前的坐标。

校准在有界后台任务中执行并缓存，不阻塞显示线程；状态写入独立增加一个校准组，最多三个待写组，仍保留确认与完整运行快照的顺序。配置核对构建、PID、进程启动身份与开机次数；表长度和数值范围受限。弱映射的值只弱引用控制器，避免循环保留已销毁的 UI。

专项主机测试覆盖：实际生产 Hook 的实例回显与 R8 合成静态回显两种 ABI，非线性正反换算，逻辑映射上限小于系统实际亮度时的回显，自动模式与原始参数保留，取消与异常边界，未知路径保留，跨启动数据拒绝，Root 节点身份与代次核对，旧空闲守护退出、活动面板保留，以及旧请求不能取得节点所有权。控制中心 134 项、亮度控制 384 项、独立自检 241 项、延迟写入 23 项通过；这些是服务替身与本地执行结果，不能代替 Android 真机验证。

未证明：各机型 UI 私有 ABI 均适用、真实 gamma/逻辑曲线精度、锁屏解锁与重启后首次回显、手动记忆的真机学习和实际功耗。完整节点刻度不解锁未开放的范围；环境因子和保护会继续改变最终输出，不能宣称节点恒定保持。
