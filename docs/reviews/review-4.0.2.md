# 4.0.2 正式版复审

2026-10-20。用户明确授权同步发布 GitHub、LSPosed 与官网，不自动安装手机。以公开 4.0.1 为基线，合入 4.0.1 Beta 01 / 02；更新说明严格使用用户给定的三条，不添加感谢名单变更。

## 代码与兼容

具体实现及边界沿用 [Beta 01](review-4.0.1-beta01.md) 与 [Beta 02](review-4.0.1-beta02.md) 复审：实际单主光感输入、传统自动亮度速率路线、独立 TwilightManager 夜间锁定范围。保留原生辅助 / 移植补位 / 折叠光感、Refactor 时长与所有原有路径；未知或残缺接口只暂停对应功能，不绕过原保护。不改 compatibility-baseline 来删除路线。

暗光锁定与夜间范围默认关闭，已有显式设置、阈值、名单、曲线和保持范围保留；仅主光感不伪造辅助值，真实 0 lux 与未接入分开。全天与日落后预设均仍需照度和持续确认；日出只恢复本模块取得的自动模式，系统时间不可用等待，不猜固定钟点。本轮将预设显示名统一为“日落后锁定”，其键和运行逻辑不变。

私有固件静态接口核对和主机服务替身回归不代表目标机真机通过。本轮不宣称实际跨日落 / 日出、位置变化、目标机动画观感或长期功耗已验证。原签名、legacy API 82、覆盖更新后重启要求不变。
