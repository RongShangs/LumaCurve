# 4.2.0 Beta 07 复审

本次只调整控制中心分区坐标、节点上界、交互准入和设置展示；原机普通边界读取、完整节点/隐藏比例路线、raw_panel原生资产及既有设置保留。新字段独立持久化，0默认真实上限，sameOwnership不包含展示偏好。节点目标在系统端二次校验。

系统反馈和手势严格分开：自动阳光屏显示可进入增强区而不生成请求；从已自动增强区开始的新拖动可接管，但系统端必须读取当前实际高亮重新确认。普通区上滑继续三秒二次确认；源滑块同步封顶，mExternalChange在finally恢复。

操作动画纯本地Canvas，不涉及亮度桥，停止时删除待执行帧。新增生产文件已登记source-map、兼容清单和源码包测试；兼容目录原路线不删除。完整核验和产物哈希见build/beta-4.2.0-beta07/verification.json及final-audit.json。仅主机回归/固件静态检查，不代表Android真机或功耗结论；仅本地交付，不安装或发布。
