# MIX Fold 3 内外屏兼容复审

2026-10-21。根据用户提供的分析包核对实际框架、屏幕和节点；机型名称按用户更正记为小米 MIX Fold 3。仅本地源码修复与完整只验证构建，未重新打包、发布或安装。此前已交付的 4.0.2 Beta 02 文件不变，不包含本次新增修复。

## 样本与结论边界

样本运行 release-4.0.2，系统实际记录 OS3.0.304.0.WMVCNXM，用户最初描述为 OS 3.0.340。版本号和型号只用于诊断归档，不参与放行或拒绝功能。原 ZIP、配置、固件及反汇编留在私有诊断目录和 build/fold3-f26a8d/，不进入源码或发布包。

导出时引擎为 attached / 官方曲线，revision 为空、consumed 为 0，config.json 为 null，自动亮度关闭。不能把这种状态下的无采样、没有增强或没有曲线调用当作适配失败；同样，接口自检通过也不能证明启用后实际效果正常。分析包只记录了外屏点亮的一次场景，缺少应用配置后内外屏分别运行的结果。

| 功能 | 本包证据 | 处理与边界 |
| --- | --- | --- |
| 基础曲线、手动记忆 | 已连接本地 physical_mapping，相关自检通过；尚未应用个性化配置 | 保留原物理映射路径；本包不能确认修改曲线后的实际效果 |
| 主光感 | 外屏 ABC 真实主槽选中私有 secondary ALS；内屏 ABC 主槽为标准 ALS | 沿用实际逻辑默认屏、控制器及其已选传感器，不以 TYPE_LIGHT 或型号替代系统选择 |
| 辅助光感 | 双策略已绑定 back_lux 辅助传感器，当前自动采样关闭 | 硬件接口存在；本包不能确认自动模式中的采样稳定性，不伪造辅助值 |
| 主屏手动节点 | 外屏点亮、panel1 为 255；panel0 为 0 且断电；正式版仍固定选中 panel0 | 新增独立显示端口与内核节点编号不一致的选择分支；保留此前普通节点和折叠端口配对路径 |
| 亮度过渡 | 原三参目标入口存在，四参入口不存在；原日志明确 NoSuchMethodException | 新增三参完整 ABI，继续使用原双动画器、原因门控和下游时长上限 |
| 户外目标、HBM、高亮范围、OPR、nit 上限 | 已识别旧目标、原生支持方法、零时间预算和传统 OPR 路径，当前户外增强未开启 | 不改这些已匹配路径；不把零时间预算误判为 HBM 不支持，也不承诺实际可达亮度 |
| 普通距离、流式距离、反射 / AON | 相应接口存在，本机原生策略关闭 | 自检分别标识系统未启用；不强制开启传感器或服务 |

| 辅助光感闸门 | 旧双策略缺少所需待重置标记 | 保留不支持，不能删除新鲜度门控来假装完整；主光感暗光稳定独立可用 |
| 节点高亮、控制中心映射 | 框架报告 pending，控制中心转换方法缺失；映射入口原本隐藏 | 不扩大手动面板修复到户外强制节点或隐藏映射，不推断它们已适配 |

崩溃记录包含其他系统应用和其他模块异常，当前证据没有证明 HyperLux 引发系统卡死；不把这些记录归因到亮度模块。

| 设置迁移 | 不新增或改写用户配置键，不触碰保存曲线和名单 | 不新增或改写用户配置键，沿用原变亮 / 变暗倍率 |
