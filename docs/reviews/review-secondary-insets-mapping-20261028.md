# 二级页沉浸与独立映射设置复审

2026-10-28。已交付4.2.0-beta03 / 42003不替换。本轮仅源码体验优化、验证与维护文档；不打包、发布、安装或操作设备。上轮实际标定端点兼容源码继续保留，不回退原兼容路线，所有359份既有APK/ZIP保持。

## 二级页系统导航区域

原ImmersiveLayout在二级页把safe.bottom加到整个root，导致内容视口停在系统导航区域上方。改为根页面只在键盘可见时保留IME高度；系统导航安全间距加在11个设置滚动视口与功能自检滚动视口内部，clipToPadding=false允许内容延伸到系统栏背后。原body尾部留白保留，末项可滚动到安全区上方，不遮挡点击；三键、手势和隐藏导航区域按实际insets更新，键盘时不叠加两套底部距离。

保留透明系统栏与对比度配置、深浅色图标、横屏cutout左右边距、状态固定视口、悬浮底栏18dp最小留白及教程/快速设置兄弟层安全区域。没有修改传感器或显示控制。

## 映射独立设置块

主屏手动亮度保留磁贴开关、简明行为说明及面板/添加磁贴按钮。控制中心映射是其后的独立卡片，不再嵌套进手动面板卡片；去除选择弹窗，三个范围在卡片内直接选择，选项与工具按钮自然高度、文本独立占宽，兼顾大字与长翻译。搜索定位卡片标题，避免巨型容器抢焦点导致滚动位置跳动。

ControlCenterStatus只读取现有runtime/已保存配置与当前草稿，区分等待连接、换算待就绪、确定不兼容、关闭、待保存、已保存未接入和已保存。只证明引擎换算就绪，不推断SystemUI已确认或实际生效。ControlCenterSettings消费这些事实，保存仍走原顶部保存动作；无法换算时可关闭或保留原选择，不能新增无法核验的启用。显式重新检测复用原只读自检，不写配置或试调亮度，兼容详情复用日志原页面。

未改变Root或任何系统映射、主屏原生程序和暗光锁定所有权逻辑，不新增常驻进程、轮询或传感器监听。
