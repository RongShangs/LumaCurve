# 4.1.0 Beta 02 复审

以公开4.1.0-r1为累计基线，沿用已交付Beta 01新增曲线路线，用户指定Beta 02本地打包。未获发布或手机操作授权。

## 依据与处理

用户反馈强光下屏幕变红、移开转白，APP显示10000 nit。所提供分析包的强光系统记录同样出现10000 nit；原生OPR已将1.0降到约0.519，模块放宽回1.0。真实主屏节点增强为关闭、守护未运行。固件消费者按灰阶索引读取原生OPR nit表，经DisplayDeviceConfig换算，且先于BCBC、峰值、温控及电量；表最高档4500 nit，物理换算末端10000 nit。

可证实的问题是额外放宽把整个换算区间当成可用范围，不能仅以最大归一值为准。新增OutdoorOprEnvelope集中读取实际对象的原生表，最高档经过既有物理nit反解后约束新增放宽。没有整组字段保留旧路线；残缺、错误、未启用及换算失败保留原生结果。不是型号白名单，不硬编码4500 / 10000，不修改原生表、灰阶、色彩参数或设置，不遮掩原本更高的系统输出。

## 复审与验证

- 生产适配器与真实反解测试覆盖非线性换算、动态表更新、空/坏/无序表、实例与静态类型、继承、异常恢复、多对象、已高于上限的原生输出、旧式无表路径；2026项主机检查。
- 生产Hook旧/新八种ABI及多加载器回归，新增超出OPR表的换算端点例，确认热控、电量、HDR退让及原生原因位处理仍有效。
- 私有固件19项消费者、系统映射、输出与节点关闭证据核对。静态证据不等于Android实测。
- 统一登记ABI、责任、证据与测试；兼容页面显示OPR实际范围；状态nit加来源字段，避免把系统换算当光学测量。
- 完整构建结果、证书、版本、源码对应、旧交付物不变与私有输入排除核验保存在build/beta-4.1.0-beta02/。

## 尚未证实

本包没有面板硬件/色彩服务的实时测量，不能断言红色偏色仅由该越界造成。此次收窄本模块输出放宽边界，偏色改善仍待目标设备新版验证。不会因反馈就全局关闭功能或删去此前机型路径；未更改节点功能。保留Beta 01分段拟合路线的原生学习与高级保持暂不开放边界，不把旧模型完整能力套到新曲线结构。
