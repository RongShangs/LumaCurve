# 分组操作与应用选择过渡复审

目标：本地4.4.5-beta13 /44513，构建beta-4.4.5-13。不发布、不安装或操作设备；保留全部历史交付及已保存配置。

## 回访和定位

用户提供2026-11-10 14:32分析包，反馈删除分组经常无效，先编辑一个应用后才可删除，应用选择页过渡与其他二级页不同。包内为pandora／25098PN5AC、HyperOS 4.0.6.0.XBLCNXM，Beta12引擎处于active，导出时分组已为空；这不能重建每次UI点击的历史。

源码和生产回调测试确认旧对象问题：未编辑草稿时，状态读取会重新解析controls及其分组对象；界面按内容签名缓存，所以相同内容不重建按钮。按钮闭包仍持有旧AppGroup，按对象删除无法命中当前列表；重命名也会修改旧对象。编辑任一应用后dirty阻止读取结果替换草稿，因而暂时绕开问题。

## 改动与保留

- 按钮只保存稳定分组ID；打开删除/重命名时查询当前草稿，确认时再查询或按ID删除，不依赖旧对象引用。
- 取消不改变任何名单；已删除ID不会复活或误操作同名新组。重命名保留当前应用成员；新增组在确认时复查最多3组的限制。忙碌时按钮显示禁用状态，删除后仍按原流程保存并应用。
- 应用选择Activity显式配置打开和关闭过渡：与既有二级页采用相同12dp位移、180ms进入/120ms退出淡变，关闭系统动画时不播放。保持Beta12页面布局、草稿返回和确认迁移语义。
- 使用项目最低运行API已具备的[Activity过渡覆盖接口](https://developer.android.com/reference/android/app/Activity#overrideActivityTransition(int,int,int,int))，在目标Activity创建时设置双向动画及主题背景，不叠加另一套内容动画。
- 亮度控制、学习隔离、节点映射及配置键不改；所有保存的旧暂停/独立/分组设置保留。

## 核验边界

18项生产分组回调检查覆盖相同配置重新解析、保留旧按钮、连续刷新、弹窗内刷新、删除/取消、重命名、同名不同ID、最新成员保留和组数上限。用修改前实际源码运行同一回归会在删除检查失败，证明测试能识别原缺口。

名单页121项检查继续覆盖初始化、布局、草稿旋转恢复及双向过渡配置，另核对4个动画资源与MainActivity现有位移/时长一致、深浅色背景及系统关闭动画。它们属于主机/服务双件和资源检查，不是Android像素渲染或设备实际动画结果。

完整构建继续覆盖已有亮度和节点恢复；最终编译指纹、签名、随包源码、最新感谢名单和历史文件核对见本地build/group-navigation-20261110回执。分析包、固件和原始日志留在私有归档；新包真实交互与动画观感仍需回访。
