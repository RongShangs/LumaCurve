# 悬浮底栏、实时搜索与日志兼容界面 · 2026-10-26

## 范围

在已交付4.1.1 Beta 05 / 41105上进行界面源码修改，版本标识暂不变，不重新打包、不发布、不安装。用户后续明确：日志顶部不做简单压缩，应重新设计，让兼容情况更直观。

## 行为

- 状态、设置、日志、关于沿用原四个入口；底栏为独立悬浮胶囊，选中项使用浅色圆角背景，深色主题沿用现有调色板。
- 只在设置首页与关于页的实际滚动手势中收放：向下浏览超过阈值向下隐藏，反向移动后出现，到顶部和切页恢复。抖动、程序恢复滚动位置、日志自动滚动不触发收起。减少动画设置生效；离开页面结束动画并清除旧结束动作。
- 系统状态栏、手势/三键导航区域透明；内容和胶囊分别处理系统栏、横屏切口与键盘边距。键盘打开时底栏避让，内容保留可操作空间。教程/快速设置仍覆盖整个主界面，并共用安全边距，不会露出后面的底栏。
- 主设置页不再显示品牌顶栏，顶部为搜索框。输入即筛选现有功能，支持中文、英文、关键词和多词查询，清空后恢复原列表及其原滚动位置。查询与原列表位置随页面重建保留；搜索与返回不提交或修改设置。未保存草稿保留，二级设置继续保留返回与保存。
- 搜索可导航至基础/记忆/暗光/户外/温控/场景等现有设置，也可到日志、自检或原快速设置邀请。隐藏的控制中心节点映射入口不通过搜索重新开放。隐藏桌面图标仍用原偏好键，入口归到运行状态与界面子页。
- 日志首页同样去掉品牌顶栏。顶部以Root访问、系统注入、亮度引擎三个区分别展示证据，下方保留可读说明与最近自检各类数量；一个完整自检入口可查看详细路线。普通窗口不截断说明，短窗口/大字体允许说明卡片内部滚动。
- Root读取失败不推断系统模块已停止；可读取不等于写入权限完整，自定义生效/系统基准/待确认/状态过期分别显示。最近自检计数包括APP、Root与引擎报告，不把部分功能不可用概括为整机不兼容。
- 日志区继续使用剩余高度，整理标题/自动滚动/刷新/工具行，移除不准确的固定导出路径说明，实际导出后显示真实路径。

## 代码归属

| 组件 | 责任 |
|---|---|
| FloatingNavigation / NavigationPolicy | 导航外观、动画、真实手势门槛与几何；不接触亮度参数 |
| ImmersiveLayout | 主界面、教程及快速设置的系统栏/键盘安全区 |
| SettingsSearch / SettingsSearchIndex | 查询、静态双语目的地、过滤及现有跳转；不探测接口 |
| LogCompatibilityState / LogCompatibilityPanel | 消费已有报告，分层展示Root/注入/引擎与独立自检结果 |
| MainActivity | 接入页面生命周期、现有设置导航和日志布局 |

源码登记144份Java，仍52项设备功能、21组兼容家族；没有新增设备兼容路线，不更改曲线、传感器、Root访问、原生控制程序或采样率。新代码不创建后台服务、Root进程或亮度监听。
