# Beta 06 后的导航与页面排版修正

## 边界

仅主线界面与验证，不更改AppBuild、Manifest或用户配置；不打包、不安装、不发布，已交付Beta 06保持原字节。所有兼容路线及采样行为保持。

## 实现

- 悬浮底栏在自身12 dp留边内绘制模糊阴影，避免依赖父容器外部的硬件阴影。参考用户后续提供的小米底栏，普通字号下可见胶囊最大288 dp、高64 dp，居中悬浮，四个触控项至少56 dp高，两侧保留明显留白；底部可见间距18 dp；仅实际遮挡的系统按键区/切口追加避让，手势提示区不重复增加底距。内部触控仍在系统手势区之上。大字号允许文字换行并自然增高，宽屏不横向铺满。
- 选中态使用一个横向平移的胶囊，240 ms减速；快速换页先取消旧动画，从当前坐标继续。首次布局、尺寸改变、暂停或关闭系统动画直接定位。
- 设置/关于只根据真实滚动方向收放，不再到达边界自动展开，禁止回弹产生反向假手势。程序恢复位置、自检及二级页不会触发收放。
- 状态页彻底移除ScrollView。固定FrameLayout依据可用高度和字号等比容纳完整逻辑布局，保留全部卡片、场景行、曲线和保护项；状态数据变化不改变卡片高度。不牺牲现有设置/关于及日志的滚动能力。
- 运行与兼容顺序为标题、运行结论与说明、Root访问/系统注入/亮度引擎、蓝底“最近自检”入口。移除右上重复自检按钮，底部入口支持换行且居中，三项状态保留等高区域。详情仍进入原有完整自检页，原始证据和兼容判断不变。

## 验证

- 导航/搜索533项：旧搜索、跳转、原位置和草稿保留，真实手势与程序滚动区分；抵达边界不自动展开。
- 指示器11项：初始位置、平移目标、中途反向、暂停、缩放布局和减少动态效果；直接执行生产动画控制方法。
- 状态几何5839项：既有几何、不同密度/字体/横竖窗口的固定适配与测量边界。
- 日志证据189项及布局接入断言：先说明再三项状态，底部只有统一蓝底入口。
- 完整构建、兼容检查、历史APK/ZIP保留与生产源码差异范围以私有build/navigation-refinement-20261026/回执为准。
- 未在Android真机验证阴影、像素排版与动画观感；主机时序/几何测试不能代替真实渲染。极小分屏或大字号下，状态页以整体缩放保持完整可见。
