# 关于页图标容器、弹幕与紧凑布局修正

2026-10-27。仅源码与验证；版本维持4.1.1-beta10 / 41110，不重打旧包、不发布、不安装。已交付Beta 10不含此次调整。

- 顶部改为有底色的圆角方形容器，和原App图标一样包含曲线；深浅模式各自使用可读配色。曲线与弹幕统一受圆角轮廓裁剪。
- 图标放入与功能卡片相同的滚动内容；后面的卡片紧随图标，不再覆盖固定背景。1:1尺寸扣除左右18 dp，宽屏上限540 dp居中。
- 弹幕不再固定为中间4轨；按实际高度和字号自适应1—12组高度带，覆盖上下区域，每条另加上下随机偏移，避免整齐列队。内容顺序、起点、间隔和16—28 dp/s的速度均变化。
- 每条具有独立速度；后发前预测比前条更快时的最小余下间距，不满足就延后发出，防止追尾。每组最多3条，总量有界；只在About前台且图标确实与滚动视口相交时推进，暂停/教程/隐藏/销毁及系统关闭动画规则保留。
- 绘制不再用“可见高度”截掉局部图标。可见高度只控制动画启停，实际裁剪由容器轮廓与原生滚动视口处理，避免部分滚出顶部时下半部也被错误隐藏。
- 更新提示、链接、复制及About其他操作的最小按钮高度从48 dp减到40 dp，内边距10→6 dp，缩小按钮外距与群号区留白。保留换行、自然增高和原有操作，其他页面的48 dp触控规格不变。

专项直接执行生产弹幕、视口交集、主题与动画生命周期模型，包含长期变速防重叠、上下覆盖、独立速度、部分可见及无接收更新。完整152份Java编译、兼容回归与此前334份APK/ZIP保留以私有build/about-layout-refinement-20261027/audit.json为准。没有Android真机或像素渲染验证，不把主机模型当作实际观感。

最终验证通过：152份Java完整编译、84949项关于页生产模型检查、180条PASS汇总；仅3份About组件源码变化，其余引擎/Root/设置源码保持，334份历史APK/ZIP未变。
