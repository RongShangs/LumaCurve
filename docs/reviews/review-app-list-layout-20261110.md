# 应用选择页布局复审

目标：本地4.4.5-beta12 /44512，构建beta-4.4.5-12。所有暂停、独立及分组名单共用同一选择页；不发布、不安装或操作设备。

## 用户要求与实现

- 返回箭头和标题与其他二级页面一致：将原有箭头绘制提为共同方法，主页面和名单页均调用；保留48dp点击范围，统一18sp标题、自动缩放、文字留白和省略。
- 仅顶栏和搜索框固定。视频/游戏批选、计数、按包名入口使用原生列表的同一个滚动头部，随应用名单滚出视口。没有把全量应用展开塞入嵌套滚动区域。
- 删除常驻分类/保存说明。分类失败或应用读取失败仍可显示必要的异常提示，正常情况不占高度。
- 单个公共背景在应用数据区域绘制连续18dp圆角矩形；行不再各自画卡片或分割线，继续回收可见行、按需读取图标。滚动到中间时首尾圆角在视口外，真正首尾到达时才显示对应圆角，不把批选头部包入白色名单。
- 透明导航栏、关闭对比度遮罩并保留图标明暗处理。根布局只预留顶部/左右安全区域；导航/键盘遮挡放入列表内部尾部，保持内容可延伸到系统导航栏下，底部操作仍可滚到安全位置。

## 保留事项

仅改页面与绘制共用方法；独立亮度运行、节点映射、暂停名单可见性、旧配置键、分类识别、跨名单确认、取消及保存并应用语义不变。所有已保存设置和历史产物保留。

## 验证

名单页回归执行真实初始化前缀、弹窗按钮方法、公共背景绘制与安全区域方法：覆盖窗口未创建顺序、三个名单入口、主题、旋转后的选择/迁移记录、多密度首尾/中段滚动、空结果、键盘和导航遮挡。核对公共背景只绘一次、头部不进入白色卡片、尾部安全距离在滚动内部。

完整构建继续执行原有亮度、配置、隔离、应用独立亮度与节点映射恢复回归。编译源码指纹、随包源码、原签名、最新感谢名单及全部历史文件核对见本地build/app-list-layout-20261110回执。新包没有Android像素渲染、设备安装或真机交互结果；界面观感需回访，不把布局双件检查写成真机通过。
