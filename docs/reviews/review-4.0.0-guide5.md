# 4.0.0 欢迎与五页教程修订

当前保持 4.0.0 / 40000 / release-4.0.0，未发布。本轮只改界面、教程文案及配套验证，不修改任何亮度引擎、兼容选择、传感器、控制权或用户设置。

- 运行状态与界面的刷新设置和使用教程分为两个独立卡片，标题、说明与按钮各归各位。
- 欢迎打开、教程前进 / 后退和返回设置加入 180 ms 淡入与方向滑动，使用 Android 原生 ViewPropertyAnimator 并遵循系统动画开关。每次先取消旧动画、清除监听和结束动作并复位；没有依赖动画完成回调的页面切换或偏好写入。暂停 / 销毁 / 连续切换都复位，避免透明或横向偏移残留。
- 第 5 页提供导出分析包、从关于页查群号入群反馈、携带机型 / 系统 / 现象 / 时间确认问题的流程；说明只要是 HyperOS，HyperLux 都会尽力适配。群号以关于页现有入口为准，不在教程维护第二份号码。
- 欢迎完成标记、原设置与草稿不变；老用户从独立入口查看五页，不强制重新欢迎。中英双语保持。
