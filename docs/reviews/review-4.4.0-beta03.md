# 4.4.0 Beta 03：兼容边界审阅

范围：公开4.4.0之后Beta01—03的本地累计交付，本轮重点是分叉与收束。175份生产Java、58项功能、24组兼容。未授权公开发布或安装/重启手机。

## 结论及处理

用户提出的原则成立。现有框架已有适配层，但曲线相关仍存在差异泄漏；不能只因为路线都登记了，就称上层已经完全统一。本轮将主要泄漏点收回适配边界，并将每组的边界、契约、单位、消费者加入强制登记。

| 发现 | 修正 | 保留的行为 |
| --- | --- | --- |
| CurveBackend共用默认实现读取Refactor原生锚点，按名称默认支持曲线保存 | 原生读取回到RefactorAdapter，共用默认不支持；增加坐标、容量、模型归属和交接能力接口 | Refactor锚点、系数、小米传统和AOSP映射路线继续存在 |
| HookRuntime自行读取Refactor亮度边界并构造具体后端 | CurveBackendFactory收束原生对象与构造，运行协调只取得CurveBackend | 同一对象选择和异常拒绝规则，构造失败不换其他ABI |
| 页面、CurveComparison与SavedCurve各自解释后端/旧状态 | CurveCompatibility集中解码curve_contract或旧快照，输出共同曲线及能力；页面和转存复用 | 完整传统基线与插值、原有高亮域、旧快照和旧配置数值不变 |
| MemoryPersistence按TraditionalAdapter类型/名字决定当前模型和恢复同步 | 后端声明memoryContextActive和memoryRestoreIncludesModel；MemoryLifecycle作为原生观察适配器提供交接 | 原生模型所有权、恢复事务、系数路线未支持能力的拒绝 |
| 一个归档读取异常可以跳过同一try里的实时记忆发布 | 实时点与存档分开读取；分别记录错误 | 坏存档原样保留，不回写默认、不删除当前点 |
| Android与Root启动入口重复维护启用判定 | BrightnessControlOptions.mappingRecoveryWanted为共同条件，复用原recover | 只绑定本次引擎，不回放历史亮度/手势；原有四次有界重试 |
| Root启动证据未明显区分历史，包路径查询缺命令限时 | 历史/本次文字区分；查询3秒限时，恢复仍8秒 | 不改Root权限、不猜KSU分支、不新增常驻服务 |

## 逐组检查的记录

24组均在[兼容索引](../architecture/compatibility-index.md)记录实际分叉实现、统一契约、坐标与消费者；这些登记来自manifest并受自动校验。核心曲线组包含本轮生产重构，其余组保留成熟控制路径和原选择优先顺序。

重点保持：HBM启用接口与预算接口是两维；单/双/折叠光感不把缺值当0；节点需绑定当前物理屏；ControlCenter节点与framework滑条双向换算；Root能力不等于LSPosed注入；应用隔离与应用暂停独立；可选检测失败不清除用户原设置。型号/系统版本不参与新路线放行。

遗留的组织债务：HookRuntime仍包含历史原生状态采集；SceneController仍有已登记的原生事实读取和执行调用。它们未在本轮产生新的设备分支，但不是完全独立的观测适配器。本轮明确登记这部分，避免用大规模机械搬迁改变成熟Hook；后续新增ABI应先在对应适配器内完成收束，不继续向管理器添加判断。

## 验证

- 新增135项生产数据边界回归：三条曲线类型的新/旧快照一致，合法契约下后端标签变化不改变绘图选择，坏契约拒绝降级，未知坐标/类型/容量拒绝，HDR和非当前输出拒绝转存，读取不修改原配置。
- 维护契约37项：旧路线、全部登记与新收束字段；注入UI/管理器原生分支的负向样本必须失败。
- 原曲线对照64、保存3099、锚点49、传统2377、系数19353、百分比表单8139、记忆240、原生模型49等对应回归；完整构建还执行其他所有主线测试与既有固件静态核验。
- 根启动30项及4个实际脚本模拟场景、Android任务171项；这些是主机双替身/临时目录验证，不是手机Root启动实测。
- 最终完整输出见私有 `build/beta-4.4.0-beta03/build.log`、`verification.json`、`local-audit.json`。APK、源码、完整ZIP和对应SHA-256一起检查；保留447份旧APK/ZIP、原签名与raw10节点资产。

本轮没有手机开机、实际亮度、动画像素或功耗测量。没有把用户设备问题标记成真机修复完成。公开官网/更新索引保持4.4.0/44000，没有推送。
