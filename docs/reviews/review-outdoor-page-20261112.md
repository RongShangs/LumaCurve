# 户外高亮页重做与拖动编辑

用户要求重做整个户外设置，曲线直接拖动，逐级开关改为单选功能块，并将原详细设置纳入曲线区域。本轮本地4.5.0-beta02 /45002，不公开发布、不安装或调整手机。

## 页面与配置

增强方式展开后选择沿用系统、常规增强、开放高亮范围、放宽画面限亮。下一步按前置选择和独立能力开放，已保存的高阶选择仍可查看和降低，缺接口不清空配置。高亮控制集中选择系统目标、自定义曲线、节点增强；更换冲突方式先确认，确认时重新检查状态，取消不关闭旧选择。设置统一nit上限与节点模式的冲突同样确认。

曲线与策略区先呈现当前高亮控制，再呈现增强过程。增强过程直接拖动进入、全强度和退出节点，编辑照度、增强幅度与退出比例；增强进度百分比不标成屏幕亮度。全部10项原参数（含确认、时长、冷却、HBM）改为参数格，点按即在对应行下面展开单个滑动杆，取消整段隐藏的详细参数。自动HBM仍按本机能力独立选择，未启用计时的设备保留预算但禁用编辑。原预设和手动阳光屏场景/条件与参数保留，不混同自动增强的曲线。

物理nit曲线可拖动照度与亮度、空白点按加点、选择后删除，至少保留两点、最多16点。旧2—16节点全部读取；空草稿仅在用户选择曲线时，用原生已校验的普通与全域物理nit边界初始化4个可拖动控制点，明确为上限控制线，不声称提取原生曲线。普通边界通过既有换算器只读补充到状态；没有边界就不生成通用机型模板。

编辑只改草稿，保存应用仍复用原流程。曲线运行、HBM范围、窗口隔离、独立亮度和节点租约逻辑未重写；OutdoorOptions协议和旧保存键不变。刷新无副作用，不再因当前能力或前置状态缺失而关闭保存的节点开关。降级关闭依赖是用户明确选择，数值、节点目标和曲线点保留。
