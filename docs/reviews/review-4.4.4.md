# 4.4.4 正式发布复审

本次以公开4.4.3为基线，合并其后Beta01—04。各轮独立复审与固件/主机证据保留；没有新增亮度控制逻辑或用户默认设置。

- K60：普通/休眠映射对象在MapperContextAccess分叉，自动模式在AutomaticModeAccess分叉，无倍率双光感在BrightnessSensorAccess分叉；统一进入既有曲线/模式/lux契约。现存优先接口损坏不降级。
- 12S Pro：原生自动策略读取有效模式；模式错误独立发布，曲线与日志继续保留，APP后台刷新不持续Toast。
- 原生节点：私有目录和锁先核验身份及同一文件对象再规范权限；占用不抢锁；候选恢复后原子替换。raw11与Beta04载荷相同，原设置、数据及持久化协议不变。
- 原有182份Java及137个受保护功能/路线组合继续校验；正式版生产差异相较Beta04仅AppBuild与Manifest身份。原签名、历史交付、配置/记忆代码及各包内容另行审计。
- 更新日志顺序为当前小版本简略、4.4.0—4.4.3累计简略、详细更新。官网首页仅当前摘要；三渠道同一APK与源码、完整包及哈希。
- 相关新路线已完成主机及匹配固件静态核对，不等于目标设备实测。K60响应、部分场景、温控、HBM、动画及SystemUI坐标仍独立检测，本版不宣称全部兼容；没有设备安装、调亮度、长测或功耗验证。

本次用户明确授权正式发布；最终签名、构建、源码和三渠道实际下载结果留在私有build/release-4.4.4-publish回执。既有独立研究和未提交分析工具改动不合入。
