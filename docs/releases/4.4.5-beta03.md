# HyperLux 4.4.5 Beta 03

1. 新增可选“本次亮屏共享应用亮度”：被隔离应用共用普通亮度，桌面沿用系统，锁屏后清除。
2. 付款码、极限值及受保护场景不进入共享，控制中心主动调节优先。
3. “记住手动偏好”移除三个预设；调整记忆开关后或展开详细参数时显示红字提醒。
4. 保留此前折叠主屏完整/分区映射适配、所有旧路线和已保存设置。

## 详细更新

累计基线为上一个已公开正式版 **4.4.5 /44500**；本版 **4.4.5-beta03 /44503**、构建 **beta-4.4.5-03** 仅本地交付；Beta01、Beta02及全部旧交付保留。

### Beta 03

- 在应用亮度隔离下增加默认关闭的共享开关，保存选择与运行能力分别处理。仅内存保存本次亮屏内一个普通应用偏好，不跨锁屏、用户、物理屏或系统进程恢复。
- 新应用进入时使用共享值，同一应用后续正常调节可更新；桌面维持系统调节，不把另一个应用原有亮度反过来覆盖共享值。
- 只有原生确认的普通非二维码调光才参与；二维码限亮、极限端点、HDR、相机及其他控制者沿用系统。仍经过原生下游限制，不写全局亮度或切换自动模式。
- 共享能力独立核验，缺少新接口不影响原有应用隔离。复用原有5个隔离Hook及窗口/屏幕事件，无新增后台服务或采样。
- 移除记住手动偏好卡片的完整记忆、渐进记忆、不记忆快捷预设，保留手动开关、强度及其他保存设置。
- 红字提醒在本次页面用户调整过记忆开关，或详细参数展开时显示。初次进入且折叠、未操作时隐藏。

### Beta 02

- 最终包核对时纠正构建信息中遗留的“折叠控制中心监听不支持”标记，使回执与本轮已实现能力一致；明确该机新包真机验证尚待完成。
- 原生回归计数读取最终汇总，避免只记录第一组基础用例。

### Beta 01

- 主屏原生工具升级为raw12，允许同时绑定经过核验的折叠背光端口和当前系统进程；沿用原租约、读回、权限恢复、HDR、锁屏及系统输出保护。
- 已保存的节点选择可在同一原生布局、同控制器、相同上限的配对内外屏间复用；每次重新核对实际默认物理屏、DSI和本次标定，不修改用户原配置，不将旧屏目标重放给新屏。
- 折叠映射监听在灭屏时释放节点权限并等待；不接受新的接管、不写灭屏节点。独立手动面板仍保留原有灭屏退出方式。
- 恢复自动亮度先确认原生守护释放与系统模式写入；附加映射暂未恢复只单独提示，不再将成功的恢复误报为失败。权限恢复或模式写入失败仍报告操作失败。
- 核对lhasa／2608BPX34C、HyperOS 4.0.26.0.XPNCNXM分析包的曲线、记忆、FOV与辅助光感、响应、场景、动画、HBM、输出及节点接口。原生未启用的普通距离、流式距离、反射/AON策略继续沿用系统；原生零HBM计时不改成虚构时间预算。
