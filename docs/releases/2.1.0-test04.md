本地布局测试版，构建 `test-2.1.0-outdoor04`，版本代码 20103。未发布 GitHub 或替换官网正式下载。

红色「有未保存的设置」与引擎控制标题同行，位于右侧；英文提示缩短为 Unsaved settings。分类卡片的箭头围绕标题与说明整体居中，使用绘制的图标，不再依赖字体基线。分类上下内边距 11dp、分类间距 8dp、标题与说明间距 3dp。

签名和包名保持原值。覆盖安装并重启一次，在中文及英文界面核对引擎控制标题、分类入口居中和子页面返回。模型、编译、签名和固件静态检查不等于 Android 实机视觉验证。没有更改亮度控制算法。
