# HyperLux 4.0.0 Beta 01

版本名称 `4.0.0-beta01`，versionCode `40001`，构建 `beta-4.0.0-beta01`。基于公开正式版 4.0.0，原包名与签名，保留已保存配置。本次仅本地交付，不推送 GitHub、LSPosed 或官网。

## 相较 4.0.0 的更新

- 新增系统实际选用的折叠主光感及原生 FOV 融合输入路线，处理已确认的私有照度光感被标准类型检查拒绝，且 ABC 保留字段与实际注册 FOV 输入不同、暗光锁定配置无法应用的问题；原标准主光感与原生 / 移植辅助路线保留。
- 暗光监听绑定当前默认逻辑屏的控制器、管理器和主辅光感；可读时跟踪物理屏身份与面板配置。折叠切换或绑定变化时清除旧采样和确认计时，释放本模块持有的锁定，重新判断。
- 每次监听使用独立代际，丢弃旧管理器 / 旧屏幕遗留的队列回调；不扫描所有光感、不混用其他屏幕候选、不把原始 / 工厂 / 流式数据当作照度。
- 统一运行检查与自检使用的光感适配器；兼容页展示实际主光感路线与来源，状态读取不再改动监听或自动亮度模式。

## 范围与安装

这是针对诊断样本的兼容测试包。已完成主机模型与私有固件静态核对，尚未完成目标折叠机安装、折叠 / 展开实测或功耗测试；不表示所有折叠设备、所有副屏功能均已适配。控制目标仍是系统默认逻辑屏，系统将内外物理屏映射为默认屏时跟随其对象；独立副屏和外接屏不新增控制权。未知私有光感及不完整的 FOV 接口 / 换算仅暂停相关暗光功能，曲线等独立功能按原路径工作。

覆盖安装后重启加载系统 Hook。常规设置保存应用无需重启；保留配置 schema、记忆保持开关及用户曲线。原 4.0.0 公开文件保持原样。验证明细见 [折叠主光感复审](../reviews/review-4.0.0-beta01.md)。
