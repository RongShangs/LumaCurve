# HyperLux 4.4.5 Beta 06

1. 新增“应用独立亮度”：旧暂停名单、逐应用独立值、最多三个共享分组统一管理，应用只能归属一个名单。
2. 名单改为灰色数量入口，进入带搜索、图标和开关的二级页面，可批选系统识别的视频或游戏应用。
3. 独立值只记明确的普通手动调节；窗口、付款码及HDR等临时提亮不进入记忆。退出恢复此前模式，支持可选跨锁屏/跨重启保留。
4. 临时亮度隔离恢复单开关；系统原生已隔离时准确显示，停用此前窗口共享。旧暂停名单及所有保存设置继续保留。

## 详细更新

累计基线为上一个已公开正式版 **4.4.5 /44500**；本版 **4.4.5-beta06 /44506**、构建 **beta-4.4.5-06** 仅本地交付，保留全部历史产物，不含发布或设备操作。

### Beta 06

- 明确按输入来源区分：播放窗口显示期间，用户通过控制中心的普通手动调节仍可记忆；窗口自身调用帧和实际输出不采集。保留HDR、极端值、同用户/物理屏及延迟回调保护。
- Beta04、Beta05中间本地构建及全部旧产物保留。

### Beta 05

- 勾选其他名单或分组已有应用时先弹窗，确认后新处开启、旧处自动关闭，取消保持原样，无需返回旧名单手动找。
- 视频/游戏批选涉及迁移时统一确认；已确认迁移后再关闭新处，旧处也保持关闭。旋转保留已确认记录，未确认弹窗离页取消。
- 补齐Root工具中的分组配置内嵌类型，直接用实际选入的工具类归档执行分组配置回归，避免仅在完整APP类路径下通过。
- Beta04首次本地构建及更早产物保留，不覆盖文件。

### Beta 04

- 设置入口“暂停自动亮度名单”合并为“应用独立亮度”，介绍及保留期限下面有暂停、独立和分组三个块。旧manual_brightness_apps原键接续，包含未安装条目；导入冲突配置明确报错，不静默丢弃名单。
- 暂停块保留原先可见性、多窗口和用户主动开启自动亮度的规则；独立值按主屏当前焦点使用，单独应用分别保存，同组应用共用。最多3组、全部名单合计64个应用；组可新增、重命名及删除，组ID稳定。
- 进入独立应用后使用固定框架比例，退出时恢复之前系统调节；原来手动则保持手动。原生窗口仍可临时提亮，但不记入独立值，不从窗口实际输出采集偏好，不需关闭临时亮度隔离。
- 仅观察原生手动调节入口，保护窗口覆盖、HDR、极端端点与普通范围，旧窗口同步隔离在独立接管期间继续保护全局偏好。原生温控和范围限制不绕过。
- 默认锁屏清空；显式选择后可保留锁屏和重启记忆，锁屏及桌面均不接管。持久化和查询有界异步执行，按设备基线、用户、物理屏和代次拒绝过期值。
- 灰色管理入口只显示数量，二级页面支持搜索、图标、名称、开关、选中计数、视频/游戏并排批选及按包名添加。其他名单归属可见，勾选即移动。分类来自本机元数据/专用游戏列表，混合影像列表不当作视频名单。
- 页面及入口统一名为“应用临时亮度隔离”，只保留隔离开关。已核验原生无同步路线显示系统已隔离，保存的模块选择不被改写；无法确认时明确等待接口。
- Beta03的窗口临时亮度共享停止执行并移除页面；旧字段留存，不自动迁移成独立应用或记忆值。

### 保留的 Beta 03 交互

- 手动记忆移除三个强度快捷预设；记忆开关被本次操作过，或详细参数展开时显示红字，其余参数和保存设置保留。

### 保留的 Beta 01 / 02 适配

- 折叠主屏完整/分区映射、同范围配对物理屏选择及恢复自动亮度的确认。
- 原生raw12、原签名、所有既有兼容路线和保存配置保留。未把主机或私有固件静态结果写成新包真机通过。
