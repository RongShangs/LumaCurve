# HyperLux 2.3.1-beta05：暗光锁定默认值

本地测试版，暂不推送或发布。继承 beta04 的暗光稳定修复；本轮仅调整锁定默认参数与预设，不改变锁定机制。

新配置的默认值以及“睡前保持”预设统一为：

- 暗光定时锁定开启。
- 进入照度 10 lux，主辅共同满足，持续 1 分钟。
- 退出照度 50 lux，任一侧达到并持续 1 秒后恢复自动亮度。

已有配置的明确开关与各项数值保留。早期不含暗光锁定开关的配置按原来的未启用处理，不因升级或导入自动开启。睡前保持预设仅修改锁定参数，不改主屏手动面板开关。

覆盖安装后重启。已有用户如需这套参数，点击“睡前保持”，再保存并应用。

实际控制器回归检查包括 59999/60000 ms 的进入边界、49.9/50 lux 的退出边界、999/1000 ms 的退出确认，以及主侧、辅侧分别触发退出和旧设置保留。完整构建与既有回归检查通过；尚需实机确认。
