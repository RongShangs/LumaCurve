# HyperLux 3.1.1 Beta 01

本地测试版，当前版本代码 **31104**，构建 `beta-3.1.1-beta01-coordinate`，沿用 legacy API 82。初始 Beta 01 为 31101，界面修订为 31102，legacy 回退包为 31103。以已发布的 3.1.1 / 31100 为基线，不推送 GitHub、LSPosed 或官网。

## 当前接口回退

按用户要求回退至 legacy API 82。交付 APK 仅保留 assets/xposed_init 入口和原有旧接口元数据，不包含 META-INF/xposed 现代入口声明或 io.github.libxposed 类型引用，不要求框架支持 API 102。默认构建不下载、不编译 API 102 依赖；研究代码独立归档，不影响当前加载。

关于页更新弹窗、节点映射、临时常亮、名单改名和新版选项弹窗全部保留。由现代入口切回 legacy 需重启一次，让驻留的旧引擎退出；仍为本地 Beta，不发布。

## 31102 界面修订与热更新实测（历史）

- “应用自动亮度名单”入口改为“暂停自动亮度名单”。
- 控制中心节点映射弹窗改为三张纵向选项卡，分别展示调节方式、效果说明和选中标记；确认后进入待保存状态，取消保留原设置。
- 真机已覆盖安装界面修订，无额外重启。官方 API 102 服务实际连接成功，分别向系统框架和系统界面提交热重载请求，两者均返回 FAILED、message=null；模块日志确认是旧引擎主动拒绝，系统钩子未替换。
- 本次仅界面与显示名称修订，沿用已有引擎协议。手机安装包为 31102，两个已注入进程仍运行 31101 引擎；界面更新立即可见，不应当作系统钩子热更新成功。临时诊断组件测试后已移除。

## 本次更新

1. 更新弹窗仅在“关于”页显示。启动、状态、设置和日志页不弹出；检查期间离开关于页也不会在其他页弹出。
2. 当前回退为 legacy API 82，沿用共用的曲线、记忆、场景和控制逻辑；此前 API 102 实验已移出产品源码。
3. 保留 Hook 注册与注销句柄管理，本版不支持热重载，更新系统钩子后仍需重启加载新引擎。
4. 主屏手动亮度设置新增“控制中心亮度条节点映射”，提供关闭、仅手动亮度、手动和自动亮度三种选择，默认关闭。
5. 节点弹窗新增“临时常亮 / 取消临时常亮”，保持当前亮屏会话，锁屏熄屏或停用模块后释放；不永久改写系统熄屏时间。

## 控制中心节点映射

本轮改为长期双向坐标映射：亮度条使用主屏真实节点比例作为刻度，用户拖动时反解为本机系统原本接收的亮度坐标；系统更新亮度时，将其报告的亮度换算为节点比例回显。不会因拖动关闭自动亮度，不取得 raw_panel 所有权，不额外启动控制中心节点守护进程。

- **关闭**：沿用系统亮度条。
- **仅手动亮度**：只在手动模式映射；自动模式沿用系统刻度。
- **手动和自动亮度**：两种模式均映射，自动亮度继续运行；拖动仍按原配置参与偏好学习、系统手动保持与保护判断。

独立读取本机显示配置的标准亮度转换函数，并在可用时读取 OEM V1 的逻辑亮度转换。标准 gamma 路径与 OEM V1 路径分别处理，不能将 V1 的逻辑目标当作标准亮度或直接节点。校准读取在后台执行，映射表缓存后只在配置变化时传递；拖动时不访问 SettingsProvider、不启动 Root、不写 sysfs。

读取主屏真实 max_brightness 和唯一节点身份，配置绑定构建、系统进程 PID、启动身份和开机次数。未知接口、缺少对应映射、映射无法单调反解或配置代次失效时，保留系统亮度条。关闭映射不会改写自动亮度开关或用户曲线。系统框架与系统界面作用域都需启用。

完整节点刻度不代表完整范围都能输出。常规范围、条件高亮范围和未开放的节点范围不是固定三段，会受本机映射、强光、温度、电量及 HBM 时间预算影响；本功能不解锁系统未开放的范围。OEM V1 的拖动反解基于本机基础逻辑目标映射，后续环境修正、手动记忆和系统保护仍可能使最终输出不同于所选位置；后续系统亮度通知会更新回显。这里不是恒定输出或直接节点保持功能。

## API 与安装

当前 APK 只声明 legacy 入口，最低 Xposed API 82；控制业务仍经模块自己的适配层共用一套实现，不额外依赖现代 API。兼容性依旧逐功能按实际设备接口检查。

沿用原包名和签名，覆盖安装可保留配置。**切换入口仍需重启**，控制中心映射需要“系统界面 / com.android.systemui”作用域。当前不具备免重启替换系统钩子的能力。

## 验证范围

主机回归分别检查 legacy 适配、双向坐标换算、原始自动模式与回调参数保持、旧请求不再取得节点所有权、配置代次、更新弹窗跨页边界及临时常亮生命周期。31104 本轮只做本地实现，尚未安装或真机验证；历史节点保持测试不计入新映射的验证证据。实际设备框架和控制中心接口已进行只读核对；安装、重启与操作验证情况以本版复审及 build-info.json 为准，不能用固件核对代替真机功能验证。

本轮完整本地构建回归通过。仍需真机核对显示配置中的归一化背光值与驱动节点读回的比例关系、实际控制中心动画和自动模式偏好学习；不以系统配置换算代替物理读回证据。
