# HyperLux 4.5.0-beta21

本地测试版，基于Beta20，未公开发布。

## 本版简略更新

- 临时亮度隔离规则改为“窗口状态 / 处理方式”表格，缩短文字说明。
- 表格共用圆角外框，协调列宽、换行、分隔线和深色模式配色。

## 自4.5.0正式版以来的累计简略更新

- Beta01：增加放宽画面限亮后的可选高亮上限曲线。
- Beta02—03：重做高亮设置与拖动曲线，增加短时主动激发测试。
- Beta10：恢复Beta03独立曲线布局，合并曲线研究另存弃用分支。
- Beta11—12：增加物理nit目标曲线，四点拖动、图例和恢复默认，保留旧配置及路线。
- Beta13—18：完善高亮测试参数、主次页面、状态信息及操作反馈。
- Beta19：增加最小/挂起窗口处理，修复小窗最大化后独立亮度恢复及自动亮度回调误判。
- Beta20：临时亮度同步隔离与小窗状态处理合并为一个开关，继承旧选择并分别判断兼容能力。

## 本版详细更新

单开关页面用两列表格展示正常小窗、最小浮窗/贴边挂起、窗口关闭/完全后台、控制中心主动调整四种规则。保留简短的视频/付款码示例，删除原长段规则说明。表格只有一个圆角外框，四角裁剪；内部细线分隔，两列按比例分配，文字自动换行，浅深色使用现有主题色。

Beta20统一开关、旧设置继承、独立能力检查和Beta19小窗最大化修复均保持不变。主机布局检查不替代Android实际显示验证。
