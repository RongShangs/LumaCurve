# HyperLux 4.1.0 Beta 01

累计基线：上一个已公开正式版 **4.1.0 / 41000（release-4.1.0-r1）**。本文件只包含该正式版之后的 Beta 01 更新，不重复计算已经公开的功能。

## Beta 01 · 41001

1. 为部分移植系统新增分段系数曲线适配，针对努比亚 Z80 Ultra 用户提供的分析包，修复缺少旧锚点字段导致整条曲线无法接入的问题。
2. 从本机实际曲线读取照度坐标、亮度基准及逻辑上限，保留原生亮度转换、手动学习、高照度缩放及下游保护；保留全部已有锚点、传统映射、机型适配与用户设置。
3. 兼容页面新增独立曲线路线，区分已接入的基础曲线 / 原生学习与尚未核实的高级记忆能力。这条新路线暂不开放跨自动亮度开关、锁屏、重启及永久保持，也暂不提供记忆转基础；原设置保留，其他设备原有能力不受影响。

## 详细说明

- 原路线依赖 `mLuxSeg0` 等锚点字段及 `defaultAtLux`。本包实际使用9项分段系数、22项拟合状态与 `getDefaultLogicalBrt`，因此同时补充后端选择和钩子安装，不能只忽略缺字段或误切到传统物理映射。
- 旧式锚点标记优先；存在任何旧式标记但结构不完整时拒绝回退。只有新结构的字段、实例方法、容器形状及真实原生消费者都通过检查时才采用新路线，不凭机型或系统版本放行。
- 照度上限由实际系数和本机逻辑亮度边界反解，不能把上限照度、逻辑 nit、面板 nit 或物理节点混为一谈。系数写入前验证原生消费者；发生错误时回滚数组身份、内容与状态，系统或其他所有者替换基准时停止覆盖。
- 原生拟合中的虚拟参考点没有已验证的完整导出 / 回放契约，不能冒充旧路线的用户锚点。页面只报告可验证的最近一次原生手动输入；高级保持与记忆转基础按功能独立暂停，不删除原始配置。此路线暂要求相邻基础亮度严格递增，避免零斜率进入原生拟合。
