# HyperLux 4.5.0-beta18

本地测试版，基于Beta17，未公开发布。

## 本版简略更新

- 增强状态增加独立底色和两列参数排版，展示当前方式、实际亮度、最高亮度限制、系统门槛及剩余时间。
- 详细设置入口统一为浅蓝底、蓝色文字，保留整块点击反馈。
- 去掉最高亮度限制入口下的灰色说明。

## 自4.5.0正式版以来的累计简略更新

- Beta01：增加放宽画面限亮后的可选高亮上限曲线。
- Beta02—03：重做高亮设置与拖动曲线，增加短时主动激发测试。
- Beta10：恢复Beta03独立曲线布局，合并曲线研究另存弃用分支。
- Beta11—12：增加独立物理nit目标曲线，固定四点拖动、图例与确认恢复，保留旧配置及路线。
- Beta13—14：完善测试参数、模式范围标示、卡片和操作行布局。
- Beta15：拆出详细设置页，测试固定两行四格并显示剩余时长，统一整块点击反馈。
- Beta16—17：主页保留预设、状态、详情入口和独立手动阳光屏；四排方式移入详情；统一触发门槛、最高亮度限制名称及搜索。

## 本版详细更新

增强状态保留在主页高亮增强容器内，以浅色底包住状态说明和三行两列参数。当前方式和最高亮度限制来自已应用运行快照，不把未保存草稿当实际状态。当前亮度沿用可靠设备nit换算或系统比例，直接节点接管、缺失或过期时不冒充有效值；快照超过15秒、时间戳来自未来或引擎非活动时显示未知。增强/冷却余量复用原刷新，HBM预算仅显示原生估值，不新增采样或轮询。

详细设置入口使用浅蓝色点击容器和蓝字，最高亮度限制去掉入口底部说明。保留Beta17布局、旧配置、原签名、普通/高亮曲线、学习与节点恢复；未修改运行控制器和测试后端。此前详情见对应Beta文件。主机回归不替代Android真机触摸、动画和像素验收。
