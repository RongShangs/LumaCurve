# HyperLux 3.0.1 Beta 02

2026-10-13。版本名 3.0.1-beta02，版本代码 30007，构建 beta-3.0.1-02。沿用原包名与原签名，可保留配置覆盖正式版或 Beta 01；安装后重启一次。

1. 手动记忆页新增“将当前绿色曲线保存为基础曲线”。保存当前实际曲线形状作为蓝色基础，清除已经吸收的手动点，之后继续学习；支持恢复设备原始基础曲线。需要先保存已有草稿，操作前有确认。
2. 暗光锁定新增“手动调整后继续锁定”。关闭时延续原行为：调整后保持手动模式；开启时保持新亮度，继续监听光感，达到退出阈值后恢复自动亮度。
3. “运行与工具”新增应用自动亮度名单。支持按名称搜索、选择启动器应用、按包名添加及移除。名单应用在主屏前台时暂停自动亮度，退出后恢复；原本已是手动模式不接管，用户主动开启自动亮度后暂不再接管。
4. 名单功能使用 system_server 的前台事件，复用显示线程，合并 150 毫秒内的切换，不增加进程、服务、无障碍监听或轮询。息屏停止订阅；启用/恢复订阅时仅查询一次当前应用。没有做本版实际耗电测量。
5. 保留 Beta 01 的设备实际 SDR/OPR 接口适配，新旧路径互斥，画面限亮和 nit 上限共用保护判断。

所有新选项默认保持原行为：手动调整后继续锁定关闭，应用名单为空，基础曲线未保存时沿用原控制逻辑。现有 HDR、防窥、温控、电池、主屏手动面板和原有光感采样设置保留。

验证包括保存曲线/回滚/蓝绿图形、传统曲线与配置导入导出、手动调整后退出、应用切换、用户主动开启自动、息屏、其他用户/显示器以及手动面板交接。完整结果以随包 build-info.json 为准。

本轮没有连接到 ADB 设备，没有本版真机验证或功耗测量。仅本地打包，不推送或部署；官网、GitHub、LSPosed 正式版保持 3.0.1 / 30005。后续正式版版本代码应高于 30007。
