# HyperLux 4.5.0 Beta 02

- 重做户外高亮页：增强方式逐级选择，曲线、系统目标和节点高亮集中管理。
- 曲线支持直接拖动，实时查看照度和亮度；点按空白加点、选择后删除，无需逐点输入数值。
- 增强过程也可拖动调整；确认时间、增强时长、冷却与 HBM 等参数在曲线区域直接查看和调整。
- 保留旧设置和原有能力；控制方式冲突时先确认，取消保持原选择，接口暂不可用时保留已保存设置。

本地测试版4.5.0-beta02 /45002、beta-4.5.0-02，未公开发布或操作手机。增强过程纵轴为增强幅度百分比；放宽后高亮曲线纵轴为物理nit上限，两者不混用。主动强光模拟测试未实现；现有高亮条件查看不模拟光感，不代表仪器测得的屏幕峰值。
