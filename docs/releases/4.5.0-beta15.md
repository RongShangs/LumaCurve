# HyperLux 4.5.0-beta15

本地高亮设置分层测试版，未公开发布。

- 增强方式恢复四排；主页只保留测试、预设、增强方式和详细设置入口。
- 曲线、准入、时长/冷却、最终上限、增强状态与手动阳光屏统一移入二级页，共用草稿；返回保留编辑，支持原保存与搜索入口。
- 激发测试固定两行四格，删除真实照度显示，将最长时长改为剩余时长，测试时不新增参数格。
- 统一整行/整块的点击与反馈，去掉内部文字按钮的重复动画；最终上限的说明区也可整块点击。
- 移除主页旧的状态和全局诊断入口，增强状态集中显示在二级页。

原签名、保存协议、旧路线和最新随包感谢名单保留。进入详细设置按原离开页面规则结束测试，采集结果保留；亮度算法、曲线、学习、节点恢复和测试后端未改。主机验证不代替Android真机触摸与像素验收。
