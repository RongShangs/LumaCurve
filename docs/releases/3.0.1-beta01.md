# HyperLux 3.0.1 Beta 01

2026-10-13。构建 beta-3.0.1-01，版本代码 30006，版本名 3.0.1-beta01。沿用正式版包名与原签名，可以保留配置覆盖 3.0.1 / 30005；安装后重启一次加载新版系统 Hook。

## 更新内容

1. 户外画面限亮按设备实际接口识别新旧 OPR 实现，不按机型名或系统版本号判断。
2. 增加旧 OPR 实现的兼容路径，覆盖本次 K90 Pro Max 官改包缺少防窥接口的情况。
3. nit 户外亮度上限复用相同的接口判断，避免两项功能各自选择不同适配路径。
4. 新旧路径互斥；完整防窥接口优先，异常时不降级，不重复安装 Hook。未知或不完整实现保留系统控制。
5. 分析包新增 SDR 兼容路径和接口失败原因，便于区分机型、官改固件与接口差异。

仅在原有强光、自动亮度、主屏和输出归属条件满足时放宽普通 OPR。HDR、防窥、手动模式、温控、电池、省电及 HBM 等系统保护继续有效。没有改动光感采样频率、背屏和用户预设。

## 验证范围

现有户外生产代码模型回归 512 项，新旧接口与冲突回归 1272 项；本次两份用户固件核对 43 项，既有三份固件样本回归保留。完整构建结果见随包 build-info.json。

本轮 ADB 未连接设备，没有本版真机验证，也没有仪器亮度测量。官改包报告的 OS4.0.0.25 不能代表所有官方 .25 固件；支持与否取决于实际接口。Beta 不保证达到指定峰值亮度。

仅本地打包；GitHub、LSPosed 和官网继续保留 3.0.1 正式版 30005。本 Beta 的更新检查不将相同语义版本的旧正式版作为新版本提示。

未来正式更新应采用高于 30006 的版本代码。直接覆盖回 30005 可能受 Android 降级限制，请保留配置备份；必要时可先在 LSPosed 停用模块并重启，或使用随包恢复脚本。
