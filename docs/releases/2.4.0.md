# HyperLux 2.4.0 LSP

This release updates the `lsp-v2.4.0` branch with a reverse-engineered Dock revision while keeping the existing HyperOS 4 brightness and Hook paths intact.

## UI changes

- The existing system light/dark mode handling remains the source of truth for the app palette, status/navigation bars, dialogs, settings, and dock tint.
- Settings now supports choosing and clearing a local background image. Images are decoded off the UI thread, capped before display, and reloaded with the current system theme.
- The bottom navigation follows the supplied KernelSU release-build reverse engineering: a 64dp, 4dp-radius rounded rectangle with 28dp horizontal margins, `8dp + navigation inset` bottom spacing (28dp without an inset), 4dp blur, 24dp panel refraction, and a 40dp expanded source capture. The selected 4dp-radius indicator tracks horizontal scrubbing and applies a cached 10dp/8dp press lens with low-strength color dispersion over the processed dock surface.
- API 33+ uses the vendored MIT-licensed AGSL refraction shaders and cached `RenderNode` layers; API 31–32 use the cached system blur/saturation path without refraction; older API levels fall back to a high-contrast translucent surface. The current APK has minSdk 34, so the lower-API branches are source compatibility paths and are not reachable in this APK.
- Two low-cost directional highlight gradients flow across the Dock border. Cards, settings surfaces, log panels, dialogs, inputs, and pipeline nodes remain ordinary themed surfaces without liquid-glass effects.
- Bloom phase advances on normal press, drag, and indicator spring frames; the Dock does not schedule idle redraws. The outer shadow uses the platform hardware outline instead of a software blur layer.
- The dock accepts horizontal swipes to move between the four existing pages. The surrounding layout and page organization are unchanged.
- Predictive/back navigation commits a settings sub-page transition atomically to avoid the old-page flash.
- The About page displays 2.4, adds the branch WeChat ID `x080814OwO` and its note, and adds the branch author `凌乱的风&` with the supplied avatar.

## Build and verification

- Version name: `2.4.0`; version code: `24000`; build identity: `release-2.4.0-lsp.2`.
- Host regression suites, Java compilation, ARM64 native compilation, resource packaging, APK signing, and native asset extraction passed locally.
- OEM firmware fixture checks were skipped because the local reverse-engineered dumps are not present in this checkout; host and runtime-policy validation remained enabled.
- No HyperOS 4 device was connected for this build. Liquid-glass rendering, frame pacing, Hook behavior, and long-running brightness behavior still require device validation.
- The APK is signed with the local branch signing key. A device carrying an APK signed by a different key must uninstall the old package before installing this build.

The liquid-glass adapter is a small source-level port of [AndroidLiquidGlassView](https://github.com/QmDeve/AndroidLiquidGlassView); its MIT notice and source URL are retained in `GlassDockView.java`, `liquidglass_effect.agsl`, and `liquidglass_indicator.agsl`. The reverse-engineered Gaussian, downsample, and bloom shader bodies were not available in the supplied prompt, so the implementation uses Android's cached RenderEffect blur plus Canvas directional gradients instead of claiming to reproduce those unknown kernels.
