# HyperLux 4.5.0-beta11

基于Beta10的本地测试版，未公开发布。

- “户外高亮”改为“高亮增强”：预设置顶，增强方式标题常显，只展开选中项。
- 新增可拖动的独立高亮目标曲线，按本机换算nit调整目标和上限，既可提亮也可降低原生高亮目标；普通曲线与记忆保持独立。
- 高亮准入统一呈现增强进入/退出与系统HBM门槛，确认、时长、冷却改为紧凑设置行；设备未启用计时预算时隐藏无效预算控件。
- 修复部分系统因非public照度通知接口未被识别而无法使用主动激发测试的问题，保留20秒结束、离开页面停止及系统保护。
- 保留旧节点、旧高亮上限曲线和全部已保存数值，转换为目标曲线前确认。

主机回归和私有固件静态核对不代替真机验证；实际激发、曲线过渡、Android触摸和深浅色像素效果仍待回访。保留原签名及最新随包感谢名单，不含发布、安装或设备操作。
