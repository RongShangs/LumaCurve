# HyperLux 4.0.2 Beta 02

累计基线：上一个已公开正式版 **4.0.2 / 40200**。包含 Beta 01—02，按引入版本分别列出。

## Beta 02 · 40202

1. 修复 Beta 01 折叠屏手动亮度面板持续等待确认、内外屏均无法调节的问题。新增 StablePhysical 地址兼容，保留原 Physical 路径。
2. 直接读取系统提供的物理端口，不根据稳定物理 ID 推导端口；按当前主屏、实际成对背光和点亮状态确认节点。
3. 完善兼容诊断中的地址类型与失败原因，补充实际默认屏取址入口、新旧地址共存和错误接口回归。

## Beta 01 · 40201

1. 新增按本机折叠布局、当前默认物理屏和实际点亮端口选择内外屏节点的路径，读取所选节点的真实上限。
2. 切换内外屏时结束旧接管、释放旧节点权限，不将上一块屏幕的目标值应用到另一块屏幕；切屏后重新滑动接管。
3. 保留普通直屏、LED 背光和其他既有路径及用户设置；多屏同时点亮、切屏中或证据不完整时等待，保留原有亮屏、用户与节点身份保护。

`4.0.2-beta02 / 40202 / beta-4.0.2-beta02`，原签名覆盖安装后需重启。本次仅本地测试包，未替换正式版。尚待目标折叠机验证内外屏效果。
