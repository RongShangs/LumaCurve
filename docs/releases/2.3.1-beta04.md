# HyperLux 2.3.1-beta04：暗光稳定补修

本地测试版，暂不推送或发布。包名与签名保持，可覆盖安装；随后重启手机，让系统进程加载新版 Hook。新版核心标识为 beta-2.3.1-dark04。

本轮只继续修改暗光稳定，暗光定时锁定保持 beta03 的实现。

## 修正

- 明确识别系统夜间驾驶状态，补上该场景此前绕过暗光保护的路径；主光感、辅助光感和小幅升亮使用暗光确认规则。
- 保留系统场景亮度下限和夜间额外确认时间，按系统保留的传感器历史限制延时，避免不断等不到确认。
- 继承 beta03 阈值访问修复，使受保护的 HBM 接口不再让暗光阈值静默失效。
- 状态新增最近实际应用的暗光阈值，配合计数和错误字段核对，不只显示开关开启。

没有修改原始光感数值、亮度曲线、手动记忆或暗光锁定，没有加入自动亮度写节点进程。

## 测试

保留你当前设置（暗光稳定与暗光阈值开启、变亮最小照度差 30 lux）。在同一暗光环境使用，检查 0～6 lux 小波动是否还触发升亮，再移到明显更亮的环境检查正常响应。手动拖动系统亮度条应仍可生效。

详细状态中 build 应为 beta-2.3.1-dark04，low_light_threshold_adjustments 应有实际调整记录，threshold_error 应为空；亮度分支中的当前触发门槛应反映新阈值，而不是仍只为 2 lux。若仍变亮，请记录发生时间并导出这版分析包。
