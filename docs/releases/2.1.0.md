# HyperLux 2.1.0 · 正式版

版本代码 **21000**，构建 **release-2.1.0**。适用于 HyperOS 4，需要 Root 和 LSPosed。包名、图标、签名、官网与仓库保持不变，可覆盖此前正式版和 2.1.0 测试版。

## 本次更新

- 新增默认关闭的户外高亮增强：确认持续强光后提高自动亮度目标，保留系统平滑过渡；进入与退出照度、确认时间、增强强度、单次时长与冷却均可调整。手动选择、锁屏、HDR、特殊场景及温度条件不满足时沿用系统。
- 按设备能力开放自动 HBM 触发与时间预算、高亮范围调整。HBM 预算最多为原值两倍且不超过原窗口，保留使用历史；零预算不视为无限时间。范围仍受设备映射、系统限亮和驱动保护约束，不保证所有设备都能额外提亮。
- 最低照度节点支持拖动或输入数值上移，设置暗处基础曲线的亮度下限；支持预设、保存与恢复。可调范围受相邻节点和本机边界约束，手动选择与保护策略继续优先。
- 设置改为六组独立子页面，参数全部直接显示，未开启自定义或接口不支持时置灰。引擎控制右侧和子页面保存区增加红色未保存提示，切换页面保留修改。
- 新增配置导出与导入：JSON 保存到设备存储根目录，可包含未保存修改。导入先预览，旧文件缺少的新选项补默认值，范围变化调整并提示，不兼容功能关闭；曲线基准不同时保留本机曲线和亮度下限，拒绝不认识的文件格式。
- 首页明确区分手动亮度、采样暂停与等待有效照度，不把初始化零值或失效阈值当作当前读数。手动模式下，开启系统自动亮度后才能读取实时光感；应用不另行订阅光感。
- 新增页签与子页面的淡入淡出和短距离移动过渡，兼容系统关闭动画；快速切换和进入后台时清理旧动画。分类入口更紧凑，箭头居中，子页面使用无底框返回箭头。
- 亮度分支和分析包补充户外目标、可用范围、HBM 条件、实际输出与最近限亮阶段，区分请求被接受和屏幕实际提亮。

## 安装与升级

1. 覆盖安装 `HyperLux-2.1.0.apk`，保持 LSPosed 启用及「系统框架 / Android 系统」作用域。
2. **更新 Hook 后重启一次**，进入 APP 核对 Root、注入和曲线连接。
3. 保持系统自动亮度开启。新的户外选项默认关闭，先检查现有曲线；按需逐项启用并保存应用。

此前同签名正式版和本地测试版均可覆盖升级。设置的版本代码提升为 21000，应用更新检测继续使用原 GitHub 仓库。配置导入只修改待保存的设置，确认后仍需点击「保存并应用」。

本地构建通过 **3495 项主机逻辑与回调模型检查**、**78 项高级参数固件检查**、**59 项传统映射固件检查**、**153 项户外固件检查**及原有消费链核对，并校验签名、归档、源码与下载包一致性。户外检查来自三份 HyperOS 4 固件资料，属于静态分析，不等于所有固件的实机验证。新增户外效果、动画与布局仍需实际使用反馈。

完整包 `LumaCurve-2.1.0.zip` 包含 APK、源码与恢复工具，**不是 KSU 模块**。出现异常可在设置中「停用并恢复」，或取消 LSPosed 勾选并重启。应用仍复用系统亮度链路，没有额外常驻亮度输出进程；资源增量以实测为准。
