# HyperLux 4.6.1 正式版

## 4.6.1 简略更新

1. 精简日志和部分亮度设置页的说明。
2. 主屏原生守护在首选目录不可用时尝试经过相同校验的备用目录。(修复用户启用了ADB Root后无法使用主屏手动亮度的问题）
3. 适配部分固件退出播放窗口后仍保留临时亮度的情况。
4. 尝试修复部分移植系统缺少流式距离输入时的无效等待。

## 4.6.0 累计简略更新

1. 重做高亮增强设置，支持四点拖动目标曲线、恢复默认及最高亮度限制。
2. 新增短时激发测试，显示剩余时间、当前亮度和测试最高亮度。
3. 完善应用临时亮度隔离：正常小窗保留临时亮度，最小浮窗或贴边挂起后交回系统。
4. 修复应用从小窗最大化后未恢复独立亮度的问题。
5. 精简多个设置页面的冗余说明，优化布局、状态展示及深色模式。

## 详细更新

### 4.6.1

- 日志连接正常时显示三个状态卡和兼容路线入口。设置页精简重复说明，保留暗光门槛、温控条件和背光节点单位。
- 首选 Root 工作目录不可用时，原生守护使用通过相同检查的备用目录。权限恢复和日志跟随实际目录，户外守护读取时也核验目录。
- 窗口亮度隔离覆盖部分固件的原生亮度保持路径。播放页仍可临时调亮，退出后将亮度调节交回系统。
- 只在系统明确缺少流式距离输入、且自动亮度所需条件满足时处理无效等待，保留有效输入及旧路线。

### 4.6.0

高亮增强加入四点目标曲线和短时激发测试。临时亮度隔离区分正常小窗和挂起窗口，并修复小窗最大化后独立亮度的恢复。见 [4.6.0 更新日志](4.6.0.md)。
