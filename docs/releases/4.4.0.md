# HyperLux 4.4.0

1. 新增应用亮度隔离：应用内临时调亮或调暗，退出后恢复系统调节，控制中心主动调整仍按原有设置处理。
2. 扩大基础曲线可调整范围，按设备实际亮度上下限编辑；节点统一按 0—100% 显示和输入。
3. 修复分区亮度条普通区间调亮受限、绿色记忆曲线提前到顶，以及松手后滑块位置回落的问题。
4. 修复进入场景设置时误弹作用域提醒，保留已有设置和兼容路线。
5. 修复更新弹窗底部按钮遮挡，改善短屏、横屏和大字体下的显示。

## 详细更新

相较上一个公开正式版 **4.3.3 / 43300**，累计合入 **4.3.3 Beta 01—09** 的改进，以下按最终行为整理。

### 应用亮度隔离

- 设置 → 运行与工具新增“应用亮度隔离”，位于“暂停自动亮度名单”上方，默认关闭，保存并应用后生效。
- 应用内临时调亮或调暗（非控制中心操作），例如视频播放、付款码展示，退出应用后恢复系统原有的亮度调节；不会固定回写进入前的同一个亮度数值。
- 控制中心主动调整仍按原有设置处理；与暂停自动亮度名单独立，不因此关闭自动亮度，不另设视频应用白名单。
- 根据本机实际接口独立自检：完整窗口来源与同步结构才进行限定隔离；原生窗口覆盖没有目标同步链路时沿用系统处理。接口不匹配仅影响本项，不重置保存的开关。
- 仅拦截已确认来自当前主屏应用窗口的临时亮度同步及拖动缓存，保留原生计算和保护。HDR、暗光锁定、节点保持、其他用户、次屏及息屏等情况下继续遵循原控制规则。
- 不全局拦截系统设置，不承诺阻止应用直接写系统设置；不新增进程、传感器采样、轮询或强制过渡动画。详细兼容路线可查看实际采用的路线、窗口状态与隔离记录。

### 基础曲线编辑

- 删除额外的固定倍率范围，亮色和深色基础曲线均按本机实际上下限编辑；调整一个节点时，按需联动相邻节点以保持曲线顺序。
- 所有节点统一按图像纵轴的0—100%显示、拖动和数值输入，包含最低点与最高点，避免相对原始节点倍率被误认为屏幕亮度百分比。
- 显示单位调整不改变内部存储格式；已保存曲线、预设、导入配置及手动记忆继续保留。仅打开弹窗再原样确认不会改动曲线。
- 实际最小亮度、系统消费者的单调性要求、温控和硬件限制继续有效，不把编辑范围扩大当作解除屏幕保护。

### 控制中心分区亮度条

- 修正部分V1兼容路线的普通区间输入换算，下方75%覆盖完整原生普通输入范围，保留原生手动记忆，避免调亮和绿色记忆曲线提前封顶。
- 修正普通区拖动与松手后的延迟回显不互逆：真实反馈通过同一本机标定反解，再映射回下方75%；直接刷新、动画比较与合成回显使用一致坐标。
- 不固定滑块在上次拖动位置；系统实际改变输出时仍正常跟随。支持不同滑块最大值及非零起点。
- gamma兼容路线、旧映射模式、上方25%节点增强、两次上滑确认、返回普通区行为、自动高亮回显和已确认节点保持继续保留；原生节点程序不变。

### 提示与使用体验

- 场景设置与主屏手动亮度页面正确区分，仅在控制中心映射需要时提醒系统界面作用域，异步结果离页后不再弹错位置。
- 更新弹窗四个操作按钮采用独立布局和实际可用高度，日志区滚动，底部操作区完整保留，改善短屏、横屏、大字体布局。
- 应用亮度隔离的说明、首页摘要、搜索与英文文案改用更直观的使用场景；关于页补充代码贡献的作者主页与参考项目跳转。

### 兼容与升级

- 继续按实际接口、对象与标定区分兼容路线，不以机型或系统大版本直接放行；新增隔离能力独立管理，不覆盖既有适配。
- 原包名、原签名和全部已保存设置保留；新增功能默认关闭。安装或覆盖更新后需重启设备加载新版系统钩子，后续参数修改只需保存并应用。
- 完成完整本地主线回归、已有私有固件消费者静态核对及签名/源码一致性检查；本轮未新增真机亮度、Android像素或功耗实测，不将模型通过表述为全部设备实测。
