# HyperLux 4.3.0 Beta 01

累计基线：上一个已公开正式版 **4.3.0 / 43000**。本包为 **4.3.0-beta01 / 43001**，只在本地交付，未发布。

## 简要更新

1. 改善直接调节屏幕节点时的亮度显示，避免继续显示过时数值。
2. 新增切换深浅色模式后保持手动记忆；独立基础曲线可选择清除、共用或分别记忆。
3. 独立记忆随当前系统主题显示，各自可保存为基础曲线或清除记忆。
4. 基础曲线最右端节点支持向下调整，深色模式同样支持。

## Beta 01 · 43001 详细更新

- 状态页复用已有刷新链路，只读当前主屏节点；优先读取驱动实际值，可读取时使用同一主屏的亮度节点读回。
- 本机背光到 nit 标定有效、物理屏身份一致且节点位于标定范围内时显示设备换算值。无法可靠换算时，节点接管显示“当前屏幕节点 / 实际上限”，不把目标值或过时框架值当作实际 nit，也不外推标定范围。正常状态保留原框架读数回退。
- 标定复用已有后台校准线程，不新增光感采样、轮询服务或常驻进程。换屏、无权限或缺少标定只影响读数，不影响原亮度控制路线。
- “保持记忆”新增“切换深浅色模式后保持”，缺省关闭；开启独立基础曲线后禁用此开关，由曲线页三个策略接管，原保存选择保留。
- 独立基础曲线的主题记忆策略缺省仍为清除，保持原版本行为。共用策略将当前有效偏好交接到另一基础曲线；独立策略隔离两种主题、当前用户和设备基础曲线。
- 两份独立记忆优先在本次系统运行内保存；只有启用“重启后保持”或“永久保持”才写入两份独立存档。不擅自开启跨锁屏、跨自动亮度开关或跨重启保持。
- 手动记忆面板按当前系统主题展示。独立深色模式显示“深色模式曲线与记忆”，保存绿色曲线只更新深色基础曲线；另一主题同理。
- 将该面板原“恢复设备原始基础曲线”替换为“清除手动记忆”，不再提供重复的保持记忆区清除按钮。独立策略仅清当前主题的手动节点和存档，保留基础曲线及另一主题。恢复系统默认仍撤销所有定制并清理全部记忆。
- 基础曲线四个点均可编辑：最高照度点可下调、不可超过该基础的原始值，保持单调约束和设备范围；Refactor、传统完整映射、保存的完整基础曲线使用同一约束，不写死设备节点。
- 旧式分段系数曲线同步开放最高点下调，使用实际系数数组的末端计算域约束形成终端平台，避免更强光下重新外推；该路线保留相邻点严格递增要求。
- 保留旧兼容路线、签名、安装标识及全部已保存设置。感谢名单不属于版本变更内容。
