# HyperLux 3.2.0

正式版标识：3.2.0 / 32000，release-3.2.0。按用户要求仅本地打包，未发布、未推送或部署，线上仍为 3.1.1 / 31100。包名与原签名连续，legacy API 82，覆盖安装后需重启加载系统钩子。

## 本地修订 R2 / 32002

保持 3.2.0 版本名，内部修订 release-3.2.0-r2；仅本地交付，不发布或部署 APK，原包保留。

- 新增传统场景确认路径：完整旧布局没有夜间驾驶接口时，独立使用本机主辅确认与阈值；保留步行、遮挡、HDR 等保护，原夜间驾驶路径保留。
- 新增旧式 HBM 原生能力方法，以及传统物理曲线户外目标入口；实际接口决定路径，新式入口继续优先，不对不完整的新式接口盲目回退。
- HBM 照度、原生计时、温控、电量、HDR、手动接管和会话时长继续有效。没有对应能力的场景仍明确不可用，不强制启用 OEM 停用的策略。
- 关于页与用户须知说明适配 HyperOS 3 / 4，具体功能以本机自检为准。须知确认键与设置存储保持不变。
- 自检页打开不再自动重检；应用首次进入运行时检查，普通前台恢复只刷新状态。保留引擎启动、配置变更、有限就绪补检与主动重检。
- 显示固定检测时刻和触发来源，避免每次进入都显示“0 秒前”；条目收紧，全部证据和备用路线仍可展开，返回位置保留。
- 感谢名单新增 Zayne；名单单独同步服务器，APK 未发布。

新增路径已对照小米 13 / OS3.0.303.0 / Android 16 分析包的系统接口与调用顺序。本地回归不代表目标设备实测，不保证所有 OS3 固件提供相同能力。

## 本地修订 R1 / 32001

仍显示 3.2.0 正式版，内部修订 release-3.2.0-r1；versionCode 递增为 32001，旧 32000 交付物保留，未推送或部署。

- 功能自检移至日志“运行与兼容”，改为独立页面，设置页旧入口移除。
- 每项显示实际采用的兼容路线与依据，展开可查看其他已实现路线、条件和未采用原因；区分未选中、不适用和信息未确认。
- 覆盖曲线、记忆、原生 / 移植辅助光感、HBM 计时 / 零计时、新旧 SDR 接口、窗口判断回退与节点来源；基于实际数据，不按机型名称猜测。
- 只解释现有快照，不轮流切换或试调亮度。保留旧配置、检测失败时的结果提示，以及页面滚动和展开状态；展开内容按需创建。
- 原兼容路径保留；控制中心映射入口继续隐藏。目标设备尚未实测。

## 相较上个正式版 3.1.1

- 更新提醒仅在关于页弹出。
- 主屏节点手动亮度面板新增“临时常亮”，本次锁屏后结束，不修改原熄屏时长。
- 针对移植系统缺失的辅助光感槽，增加严格能力检查后的原生补位；原生已正常绑定时继续优先使用原路径，不新增额外采样。
- 修复特定 Refactor 系统重建或交接曲线后偏离用户蓝色基础设置的问题；仅修复已验证的系统重建形式，保留 OEM 手动点与未知算法。
- 手动记忆统一为“保持记忆”分类，可分别选择跨自动亮度开关、锁屏和重启保持，并可使用永久保持。保留旧设置的实际行为，新选项默认关闭；主动清除、新调整和用户 / 基准隔离仍优先。
- HBM 新增零时间预算适配：三个计时参数均为零且实际接口完整时，只调整照度门槛，不制造计时预算。原有带预算设备继续使用原路径；无效或未知布局继续局部暂停。
- 普通距离策略被系统关闭时，自检显示“系统未启用”，并在本机流式距离能力存在时说明可用入口；不强制启动传感器，不把普通与流式条件混用。
- 控制中心节点映射入口暂时隐藏，底层实现和已保存的选择保留。分析包中的非单调转换尚未修复，本版不承诺该功能可用。
- “新增适配保留旧兼容、覆盖升级保留用户设置”写入根目录项目最高要求。能力暂缺的运行期配置使用副本，不回写清空原始偏好。

## 验证边界

实际包确认原生普通距离策略关闭、流式路径可用，HBM 门槛 4475 lux、三个计时字段全零。已完成对应本地字节码核对、原路径与新路径模型验证，未在该设备覆盖安装验证。正式版名称代表交付渠道，不将主机测试等同于真机兼容和功耗长测。

完整构建和签名核对以本版复审及本地最终审计为准。无新增常驻进程、额外传感器注册或轮询；户外增强仍受会话时长、温控、电量、HDR 与原生输出条件限制。
