# HyperLux 3.0.2 Beta 02

2026-10-15 · 版本代码 30011 · 本地测试包，未推送。

在 Beta 01 的独立功能自检与兼容改进基础上修复：

1. “跨重启保留手动记忆”和“亮屏后恢复已保存偏好”默认关闭。旧配置缺少字段、引擎初始化和 APP 尚未取得配置时均不会自动开启。
2. 修复引擎接受同曲线基准的 OTA 配置、界面却因固件标识变化将其丢弃的不一致。沿用已核验的设置；配置不能沿用时，记忆界面读取当前实际生效状态，避免回到错误的默认值。
3. 暗光锁定开关改为“手动调整后退出锁定”，默认关闭。默认手动调整后保持新亮度并继续锁定，任一光感持续满足退出条件后恢复自动亮度；打开开关后，手动调整即结束锁定并保持手动模式。
4. 新的退出锁定选项独立保存，旧版“继续锁定”字段不再反向开启退出行为。旧配置迁移采用新的默认继续策略；希望保留旧的退出行为，需要打开新开关并保存。

缺省值修复不覆盖已经明确保存为开启的跨重启/亮屏恢复设置。如果旧版本已将错误的开启值写入配置，需要将这两项关闭并“保存并应用”一次。关闭不删除存档，也不清空当前会话的手动调整；需要回到基础曲线时，可使用“清除手动记忆”。

沿用原包名和签名，可覆盖 3.0.2 正式版及 Beta 01，安装后重启一次。版本仍为 3.0.2 系列，仅增加 Beta 标识和覆盖安装代码。

已执行记忆、迁移、OTA、暗光控制专项回归，完整构建与归档审计结果见包内 build-info.json。本版没有 ADB 真机验证，不把主机服务模拟测试当作设备效果验证。
