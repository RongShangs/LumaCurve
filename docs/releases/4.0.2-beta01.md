# HyperLux 4.0.2 Beta 01

累计基线：上一个已公开正式版 **4.0.2 / 40200**。以下为正式版之后至 Beta 01 的更新。

## Beta 01 · 40201

1. 修复折叠屏主屏手动亮度面板仅能调节内屏的问题。根据本机折叠布局、当前默认物理屏和实际点亮的显示端口选择内屏或外屏节点，读取所选节点的真实上限。
2. 切换内外屏时结束旧接管，释放旧节点权限，不将上一块屏幕的目标值应用到另一块屏幕；切屏后重新滑动接管。
3. 保留普通直屏、LED 背光与其他既有路径，保留用户设置。不解除息屏、自动亮度、用户和节点身份保护；多屏同时点亮、切屏过程中或证据不完整时等待。

版本 `4.0.2-beta01 / 40201 / beta-4.0.2-beta01`，原包名与原签名。仅本地测试包，不替换公开 4.0.2。覆盖安装后需重启；本轮未对目标折叠机进行 Android 实测，需用户验证外屏面板和折叠切换。
