# HyperLux 2.3.1 LSP.2

This release builds the `lsp-v2.3.1` branch as an installable APK. It includes the branch fixes documented in `release/RELEASE_NOTES.md` and keeps the app version at 2.3.1. The build identity is `release-2.3.1-lsp.2`, with version code 23107.

## Installation

The original signing keystore was not available on the build machine. This APK is signed with a newly generated key and cannot update an existing installation signed with the previous key. Uninstall the existing `top.rongshangs.lumacurve` app before installing this APK; uninstalling may remove its local settings and data. The new signing key is not included in the release assets.

Enable the app in LSPosed for the system framework and reboot to load the Hook. Confirm the runtime build reads `release-2.3.1-lsp.2`. The recovery script is included in the complete ZIP bundle.

## Verification

The build runs Java and ARM64 native compilation, host regression tests, APK signature and alignment checks, and packaged native-asset validation. Proprietary device firmware fixtures are not present on the build machine and are skipped. No Android device was connected, so HyperOS 4 Hook behavior, rendering, and long-term brightness stability are not claimed as device-verified.
