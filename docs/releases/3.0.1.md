# HyperLux 3.0.1 正式版

构建 `release-3.0.1`，版本代码 `30004`，2026-10-12。以 3.0.0 正式版为基线，沿用原包名和签名，可保留配置覆盖安装，也可覆盖本地 3.0.1 内部测试版。当前仅完成本地正式打包，尚未推送、发布或部署。

## 本次更新

1. 户外高亮新增独立的 **nit 亮度上限**，可直接输入 2000 nit 等目标，0 表示不限制。仅在户外增强生效的自动 SDR 链路中生效；即使系统原目标高于上限，也限制在换算后的上限以内。使用本机显示配置的 nit 映射，支持非线性换算；不支持可靠换算的固件不开放此设置。
2. 原“增强强度”改称“额外增强幅度”，明确它只增加目标、不代表最高输出上限。切换户外预设保留用户填写的上限，配置导入导出也保留此项；旧配置默认不限制。不兼容设备导入时取消上限并提示。
3. 设置页“运行与工具”最底部新增 **隐藏桌面图标**，立即生效，无需保存或重启。只切换独立桌面入口；隐藏后仍可从 LSPosed 的模块设置打开 HyperLux，并在同一位置恢复图标。
4. 首次进入设置页显示 **用户需知**，说明配置备份用途、按个人感受调整曲线与记忆、户外和暗光功能的使用方式。正文可滚动，确定按钮倒计时 10 秒后可用；点击确定前不自动关闭，也不能通过返回键或点击外部关闭。确认记录只保存在本机，不随亮度配置导入导出。

温控、电量、省电和 HBM 时间等保护继续执行，可将输出进一步降到上限以下。手动亮度、HDR / 杜比、隐私画面和不属于本模块的输出路径沿用系统；户外增强未生效时不应用新增上限。未调整传感器采样率，未改动背屏控制。

## 安装与验证

覆盖安装后重启一次，加载新版系统钩子；原配置保留。隐藏桌面图标和确认用户需知属于本机界面偏好，不需要 Root 命令，也不需要点击“保存并应用”。

本版完成主机回归、既有三份 HyperOS 4 固件静态核对、原签名及归档一致性检查；具体结果见 [3.0.1 审阅记录](../review-3.0.1.md)及包内 `build-info.json`。未取得本版真机验证结果，nit 依系统映射计算，不是外部仪器测量值。

K90PM / K80PM 偶发解锁卡死的根因仍未确认，本版不宣称已解决。3.0.0 及此前改进见 [完整更新日志](3.0.0.md)。
