# HyperLux 4.1.1 Beta 01

累计基线：上一个已公开正式版 **4.1.1 / 41100（release-4.1.1）**。本包仅包含该正式版之后的Beta 01修复，不重复计算已发布的功能。

## Beta 01 · 41101

1. 户外节点增强增加短暂写入错误重试，减少一次写入异常后功能持续失效的情况。
2. 修复旧失败记录持续阻止恢复的问题，主动“保存并应用”后可重新检查并尝试恢复，无需清空设置。
3. 完善节点增强诊断记录，区分系统改写、短暂竞争及实际写入错误，保留原有兼容和全部已保存设置。

## 详细说明

- 仅对可恢复I/O错误增加有界重试：包括首次最多3次，间隔80、160毫秒；等待时释放手动控制锁，不变成持续循环写入，不增加光感采样。
- 每次按最初计算目标时的许可重新检查实际节点、上限、系统进程、目标及物理屏身份。系统更改请求、手动接管、熄屏或保护收回许可时停止，不把系统主动降低亮度当作写入错误反复顶回去。
- 区分写入已被接受但读回稍有延迟，与写入未成功后系统自行改成相同值的情况；后者不能冒认为本模块持有控制权。
- 保留v1比例、v2原始节点及折叠屏v3物理身份路径。切屏等待、节点唯一性、HDR、温控、电量、系统接管及实际HBM允许条件继续有效。恢复原亮度只做一次比较写入，不延迟覆盖新所有者。
- 权限错误或真正失败耗尽次数时仍停止。普通状态查询不反复启动守护；用户主动保存且配置获引擎确认后，经过原有完整支持、节点和屏幕校验再尝试恢复，失败仍保留证据与原有配置回滚。
- 健康记录增加尝试次数、错误码和失败阶段，退出清理不会覆盖原始错误，便于后续分析。

## 安装与验证

**4.1.1-beta01 / 41101 / beta-4.1.1-beta01**。保留原包名、原签名及已保存设置。本地Beta，不发布到官网、GitHub或LSPosed。

覆盖安装后需重启加载新版钩子和守护。此前已遇到节点写入失败的用户，重启后到设置点击一次**保存并应用**，让新版重新校验旧失败状态并尝试恢复；不需要重置配置。实际高亮仍需满足强光与系统保护条件。
