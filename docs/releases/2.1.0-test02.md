## 暗处曲线下限

原倍率方案在设备原始 0 lux 曲线点为零时，乘任何倍率仍为零；部分原始点很低时也只允许极小上移。本次增加独立的 `curve_floor_nit` 参数，以设备自身曲线坐标保存，不使用背光原始代码。

最左侧节点现在可拖动或点击输入本机曲线范围的百分比。该百分比不是控制中心亮度条，也不是固定物理 nit；Refactor 与传统物理映射各自保持本来的坐标。最低点不超过下一点，若需要更高先上调下一点；第二点的编辑下限同步考虑最低点，避免曲线倒挂。

Refactor 修改真实默认字段和锚点，清除手动记忆时保留下限；传统映射调整原曲线低端完整节点，不删节点、不改高照度末端、不丢原配置元数据。保存预设同时记录下限和设备基准；选择系统默认预设清除附加下限。旧配置没有下限字段时按零处理，原曲线保持不变。

这是基础曲线下限，不是在最终输出之后强制锁亮。系统手动选择、温控、电池与驱动仍可降低实际亮度。

## 二级菜单

引擎控制保留在设置顶部；设置主页按功能提供六个入口：亮度曲线与偏好、户外高亮、环境变化与确认、亮度过渡、场景与温控、运行状态与界面。

点击进入对应设置，顶部提供返回设置。系统返回键先回到设置目录，再退出 APP。各组使用同一份草稿，组间切换不重新创建表单、不自动应用、不丢弃未保存的修改；通过顶部保存统一提交。

## 导出与跨版本导入

引擎控制提供「导出配置」「导入配置」，不再复制配置到剪贴板。

导出当前设置（包含草稿和界面偏好）为带格式版本的 JSON，保存到 `/sdcard/HyperLux-config-时间-随机后缀.json`。文件在设备存储根目录，不含 Root 授权、用户标识、系统进程编号或可重放的锚点重置命令。

导入通过系统文件选择器读取 JSON，最多 32 KiB，先做完整校验并展示迁移提示。确认后载入草稿，需点击「保存并应用」才更改引擎；界面刷新和日志自动滚动属于本地偏好，导入确认后更新。

兼容策略：

- 当前文件格式 `hyperlux_config_v2` / schema 2；兼容此前 `hyperlux_config_v1` 复制格式，以及 APP 旧版本 schema 1 的运行配置。旧 KSU 模块不是相同配置结构，不能直接导入。
- 不按 APP 版本号或旧固件指纹直接拒绝所有设置。旧版缺失新选项时采用当前默认值，新增强默认关闭。
- 当前可调范围变化时，调整已知数值范围并列出提示；错误类型、非整数时间、无效曲线和未知文件格式拒绝，避免只导入一半。
- 读取当前系统能力，将不支持的控制选项关闭并说明。其他受支持的设置可继续使用。
- 曲线以路径和基准标识匹配。基准不同保留本机曲线、倍率与亮度下限，只迁移其他已知设置，并明确提示；不把旧设备的 native nit 原样灌入新设备。
- 忽略未知设置项并提示数量，拒绝不认识的文件格式版本。新版本导出的文件不保证能被任意旧 APP 正确读取。
- 不重放旧 revision、用户 serial、重置命令或旧进程状态。保存时 Root 桥接始终生成本机当前固件、曲线基准和新提交标识，沿用原来的校验与失败回滚。

配置校验在临时对象上进行，取消、解析失败或文件过大不修改原设置。导入有未保存草稿时提示将被替换。
