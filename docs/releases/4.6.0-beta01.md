# HyperLux 4.6.0-beta01

本地尝试修复版，累计基线为已公开的4.6.0正式版，未公开发布。

## 简略更新

- 尝试修复部分移植系统因缺少流式距离传感器而持续等待，导致实际曲线不显示、自动亮度响应异常的问题。
- 保留有效传感器和AON确认，新增修正计数供分析包核对，不替换厂商传感器接口。

## 详细更新

仅当旧式场景接口完整、模块配置生效、当前用户主屏亮屏且自动光感有效，同时原生流式传感器对象为空、状态为未注册、传感器管理器确认原生类型不存在时，临时阻止不可完成的距离确认。已有等待判断仅移除缺失距离输入的贡献，AON和未知结果保留。调用结束或异常后恢复临时字段，不改用户配置、持久等待标志和原生输出保护，不按机型放行，不注册或代用中兴传感器。

以努比亚Z70 Ultra移植HyperOS 4分析样本核对；主机回归与私有固件静态核验不等于真机已修复。需覆盖安装并重启后回访曲线、自动明暗响应和分析包修正计数。
