# HyperLux 2.3.1

版本代码 **23106**，构建 **release-2.3.1**。Root + LSPosed，支持 HyperOS 4；沿用包名、图标、签名和现有需求。

## 本版调整

- 修复暗光锁定注册成功但未收到匹配回调的问题：复用系统显示控制器的 SensorManager，以传感器类型和硬件 handle 识别同一感光器。
- 修复受保护 HBM 数据访问失败导致暗光阈值未应用的问题；明确识别的夜间驾驶场景继续执行暗光保护，同时保留原生额外确认、亮度下限及其他场景保护。诊断增加阈值错误和最近计算结果。
- 新配置及“睡前保持”默认开启暗光锁定：**主辅均 ≤10 lux 持续 1 分钟进入；任一侧 ≥50 lux 持续 1 秒恢复自动**。已有显式设置保留，早期未配置开关的用户继续保持未启用；选择预设后保存才应用。
- 主屏手动面板有界发现主屏背光节点，排除副屏和非显示节点；歧义拒绝接管。Java 与原生守护分别验证路径、范围和身份，权限恢复记录绑定当前开机与节点。
- 修复保存确认返回时覆盖等待期间新改草稿的问题，保留未保存提示，用户可继续保存新修改。
- 修复暗光锁定转手动接管失败后遗失原自动模式所有权的问题；接管确认丢失时按会话回滚，不停止其他新会话。
- 手动守护使用单调时钟每 2 秒更新健康记录，超过 5 秒未更新时系统取消接管并停止隔离输出，避免异常退出后的旧记录长期被采信。自动亮度路径不启用守护，也不增加传感器订阅。

## 安装与恢复

覆盖安装 `HyperLux-2.3.1.apk` 后**重启手机**，让系统进程加载新版 Hook。LSPosed 作用域选择系统框架；详细读数应显示 `runtime.build=release-2.3.1`。版本代码高于 beta05，可覆盖同签名正式版与 beta 版，保留已有设置。

异常时先用手动面板“恢复自动”或 APP“停用并恢复”；也可在 LSPosed 取消启用并重启。完整 ZIP 解压后，在同目录 Root 终端执行：

```sh
sh ./restore_refactor_hook_android.sh
```

完整 ZIP 是 APK、源码与恢复工具合集，不是 KSU 模块。

## 验证范围

构建执行真实 Java / ARM64 C 编译、现有主机回归、已有私有固件接口静态核对、APK 签名与对齐、最终 APK 原生资产校验。新增回归覆盖保存时继续编辑、暗光锁定转手动失败、确认丢失后回滚、健康记录过期与错误会话。

本版没有连接 Android 设备进行实际 Hook、界面渲染或长期暗光测试。此前用户已确认定时锁定正常；暗光异常升亮的改进仍需本版实机反馈。主机回归和静态核对不能证明所有固件兼容，也不能保证消除所有亮度波动。

正式产物包含 APK、对应源码及恢复工具；官网与 GitHub 正式 Release 提供相同版本下载。网站部署包需将全部内容放入站点根目录。
