# HyperLux 4.4.0 Beta 01

1. 修复重启后控制中心亮度条映射需打开APP或重新开关才能生效的问题。
2. 系统界面作用域提醒仅在修改相关映射设置时按需出现，减少重复提示。
3. 功能自检与分析包补充映射开机恢复状态，便于排查启动异常。

## 详细更新

累计基线为上一个公开正式版 **4.4.0 / 44000**。本地Beta序号01，versionCode **44001**，构建 `beta-4.4.0-beta01`。不替换或发布现有正式版。

### Beta 01

- 开机解锁后，已保存开启的映射通过系统一次性任务重新连接本次开机的亮度引擎及节点监听，不再仅依赖APP打开时的inspect/apply连接。
- 原配置、当前系统进程、开机代次、用户、标定及节点身份仍逐项核验；接口暂未就绪时最多四次等待，Root拒绝或不可用时停止并保留原因。不增加APP常驻服务，不恢复上次亮度目标或旧操作。
- 页面打开、无关设置保存、重复选择相同模式不自动弹作用域提示；只在映射模式、分区上限、返回行为确实变化时按需提醒，同一设置草稿去重。
- 当前SystemUI注入已经核验时，单纯作用域数据库不可读不再误报缺失；已知未添加时仍保留引导，手动检查和重启按钮保留。
- 功能自检新增独立开机恢复路线及状态，分析包保存恢复结果和作用域/注入诊断，便于区分配置、系统注入与Root监听。
- 保留原有全部兼容路线、已保存设置、原签名和raw10节点程序；无需重新配置亮度。覆盖安装后需重启加载新版系统钩子。

完成本地主线回归及包内一致性检查；未将主机测试表述为受影响设备的实际重启或功耗验证。官网、GitHub和LSPosed公开版本保持4.4.0。
