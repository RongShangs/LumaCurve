# HyperLux 2.0.1 · 正式版

版本代码 **20001**，构建 **release-2.0.1-r1**。适配 HyperOS 4，需要 Root 与 LSPosed。

## 更新内容

- **亮度分支可视化**：状态页与日志页新增入口，查看当前主/辅助参考、实际曲线路径、场景与手动保持修正、短期记忆模型、夜间唤醒、HDR、阳光增强及输出策略。未观察到的阶段显示「未取得」，不把系统回退解释为用户关闭自动亮度。
- **可选暗光稳定**：设置 → 场景响应，默认关闭。已确认或候选照度 ≤50 lux 时，主、辅助路径变亮确认至少 3 秒、变暗至少 4 秒；保留更长的系统等待，采样窗口不足时不追加等待。保持传感器原值、系统滤波与过渡动画。
- **更完整的分析包**：新增 `pipeline-trace.json`、`output-trace.json` 和字段说明。分别保留最近 24 次曲线计算与 16 次不同输出记录，帮助追查照度波动、曲线目标和显示修正。记录有界、不持续写文件、不增加光感订阅。
- **曲线展示更准确**：没有观察到可绘制的当前曲线路径时，不冒用 Refactor 锚点；区分记忆模型存在、策略开启和实际目标被改写。
- **同步发行资料**：更新 README、官网首页更新日志、下载包、源码、恢复工具和版本信息。沿用原包名、图标、签名、官网与仓库。

## 安装与升级

1. 下载并安装 `HyperLux-2.0.1.apk`，可覆盖 2.0.0 与同签名测试版，保留设置和预设。
2. 在 LSPosed 保持 HyperLux 的「系统框架 / Android 系统」作用域，**更新后重启一次**，让系统加载新 Hook。
3. 如需减少短暂暗光波动，进入设置开启「暗光稳定」，点击「保存并应用」。后续调整无需重启。

`LumaCurve-2.0.1.zip` 是 APK、源码和恢复工具合集，**不是 KSU 模块刷入包**。

## 验证与已知范围

通过 611 项主机检查、提供固件的静态消费链核对，以及 APK 签名、对齐和归档完整性检查。新选项与分支界面尚待更多实机反馈。

暗光稳定只延长符合条件的变化确认，不参与手动调节、熄屏、HDR、闲置或驾驶模式。持续光感波动或其他系统策略仍可改变亮度，不承诺已解决所有“变暗再变亮”。本版没有新增独立亮度进程；实际内存与 CPU 增量尚待测量。

反馈时请附系统版本、复现时间和日志页导出的分析包。
