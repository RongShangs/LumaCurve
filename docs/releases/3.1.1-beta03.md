# HyperLux 3.1.1 Beta 03

本地测试版，版本代码 **31106**，构建 `beta-3.1.1-beta03-curve`。继承 Beta 02 / 31105，正式发布基线仍为 3.1.1 / 31100。本轮不推送 GitHub、LSPosed 或官网，原交付物保留。

## Beta 03 修订

1. 补齐移植系统辅助光感接入后的双光感能力缓存。原系统构造时未找到辅助传感器而缓存了单光感能力，后补传感器后现在同步缓存；运行中的主光感已有有效照度时，调用原生初始化恢复输入选择。辅助的滤波、确认时间、场景、手电筒和亮灭屏策略仍交给系统。
2. 普通蓝色基础曲线与保存下来的曲线统一覆盖系统重置、自动亮度状态切换和备用曲线切换，避免普通参数编辑漏掉重建保护。
3. 新增重建与手动调整后的基础核对。仅对可确认属于出厂基准或设备默认字段采样基准的回退进行校正，保留 OEM 手动点、次序、数量及记忆；未知算法不强行套用。已保存为基础的曲线保留完整节点形状。
4. 分析包新增真实默认字段读回、运行曲线基准核对结果、校正次数，以及双光感能力缓存状态，区分“已保存”“已接入”和“实际保持生效”。

不新增传感器监听、定时采样、守护进程或控制输出的另一套通道。基础核对在重置、手动调整与曲线切换事件后运行；保持传统物理曲线后端独立。原生辅助对象存在时不启用补位路径，停用或切换用户 / 对象时恢复本次持有的缓存与传感器选择。

## 相对正式 3.1.1 的累计更新

除本轮修订，继续包含：关于页专属更新弹窗；可选的手动 / 自动控制中心亮度条双向节点坐标映射及设置弹窗优化；主屏手动亮度的本次亮屏临时常亮；“暂停自动亮度名单”入口改名；移植系统缺失辅助光感的严格身份补位。详见 [Beta 02 累计日志](3.1.1-beta02.md)。

接口保持 legacy API 82，没有 API 102 入口或热更新。控制中心映射默认关闭，不改变自动亮度、手动记忆和保护策略，真实节点比例仍待设备验证。

## 安装与验证边界

原包名、原签名，覆盖安装保留配置；**安装后需重启一次加载新系统钩子**。此包尚未在目标努比亚移植设备运行，不能宣称硬件兼容问题已实测解决。用户回传的 Beta 02 包证明第二光感已取得真实采样，也暴露出输入选择和基础曲线保持问题；Beta 03 针对这些证据修订，并以主机回归、真实固件静态检查和最终交付核对验证。
