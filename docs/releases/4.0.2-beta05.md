# HyperLux 4.0.2 Beta 05

累计基线：上一个已公开正式版 **4.0.2 / 40200**。包含 Beta 01—05，按引入版本分别列出。

## Beta 05 · 40205

1. 设置首页新增“快速设置”，通过六页易懂的单选问题，分别选择响应速度、日常亮度、记忆保持、暗光体验、户外高亮和温控预设。
2. 首次进入设置页时邀请使用，可跳过；每题均可保留当前设置。支持上一步、修改及退出，最后汇总并统一保存应用，答题过程中不改变当前亮度。
3. 选项按本机实际支持情况展示；保存前刷新当前设备状态，能力变化或屏幕基准改变时阻止错误应用。旋转后保留答题进度，取消不覆盖原配置。
4. 温控预设补充系统默认、略微放宽、更多放宽、最大放宽；显示层调节仍保留严重过热退让。原有“适度放宽”保持43℃参数。
5. 保留无关分类、应用名单、记忆参数及已设置的 nit 上限和节点目标；快速设置的户外预设不会主动开启强制节点增强。没有新增常驻进程、传感器监听或后台轮询。

## Beta 04 · 40204

1. 新增旧框架独立自动亮度对象与亮度原因的兼容路线，修复 MIX Fold 3 等实际使用此结构的设备“强制达到节点上限”开关置灰；保留原生输出策略路线。
2. 为户外节点增强新增独立折叠屏绑定：读取当前物理主屏及真实节点上限，使用携带物理身份的租约；内外屏切换时清除旧接管，待新物理身份与点亮端口一致后重新确认。
3. 手动面板与户外节点增强分别核验；兼容页展示采用路线和未采用原因。双屏同亮、熄屏、临时 / 应用指定亮度、HDR、温控、电量及系统接管时继续退让。
4. 保留旧主屏节点、原有租约、全部已有适配和保存设置；增强目标及持续时间沿用户原有户外设置，不增加单独的增强时限。

## Beta 03 · 40203

1. 新增 MIX Fold 3 分析包所需的独立显示端口绑定路线，支持系统显示端口与背光节点编号不同的情况；双屏同亮、熄屏或切换未确认时保守等待。
2. 补充传统亮度过渡三参数入口，保留原四参数与 Refactor 路线，可分别调整普通自动变亮、变暗倍率，继续遵守原生保护和时长上限。
3. 改善兼容自检：区分接口不支持和系统未启用的距离遮挡、AON 等策略，补充节点绑定证据。
4. 加高更新日志阅读区；官网下载和 GitHub 下载并排放置，下载及忽略按钮固定在滚动区外，弹窗按当前窗口与安全边距限制高度。
5. “暗光稳定与锁定”页面调整为暗光稳定在上、暗光锁定在下。

## Beta 02 · 40202

1. 修复 Beta 01 持续等待确认、内外屏均无法调节的地址识别问题，新增 StablePhysical 兼容，保留原 Physical 路径。
2. 直接读取系统提供的物理端口，不根据稳定物理 ID 推导端口；结合当前主屏、成对背光和点亮状态确认节点。
3. 完善兼容诊断中的地址类型与失败原因，补充实际默认屏取址、新旧地址共存和错误接口回归。

## Beta 01 · 40201

1. 新增按本机折叠布局、当前默认物理屏和实际点亮端口选择内外屏节点的路径，读取所选节点的真实上限。
2. 切换内外屏时结束旧接管、释放旧节点权限，不将上一块屏幕的目标值应用到另一块屏幕；切屏后重新滑动接管。
3. 保留普通直屏、LED 背光和其他既有路径及用户设置；多屏同时点亮、切屏中或证据不完整时等待，保留原有亮屏、用户与节点身份保护。

`4.0.2-beta05 / 40205 / beta-4.0.2-beta05`。保留原包名、原签名和已保存设置；覆盖安装后需重启。仅本地 Beta 测试包，不替换官网、GitHub 或 LSPosed 正式版。快速设置已通过主机组合、界面生命周期及语言回归；此前新增路线已做私有固件静态核对与主机回归。Android 真机界面、目标折叠屏实际增强与连续切换、长测及功耗仍待验证。
