# HyperLux 3.0.2 正式版

2026-10-15 · 版本代码 30009 · 构建 release-3.0.2。

1. 扩展户外高亮兼容，根据设备实际接口选择新旧画面限亮适配路径；两条路径互斥，保留 HDR、防窥、温控与电池保护。不完整或未知接口继续沿用系统行为。
2. 手动记忆新增“将当前绿色曲线保存为基础曲线”，保留实际曲线形状，清除已吸收的记忆点后继续学习；支持恢复设备原始基础曲线。
3. 暗光锁定新增手动调整处理方案：保持原来的手动模式，或以新亮度继续稳定，达到退出阈值后恢复自动亮度。
4. “运行与工具”新增应用自动亮度名单：指定应用前台运行时暂停自动亮度，退出后恢复。仅恢复由模块接管的自动亮度，尊重用户主动切换。
5. 名单使用系统前台切换事件，复用已有显示线程，合并短时间内的切换；不新增常驻进程、服务或轮询，息屏停止订阅。

6. 复审修复应用名单首次查询与前台切换的竞态，避免旧查询覆盖新事件造成错误接管；修复息屏期间保存名单时重新订阅的问题。

新选项默认保留原有行为。沿用原包名与签名，可保留配置覆盖 3.0.1 正式版及两个 Beta；安装后重启一次。

本版发布至 GitHub、LSPosed 模块仓库与官网。回归结果与源码摘要见随包 build-info.json；固件静态核对和主机回归不代表本版真机测试，未做实际功耗测量。
