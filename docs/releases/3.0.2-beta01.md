# HyperLux 3.0.2 Beta 01

2026-10-15 · 版本代码 30010 · 本地测试包，未发布。

- 引擎启动及每次打开 APP 时，独立检查各项功能的实际接口和运行对象。系统版本只保留为诊断信息，不再按版本号阻止运行。
- 自检区分可用、等待就绪和接口不支持。启动时尚未就绪的功能在 1、5、15 秒有限复查，不增加持续轮询或光感采样。
- 某项可选功能不可用时，仅暂停该项；保留原配置，其他已兼容功能继续工作。服务恢复后重新核验，支持在“运行与工具 → 界面 → 功能自检”查看结果。
- 系统升级后，实际曲线基准和控制路径未变化时继续使用原设置，不再只因固件版本字符串变化而拒绝配置。基准确实变化时仍需重新应用设置。
- 新增默认关闭的节点高亮兼容选项，按实际框架输出、主屏节点、打开权限和画面限亮接口判定，不使用机型或固件版本白名单。仅在持续强光且框架自动亮度已到顶时尝试补充节点余量。
- 节点增强最长连续 30 秒，使用短期授权；系统重新写入节点后让出控制，不持续对抗。与主屏手动面板互斥。启用时会运行一个额外 Root 守护，关闭时不运行。
- 节点增强不提供未标定的实际 nit 值，不承诺达到 3500 nit；启用时状态页明确显示系统换算值。设置了 nit 上限时不启用该路径。

保持 3.0.2 版本系列，覆盖安装代码为 30010，沿用原包名和签名。安装后重启一次加载新版系统钩子。官网与公开 Release 仍为 3.0.2 正式版。

自检检查接口、数据与就绪状态，不通过试写亮度或切换自动模式验证效果。出现不兼容后暂停功能可能需要正常归还原有控制权。网络更新与在线名单在实际请求时检查网络连接。

已执行主机回归、私有固件静态核对、完整编译与归档审计；不等同于真机验证。当前没有连接的 ADB 设备，尚无本版亮度效果、解锁稳定性或功耗实测。
