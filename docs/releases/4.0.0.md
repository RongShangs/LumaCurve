# HyperLux 4.0.0

相较上一个公开版本 **3.1.1 / 31100** 的完整累计更新，包含这期间已完成的 Beta、本地修订与当前版本调整。

正式版 **4.0.0 / 40000**（release-4.0.0）。沿用原包名、签名和配置存储，覆盖安装后需重启加载新系统 Hook。

## 兼容性扩展与修复

1. **新增对部分机型 HyperOS 3 的支持。** 补充旧式场景确认、原生 HBM 能力判断及传统物理曲线的户外目标接口，保留已有 HyperOS 适配。关于页统一表述为“兼容 HyperOS”；各项功能根据本机实际接口独立判断。
2. **新增对部分移植系统的支持。** 针对已核对的第二光感身份，补充辅助光感缺失时的接入及双光感能力同步；已有原生辅助输入继续优先，不增加独立传感器监听或采样。已有移植包兼容案例，不代表所有移植方案均支持。
3. **修复部分系统蓝色基础曲线设置未持续生效的问题。** 在已确认的系统重置、自动亮度切换、手动调节和曲线交接后核对基础曲线，保留原生手动记忆与完整曲线形状；分析包增加实际读回及核对信息。
4. **扩展 HBM 和距离场景的兼容处理。** 新增原生零计时 HBM 的照度门槛适配，保留已有计时预算路径。普通距离策略被系统停用时准确说明，并区分本机可用的流式距离路径，不强制启用传感器。
5. **加强兼容隔离与异常恢复。** 修复部分 Hook 安装失败后的残留，以及可选观测异常影响核心功能安装的问题；完善实际接口归属校验。新增路径保留旧适配，覆盖更新保留全部已保存设置，个别功能不支持时不重置其他功能或用户偏好。

## 功能与界面

6. **手动记忆统一为“保持记忆”。** 可分别选择跨自动亮度开关、锁屏和重启保持，新增“永久保持”及对应预设。已有选择保留，新选项默认关闭；仅需要跨重启保持时才写入持久存档。
7. **功能自检改为独立页面。** 入口位于“日志 → 运行与兼容”，每项展示实际采用的兼容路线与依据，展开可看其他已实现路线及未采用原因。条目更紧凑，显示固定检测时间和检测来源，普通查看或前台恢复不重复检测。
8. **主屏手动亮度面板新增“临时常亮”。** 本次锁屏熄屏或停用后释放，不永久修改系统熄屏时间。
9. **更新弹窗只在关于页显示。** 检查期间离开关于页，也不会在其他界面弹出。应用名单入口统一改名为“暂停自动亮度名单”。
10. **新增首次欢迎与五页核心教程。** 欢迎页保留居中轻浮动 Logo、无标点欢迎语及唯一“下一步”，HyperLux 使用蓝色强调；首次依次浏览五页后开始使用。教程顶部只显示标题与页码，底部提供上一步、下一步及重看位置提示。重看从欢迎页开始，入口与刷新间隔使用独立卡片。
11. **移除旧设置须知与倒计时。** 保留已有确认和设置记录；新欢迎完成状态独立保存，桌面图标切换不清除记录。教程说明启用、基础曲线与手动记忆、暗光与户外、状态与兼容，以及 BUG / 不兼容时导出分析包反馈；不提供 Issues 外跳按钮。页面过渡及 Logo 动画遵循系统动画开关，后台、离页与销毁及时停止。
12. **完善兼容维护与官网说明。** 统一兼容目录、路线职责、回滚边界和回归规范；官网精简文案，突出持续扩展的兼容范围及已有移植包案例，下载资料与更新元数据准备同步。

## 本版范围与安装

- 控制中心亮度条节点映射入口暂时隐藏，不作为本版开放功能；保留其底层代码及旧配置。
- 继续使用 legacy Xposed API 82；API 102 研究不进入本版，系统 Hook 更新后仍需重启。日常修改参数只需保存并应用。
- 部分机型 HyperOS 3 和移植系统采用新增的实际接口路径，不保证所有固件或全部功能可用。各项功能以本机自检和实际运行结果为准；温控、电量、HDR 及下游保护继续生效。
- 本地主机回归、用户固件静态核对与历史设备反馈分别记录，不将其等同于本版所有目标设备已完成真机验证，不承诺特定 nit 或功耗改善。

本次按用户授权正式发布，同步 GitHub、LSPosed 与官网。安装包、对应源码、完整包、校验值及更新元数据以各渠道一致性核对为准。
