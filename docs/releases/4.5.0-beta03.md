# HyperLux 4.5.0-beta03

本地测试版，未公开发布。

- 户外预设置顶，增强方式、高亮控制直接展示当前选择。
- 户外曲线统一为照度与nit图，可拖动进入、退出、全强度、增强目标及统一上限；自定义高亮上限支持增删点与联动拖动，移除重复参数格。
- 加入主动激发测试：确认后短时模拟强光，记录设备输出，最多20秒；停止、离页、锁屏、手动调光或系统保护接管时恢复。
- 原确认时间、时长、冷却、HBM及节点、手动阳光屏设置保留，覆盖升级保留已保存参数。

图中nit与测试结果来自设备标定换算，不代表仪器实测峰值。缺少可靠标定时保留原设置，不用百分比冒充nit；测试可单独不可用。Android真机效果和功耗待回访。
