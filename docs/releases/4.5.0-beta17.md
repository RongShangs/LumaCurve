# HyperLux 4.5.0-beta17

本地测试版，基于本地Beta16，未公开发布。

## 本版简略更新

- 高亮准入改名为触发门槛；最终亮度上限改名为最高亮度限制，同步图例、弹窗和搜索名称。

- 高亮增强主页按预设、增强状态、详细设置排列在同一容器中。
- 四排增强方式移入详细设置；手动模式阳光屏移回主页独立卡片，展开按钮恢复标准全宽尺寸。
- 搜索与错误定位跟随实际页面，返回继续保留未保存设置。

## 自4.5.0正式版以来的累计简略更新

- Beta01：增加放宽画面限亮后的可选高亮上限曲线。
- Beta02—03：重做高亮设置与拖动曲线，增加短时主动激发测试。
- Beta10：恢复Beta03独立曲线布局，合并曲线研究另存弃用分支。
- Beta11—12：增加独立物理nit目标曲线，固定四点拖动、图例与确认恢复，保留旧配置及路线。
- Beta13—14：完善测试参数、模式范围标示、卡片和操作行布局。
- Beta15：拆出详细设置页，测试固定两行四格并显示剩余时长，统一整块点击反馈。

## 本版详细更新

将两项设置及曲线提示统一为触发门槛、最高亮度限制；旧搜索别名继续可用，保存键和运行机制不变。

激发测试仍独立置顶。高亮增强卡片内部先显示预设，再显示增强运行状态，最后是详细设置入口。四排增强方式位于二级页顶部，后续触发门槛、曲线、保护和最高亮度限制维持同一草稿。手动模式阳光屏作为主页独立卡片，使用与其他设置一致的全宽48dp展开按钮。搜索增强方式进入二级页，搜索手动阳光屏留在主页并展开对应内容。

保存协议、旧参数、原签名、曲线及学习逻辑、节点恢复与测试后端保持不变。此前各Beta详情见对应版本文件；主机回归不替代Android真机触摸、动画和像素验收。
