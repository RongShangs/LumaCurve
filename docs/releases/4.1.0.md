# HyperLux 4.1.0

1. 新增快速设置，回答6个简单问题，选择更符合自己习惯的亮度方案。
2. 完善小米 MIX Fold 3 等折叠屏的内外屏亮度调节和户外高亮适配。
3. 改善部分设备的亮度过渡设置，可分别调整变亮、变暗速度。
4. 优化更新日志弹窗，缩小占屏高度，修复底部按钮显示不完整；调整暗光设置顺序和兼容状态说明。
5. 补充温控预设，覆盖更新保留已有设置。

## 详细更新

相较上一个公开正式版 **4.0.2 / 40200**，累计包含期间 Beta 01—08 的改动，以下按最终功能整理。

### 快速设置

- 设置首页新增入口，通过响应速度、日常亮度、记忆保持、暗光体验、户外高亮、温控六个问题组合已有预设。首次进入设置页提供可跳过的邀请，手动点击入口也先确认再进入。
- 每题可以不选，直接下一步即保留该项；再次点击已选选项可取消。支持上一步和修改，最后用一张清单确认，答题或取消不会改动当前亮度。
- 问题、说明和选项左对齐，缩小卡片高度，长文字自然换行；底部提示居中，按钮保持等高。邀请简化为“试试快速设置”和一句说明，设置首页去掉“引擎控制”标题。
- 保存前复核最新设备状态及亮度基准。能力变化、切屏未确认或取消等待时不错误提交；旋转保留答题进度，不自动重复应用。未选择任何项目时直接结束，不提交配置。
- 保留未选择分类和无关设置，包括应用名单、记忆参数、已设置的 nit 上限与节点目标。户外快速预设不会开启强制节点增强；原已开启时，确认页会说明此次预设将关闭该项。

### 折叠屏与户外高亮

- 新增实际折叠布局、默认物理屏与点亮端口联合确认路径，完善 MIX Fold 3 等设备系统显示端口与背光节点编号不同的兼容。保留普通直屏、LED 背光和此前折叠屏路线。
- 主屏手动面板按当前屏幕读取真实节点及上限；切换内外屏时结束旧接管、释放旧节点权限，切屏后重新滑动接管，避免把另一块屏幕的目标直接套用。
- 补充 Physical / StablePhysical 地址识别，直接读取系统实际端口；双屏同亮、熄屏或证据不足时等待确认，不用型号、系统版本或固定编号推测节点。
- 为缺少原生输出策略入口、但具备独立自动亮度对象及可核验亮度原因的设备，新增独立户外兼容路径，改善“强制达到节点上限”不可用的情况。原策略路线优先且保留，不用备用路线掩盖原接口异常。
- 户外节点增强单独核验当前屏幕身份与节点上限，切屏后清除旧接管，待新屏幕确认再继续判断。沿用已有户外目标和持续时间，不额外增加时限；继续遵守温控、电量、HDR、临时/应用指定亮度及系统接管保护。
- 兼容页面区分手动面板与户外节点增强，展示采用路线、绑定依据及未采用原因；区分“接口不支持”与系统本身未启用距离遮挡、AON 等策略。

### 亮度过渡与设置体验

- 传统亮度过渡补充三参数入口，保留四参数入口及 Refactor 路线。可分别调整普通自动变亮、变暗倍率，保留系统保护和时长上限。
- 更新弹窗按当前安全可用高度的82%设置常规上限；官网下载与 GitHub 下载并排，下载、关闭与忽略版本两排按钮完整保留，仅日志滚动。移除日志320dp最小高度，短日志不再强占空间。小窗口与大字体优先为按钮保留空间，必要时在安全范围内适当增高。
- “暗光稳定与锁定”页面将暗光稳定放在暗光锁定上方。
- 温控预设补充系统默认、略微放宽、更多放宽、最大放宽。保留原“适度放宽”43℃参数及严重过热退让；仅选择相关预设时改变该项配置。

## 安装与验证说明

**4.1.0 / 41000 / release-4.1.0-r1**，本次为修复更新弹窗的同版本重新发布，版本名称和版本代码不变，保留原包名、签名及全部已保存设置。已安装首发4.1.0的用户请从官网或发布页手动下载覆盖安装；同版本不会再次弹出更新提醒。覆盖安装后需重启加载新版系统钩子；日常修改设置只需保存并应用。

本版通过主机自动检查，并使用已提供固件进行接口静态核对。新增折叠屏路径的实际增强、连续切换及长期功耗仍需各设备实际使用验证，不能将静态核对视为所有机型均已实测。未新增快速设置专用常驻进程、传感器监听或后台轮询。
