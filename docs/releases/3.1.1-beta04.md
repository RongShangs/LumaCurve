# HyperLux 3.1.1 Beta 04

本地测试版，版本代码 **31107**，构建 `beta-3.1.1-beta04-memory`。继承 Beta 03 / 31106 的全部修订；正式发布基线仍为 3.1.1 / 31100，不推送 GitHub、LSPosed 或官网。

## 本轮更新

手动记忆设置统一新增“保持记忆”分组：

- 切换自动亮度后保持：关闭自动亮度前保存偏好，重新开启后恢复完整偏好。
- 锁屏后保持：熄屏前保留，亮屏取得有效照度并等待稳定后恢复，可单独选择是否要求相近照度。
- 重启后保持：将偏好存档，在用户、曲线与设备基准匹配时恢复。
- 永久保持：同时覆盖上述三种范围，不因存档时间或照度变化而过期；保留手动学习，主动清除、基础曲线或用户变化仍优先。

提供“跟随系统”和“永久保持”预设。详细参数收在同一分组内；永久保持时，时间、照度及系统重判参数暂停生效，原值保留。关闭永久保持后可继续按范围自定义。

仅开启跨开关或锁屏保持时使用本次系统进程内存，不读取上次启动的存档，也不为此写入磁盘。选择重启保持才持久化。复用已有模式设置通知，区分实际开关与系统熄屏暂停；不增加采样、轮询或进程。恢复在原操作结束后排队执行，新手动调整取消待恢复任务。

新范围与永久保持默认关闭。旧版显式开启的重启、亮屏恢复继续保留；旧版总开关已关闭但遗留的亮屏选项不会在升级后自行生效。

Beta 03 的基础曲线保持、真实字段核对、移植系统辅助光感补位与能力缓存修订继续保留；此前控制中心映射、临时常亮、关于页更新和界面修订见 [Beta 03 日志](3.1.1-beta03.md)。接口保持 legacy API 82。

原包名、原签名，覆盖安装保留配置；安装后需重启加载新的系统钩子。本轮完成本地回归和打包，不将主机模型或固件静态核对当作目标设备实测。
