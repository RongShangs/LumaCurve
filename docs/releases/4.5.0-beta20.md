# HyperLux 4.5.0-beta20

本地测试版，基于Beta19，未公开发布。

## 本版简略更新

- 应用临时亮度隔离合并为一个开关：正常小窗保留临时亮度，最小浮窗或贴边挂起后交回系统，控制中心主动调整优先。
- 升级继承旧隔离设置，兼容能力分别判断，不丢失已保存选择。

## 自4.5.0正式版以来的累计简略更新

- Beta01：增加放宽画面限亮后的可选高亮上限曲线。
- Beta02—03：重做高亮设置与拖动曲线，增加短时主动激发测试。
- Beta10：恢复Beta03独立曲线布局，合并曲线研究另存弃用分支。
- Beta11—12：增加物理nit目标曲线，四点拖动、图例和恢复默认，保留旧配置及路线。
- Beta13—18：完善测试参数、主次页面、状态信息及操作反馈，统一触发门槛、最高亮度限制名称。
- Beta19：增加最小/挂起窗口处理，修复小窗最大化后独立亮度恢复及自动亮度回调误判。

## 本版详细更新

移除新增的独立小窗开关，将临时亮度偏好同步隔离与小窗状态处理合为一套：正常小窗保留请求；最小浮窗、贴边挂起时忽略该窗口请求；关闭或完全后台由系统撤销；控制中心的主动调整继续优先。不记忆或延续临时亮度。

旧两项选择中任一已开启，统一开关即继承为开启；新操作同时更新两项兼容字段。运行时先合并意图，再分别检查同步隔离和小窗能力，缺少一项不会拖停另一项，也不会越过其能力限制。原生自带同步隔离继续保留，页面明确说明，不能假称由模块关闭。

保留Beta19的窗口判断、独立亮度最大化恢复及用户操作优先逻辑，原配置、曲线、记忆、原签名与节点恢复保持兼容。主机验证不替代Android真机小窗与亮度效果确认。
