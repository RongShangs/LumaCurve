# HyperLux 2.0.4 · 正式版

版本代码 **20004**，构建 **release-2.0.4-r1**。需要 HyperOS 4、Root 和 LSPosed，包名、图标、官网和签名保持不变。

## 本次更新

- 按当前主屏实际使用的控制器识别曲线机制，支持小米 Refactor 和传统物理亮度映射；不再只接入 Refactor 路径，不按机型名单选择。
- 默认读取当前设备的本地曲线，四个编辑点初始均为 100%。传统映射保留完整原始节点，100% 时保持原曲线，编辑时围绕原节点形状调整，不将密集曲线压成四段直线。
- 状态图读取系统正在使用的曲线；设置预览使用本机基准与边界，保留柔和、系统默认、稍亮及命名预设。
- 传统映射继续保留系统应用分类修正、手动记忆及曲线元数据。按实际映射区分物理 nit、逻辑亮度与框架亮度坐标，避免跨机制套用。
- 权限与兼容状态区分 Root、LSPosed 已注入和曲线已连接，补充分析包注入记录及本机完整基准曲线；接口不支持时给出具体原因。
- 保存配置绑定固件、实际曲线机制及本机基准。切换用户或基准变化时停止旧覆盖并重新核对，应用失败回滚；停用恢复时避免覆盖系统后续下发的新曲线。

系统感光、双参考场景处理、平滑过渡、HDR、阳光屏和输出保护继续运行。没有新增独立亮度输出进程或光感订阅。高级参数按本机接口支持情况开放，默认关闭。

## 安装与升级

1. 覆盖安装 `HyperLux-2.0.4.apk`，LSPosed 保持启用，作用域选择「系统框架 / Android 系统」。
2. **更新 Hook 后重启一次**，进入 APP 检查 Root、注入和曲线连接状态。
3. 首次核对新机制时建议选择系统默认曲线、保持编辑点 100% 和高级选项关闭，保存并应用；随后再逐项调整。

以前保存的配置或编辑草稿与当前机制、固件或完整基准不一致时，需重新读取本机曲线并保存。手动记忆沿用系统锚点机制，不承诺所有记忆跨重启永久保存。

完整包 `LumaCurve-2.0.4.zip` 是 APK、源码与恢复工具合集，**不是 KSU 模块**。恢复可在设置中选择「停用并恢复」，或取消 LSPosed 勾选并重启。

## 验证范围

本地构建通过 3093 项逻辑与回调模型检查、78 项高级参数固件检查、59 项传统映射固件检查及原有消费链核对，并完成 APK 签名和归档校验。传统映射依据所提供 K90PM 固件核对接口；这些检查不等于该机型或所有 HyperOS 4 固件的实机验证。未知接口保留系统行为，系统更新后请重新检查连接。
