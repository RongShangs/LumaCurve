## 详细说明

### 紧凑底栏与固定状态页（Beta 07）

- 参考小米系统底栏调整为居中紧凑胶囊，常规字号下可见宽度最多288 dp、高约64 dp，图标与文字居中、各项等高；大字号支持文字换行和自然增高。为阴影预留自身绘制空间，避免被父容器裁掉。
- 手势提示区不重复叠加到底部间距；实际系统按键及屏幕切口仍避让。可见底部间距约18 dp，宽屏不横向铺满。
- 一个选中胶囊在四个入口间平移，240 ms减速；快速连续切换从当前位置继续，尺寸变化、暂停及系统关闭动画时直接归位。
- 仅设置与关于的真实下滚收起、真实上滚展开，抵达顶部或底部均不会单独触发弹出；取消回弹造成的反向误判。切页、返回和键盘避让仍按正常页面状态恢复。
- 状态页彻底移除滚动容器，完整保留光感输入、场景、曲线、保护状态与亮度；可用高度不足时等比适配，底栏保持自身正常尺寸。极短窗口下文字会随内容缩小，此取舍用于保持一屏完整显示。
- 日志兼容区域按“标题与说明 → Root访问/系统注入/亮度引擎 → 蓝底最近自检入口”重排；移除右上重复按钮，底部入口支持换行并居中。原始兼容证据和详细路线页面保持。
- 导航/搜索533项、平移指示器11项、状态几何5839项、日志证据189项主机检查，以及完整编译与旧回归继续执行。亮度引擎、Root桥、兼容路线、原生程序及采样率不变，全部已保存设置保留。
- 本轮未在Android真机完成像素排版与动画观感验证，主机几何和时序检查不等于任意机型实测。

### 悬浮导航、设置搜索与日志界面（Beta 06）

- 四个原入口保持不变，悬浮底栏采用胶囊与选中项圆角背景。设置首页、关于页仅在实际手势中根据方向收放；程序恢复滚动位置、日志自动滚动不会触发。到顶部、切页和返回时恢复显示。
- 选中背景与图标轻过渡，底栏收放可中途反向；离开时结束动画，旧结束回调不会再隐藏新状态。遵守系统减少动画设置。搜索只在原列表/结果列表切换时轻过渡，连续输入不反复淡入，减少闪烁。
- 状态栏与系统导航区域透明，按实际系统栏、横屏切口和键盘处理边距；滚动内容可经过浮栏后方，末尾仍可滚到浮栏上方。教程、快速设置和二级页面共用安全区，避免后方底栏露出或底部控件被遮挡。
- 设置搜索支持中文、英文、关键词和多词匹配，直接使用现有页面/功能入口；保留查询、原列表位置、二级返回位置和草稿。隐藏的控制中心节点映射入口不会通过搜索重新开放。隐藏桌面图标入口归入运行状态与界面子页，原偏好键不变。
- 日志顶部保留可读说明，按 Root 访问、系统注入、亮度引擎三个阶段展示；支持状态与生效状态分开。Root读取失败不推断系统模块已停止，不以一项暂不可用代替整机兼容结论。最近自检按APP/Root/引擎独立报告统计，详细路线仍在自检页面。
- 普通窗口展示完整兼容说明，短窗口或大字体允许卡片内部滚动。整理日志标题/自动滚动/刷新和底部等高工具行，日志继续占用剩余高度；实际导出后提示真实保存位置。
- 新增531项界面主机模型与189项日志证据模型，144份生产Java参与完整编译与回归。没有修改亮度引擎、兼容路线、原生节点程序或采样率，没有新增后台服务或传感器监听。
- 尚未完成本轮Android真机和像素级界面截图验证；主机布局、动画状态和安全区模型不能视为所有OEM、字体及极小多窗口的实际渲染保证。

### 稳定性与规范复审（Beta 05）

- 温控、触摸和场景的临时字段共用同一恢复机制。只恢复当前仍属于本次调用的值；系统或其他所有者在调用期间更新后不覆盖，保留异常与嵌套调用的正确顺序。
- Hook 撤销统一逆序处理，一项失败或日志异常不阻断其余清理。撤销真正失败的句柄保留再次尝试能力，避免提前记成已经完成；各兼容路线原探测条件、优先顺序与保护不变。
- 系统更新提示按运行状态和配置确认标识判断。原设置已核验且实际生效时不再弹“已恢复系统曲线”；尚未确认时引导查看功能自检，原设置保留。
- Root 自检补充选中目录当前不可用的原因和备用目录的实际检查结果。Root 受限分支同步清理对应旧读数并重绘；不创建目录或试写亮度来伪装自检通过。
- 构建前拒绝覆盖同名 APK / 源码 ZIP / 完整 ZIP / 版本日志；保留原签名校验。更新提醒元数据与状态页每次进入仅提醒一次的实际行为保持一致。
- 52项功能、21组兼容家族和137份生产Java完成维护检查；新增135项复审专项，Root专项186项，原有全部回归继续执行。没有新增传感器监听、周期任务或常驻进程，原生节点程序与采样率未改。
- 完整审阅结论、修正依据和仍需分阶段整理的技术债见 `docs/reviews/review-current-20261026.md`。主机故障注入不能证明其就是用户历史卡死的原因，本轮未做目标Android真机、功耗或长时验证。

### Root 能力与设置桥（Beta 04）

- LSPosed 成功注入后的曲线和场景逻辑仍在系统进程内运行，不要求 APP 持续持有 Root；APP 与引擎通信、完整诊断和直接节点控制分别受到实际权限约束。KSU 的“越狱模式”不等于权限必然不完整，不按 Root 品牌、型号或系统版本判定。
- 保留原有外部设置 Provider，读取探测失败时依次核验系统 `cmd settings`、`settings` 入口；这三种入口均受系统服务权限检查。只在读取探测时选择路线，不把写入失败换入口反复重放。写入仍须读回确认；启动和自检不试写亮度或配置。
- 启动阶段优先原私有目录，受限时仅使用身份和权限检查通过的独立 Root 私有目录。拒绝符号链接、不可信父目录和其他所有者；原生屏幕控制仍使用原目录，不移动守护、租约或用户设置。
- 引擎已确认的核心配置不因可选节点工具启动失败而回滚；返回具体警告。权限暂缺时允许原样保留此前有效、未改动的节点偏好，但不允许借此新启用或修改尚未核验的节点功能。原生节点、系统进程身份、物理屏、保护及控制权检查保留。
- 自检页面逐项展示身份 / Capabilities / SELinux 证据、所选设置入口、实际写入确认情况、操作目录和节点打开错误。未采用入口区分“探测失败”与“优先入口可用，未尝试”；辅助程序启动失败只记为检查未完成，不据此宣布设备或 LSPosed 不兼容。明确重新检测会重建 APP 的 Root 辅助连接，以使用重新授权后的权限。
- 完整 Root 分析包导出失败时，APP 使用系统下载服务保存 `Download/HyperLux/HyperLux-root-analysis-*.zip`。明确标记不完整、最近状态并非实时；不伪造实时日志，保存失败清理未完成条目。
- 不修改内核、SELinux、Root 管理器策略、引擎算法或既有采样率，不新增后台守护 / 定时器。备用设置命令在 APP 查询或操作时可能比原 Provider 慢；不宣称功耗改善。
- 权限确实被拒绝的节点写入、跨进程读取等能力无法由 APP 凭空补齐。此版本提供等价入口、故障隔离和明确诊断；目标 KSU 环境仍需实际反馈验证，不承诺所有临时 Root 均可完整工作。

### 更新提醒与按钮布局（Beta 03）

- 状态页和关于页共用本次访问的自动检查结果；自动更新弹窗只允许在状态页显示，而且实际显示后本次访问不再自动弹出。欢迎、快速设置、权限或旧模块提示阻挡时延后，切到设置、日志或关于页时不抢弹。
- 真正离开APP前台后结束本次访问；未忽略的版本下次进入仍可提醒。旋转等配置重建保留已提醒状态，不当作新一次进入。点击“忽略此版本”仍沿用原持久化记录，稍后不写忽略。
- 关于页只保留更新状态文字和用户主动检查入口；主动点击仍可查看更新详情，包括已忽略的版本。没有新增后台周期检查、服务或亮度控制变化。
- 更新框四个按钮不再固定48dp高度，保留最小点击高度，允许多行、取消省略并增加上下留白；原有布局优先测量两排操作区，日志单独滚动，常规高度按安全可用范围82%限制。
- 已完成123项更新流程主机断言及4666项布局模型断言，覆盖常见小屏、短横屏、中英文和1—2倍字体模型。尚未在实际Android设备复测，不能视为任意极小窗口或所有机型的真机保证。

### 绿色曲线转基础

- 传统物理映射的原生样条和亮度换算，在高亮平台附近可能产生极小浮点误差。例如4000 nit采样成4000.000488 nit，再回到4000 nit，旧校验会把它当作越界或下降。
- 仅在捕获当前普通物理映射曲线时，对4个float ULP以内的边界或平台舍入误差归一；不按型号或系统版本判断，不以固定nit数值放宽上限。
- 保留全部照度坐标与节点数量，不拟合成4点；仍严格拒绝真实越界、异常下降、无效坐标及非数值。Refactor锚点路线和保存文件的严格校验保持原样，系数路线未验证的高级记忆功能仍不放行。
- 原有HDR、当前活动映射、状态时效、配置版本与用户/基准校验继续有效。失败发生在提交前时不应用新配置、不清除当前记忆，也不回写默认设置。
- 此修复仅在用户主动转存时执行，不增加监听、轮询或光感采样。

### 节点写入与恢复（沿用Beta 01）

- 仅对可恢复I/O错误增加有界重试：包括首次最多3次，间隔80、160毫秒；等待时释放手动控制锁，不变成持续循环写入。
- 每次按原始请求重新检查实际节点、上限、系统进程、目标、物理屏及许可。系统更改请求、手动接管、熄屏或保护收回许可时停止，不把系统主动降低亮度当作错误持续顶回去。
- 区分写入被接受但读回稍有延迟，与写入未成功后系统自行改成相同值；后者不能冒认为本模块持有控制权。
- 保留v1比例、v2原始节点及折叠屏v3物理身份路径。节点唯一性、HDR、温控、电量、系统接管和实际HBM允许条件继续有效。恢复原亮度只做一次比较写入，不延迟覆盖新所有者。
- 权限错误或次数耗尽仍停止。普通查询不反复启动守护；仅用户主动保存且配置获引擎确认后，重新经过完整支持、节点和屏幕校验尝试恢复。健康记录保留尝试次数、错误码及原始失败阶段。

## 安装与验证

**4.1.1-beta07 / 41107 / beta-4.1.1-beta07**。保留原包名、原签名及已保存设置。本地Beta，不发布到官网、GitHub或LSPosed。

覆盖安装后需让APP与系统钩子使用同一版本。永久Root通常重启即可；临时Root请按所用方案重新取得本次Root及LSPosed注入，避免直接重启后误以为Root仍存在。权限调整后可主动重新检测。此前已遇到节点写入失败的用户，重启后到设置点击一次**保存并应用**，让新版重新检查旧失败状态；不需要重置配置。绿色曲线转存需当前确有手动记忆，先保存并应用现有草稿，再点击转存按钮。

实际257点分析样本已在主机重现旧错误，修复后捕获、JSON往返及中性基础重建通过，仅3个值需要小于0.0005 nit的精度修正。曲线与提交专项测试、节点重试100项专项、完整回归及原签名打包核验结果以本包审计为准。尚未在目标设备完成实际保存和重启验证，不把主机或固件静态检查视为真机通过，也不宣称功耗改善。
