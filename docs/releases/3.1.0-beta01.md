# HyperLux 3.1.0 Beta 01

2026-10-16 · 版本代码 31001 · 构建 beta-3.1.0-01 · 本地测试版，未推送。

1. 修复应用暂停自动亮度名单只按焦点判断的问题。名单应用仍在主屏可见时，打开或操作其他小窗、切换分屏焦点继续暂停；所有名单应用离开可见区域后恢复。
2. 同时监听焦点与窗口显隐变化，即使焦点留在小窗，底层名单应用隐藏或退出也能释放接管。仅后台存活、隐藏的最近任务、其他用户和副屏不作为匹配。
3. 保留用户主动开启自动亮度的优先权：名单应用仍可见期间不再次关闭。原本处于手动模式的不接管，息屏、停用及手动面板接管的恢复规则保留。
4. 可见任务查询异步执行，不在 WM 钩子或显示线程同步查询服务。事件合并 150 ms，不轮询；单个有界工作线程按需启动，空闲 10 秒退出，不新增 APP 常驻进程或服务。读取超时、失败及迟到结果均有退出保护。
5. 根据本机实际接口启用多窗口判断；缺少完整接口时保留原焦点功能，并在名单设置中明确提示。分析状态补充可见名单应用及查询等待情况。

沿用原签名，可保留配置覆盖 3.1.0 正式版，安装后重启加载新钩子。正式版本号仍属于 3.1.0，不抬到 3.1.1；官网、GitHub 和 LSPosed 仍维持已发布的 3.1.0 / 31000。

已完成主机回归与实际固件接口静态核对，结果见 build-info.json。没有连接的 ADB 设备，本轮不包含小窗、分屏、亮度或功耗真机验证。
