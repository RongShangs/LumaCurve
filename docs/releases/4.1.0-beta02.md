# HyperLux 4.1.0 Beta 02

累计基线：上一个已公开正式版 **4.1.0 / 41000（release-4.1.0-r1）**。包含 Beta 01—02 的更新，分别列出；本地测试包，不替换线上正式版。

## Beta 02 · 41002

1. 针对强光下异常高亮与偏色反馈，完善画面限亮放宽范围：有完整原生高亮档位表的设备，额外增强不再超过该表最高档，避免直接冲到亮度换算表末端。
2. 功能自检的画面限亮详情增加实际使用的范围、配置上限及异常原因，便于区分设备换算范围与本次允许的放宽范围。
3. 保留原有兼容路线、全部已保存设置和原生保护；未开启此选项时不增加控制。保留 Beta 01 的移植曲线适配。

## Beta 01 · 41001

1. 为部分移植系统新增分段系数曲线适配，针对努比亚 Z80 Ultra 用户分析包，修复缺少旧锚点字段导致整条曲线无法接入的问题。
2. 从实际设备曲线读取照度坐标、亮度基准和逻辑上限，保留原生亮度转换、手动学习、高照度缩放及下游保护；旧锚点、传统映射与用户设置继续保留。
3. 兼容页面新增独立曲线路线，区分已接入的基础曲线 / 原生学习与尚未核实的高级记忆能力。此新路线暂不开放跨自动亮度开关、锁屏、重启、永久保持及记忆转基础，原配置保留，其他路线不受影响。

## Beta 02 详细说明

- 本轮样本用户称 K100pm，系统记录 M098FE / songyuan。强光时的系统亮度记录从原生 OPR 限制的约1200 nit，转为模块放宽后的换算端点10000 nit；节点增强关闭，未运行节点守护。
- 该设备的物理换算表最高10000 nit，而原生 OPR 灰阶表的最高档为4500 nit。两者用途不同，不能因为换算能够到达就把该端点当作通用高亮目标。上述数字均为系统配置 / 换算值，不能当作光学实测亮度。
- 新增只读包络适配器：完整实例字段、灰阶递增、nit档位非递增、N+1档位形状和物理换算均有效，才按表内最高档约束本模块额外放宽。没有整组字段时保留原有映射路线；部分缺失、类型错误、坏表、未启用或换算失败时保留原生结果，不盲目降级。
- 只约束本模块新增的放宽量，不降低已存在的更高原生输出，不写色彩、灰阶、设备映射或用户配置。HDR、隐私显示、手动接管、HBM允许条件、温控与电量限制继续有效；本轮不改节点手动 / 强制节点功能。
- 运行报告补充OPR范围 profile、上限与错误，以及屏幕nit来自设备背光映射的证据。未执行放宽前报告未确认，不在打开自检页面时试调亮度。

验证：完成主机回归、实际用户固件静态消费者核对及原签名打包核验。尚未在反馈设备安装新版，**偏色是否消失仍待真机确认**；不宣称达到了实测4500 nit，也不将此次缓解称为已证实的硬件偏色根因修复。Beta 01 新曲线路线的高级记忆边界继续保留。
