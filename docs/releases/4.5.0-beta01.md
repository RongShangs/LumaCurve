# HyperLux 4.5.0 Beta 01

1. 新增可选“自定义放宽后的高亮曲线”，按照度设置激发段的nit上限，可调整达到目标上限的时机。
2. 支持添加、编辑、删除2—16个节点并预览曲线；普通亮度、温控等更低结果及原有户外上限继续保留。
3. 默认关闭，与强制节点高亮确认切换；旧设置和旧画面放宽路径保留，接口暂不支持时保留曲线节点。

本地累计基线为上一个公开正式版4.5.0 /45000。本包4.5.0-beta01 /45001、beta-4.5.0-01只作本地测试，未发布或操作手机。

这是放宽后的高亮上限包络，不是声称从每台设备提取了独立原生HBM曲线。曲线按照度线性插值，只约束高于本机普通上限的部分；不会主动抬高原生或保护给出的更低输出，也不会让超出设备映射的nit值成为可达到亮度。生效范围仍跟随户外会话、画面放宽及系统允许条件。

在户外高亮页添加至少两个照度—nit节点，再开启曲线并保存应用；可关闭该开关对照原有输出。实际效果和长测仍需新包真机回访。

具体核对见[放宽后高亮曲线复审](../reviews/review-opr-curve-20261112.md)。
