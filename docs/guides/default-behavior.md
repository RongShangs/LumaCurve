# 默认行为约定

新安装、没有已保存配置、缺少新字段时，主动改变亮度控制的功能默认关闭或跟随系统。兼容接口可用只表示功能可以使用，不能自动启用增强。覆盖升级、载入草稿和导入配置继续尊重已有显式选择；不能把修改默认值做成重置用户设置。

| 功能 | 新配置默认 | 对原机的含义 |
| --- | --- | --- |
| 基础曲线与额外亮度下限 | 本机原始曲线、倍率全为 1、额外下限为 0 | 不额外抬高或压低亮度 |
| 暗光锁定 | 关闭 | 不定时关闭自动亮度，不订阅锁定用的额外主辅光感监听 |
| 暗光稳定、小变化阈值、辅助闸门 | 均关闭 | 沿用系统确认和变化门槛；阈值子项不暗中预选 |
| 户外增强、HBM 调整、高亮范围、画面放宽、节点增强 | 均关闭 | 系统阳光屏 / HBM 仍由原机决定，不施加自定义目标与上限 |
| 温控放宽与回落调整 | 放宽关闭，回落倍率为 1 | 不开放系统温控限制 |
| 普通 / 微小变化确认、光感门槛、辅助确认、动画、阳光屏门槛、触摸释放 | 覆盖开关均关闭 | 参数只在主动启用后参与计算，不用预填数字替代原机数值 |
| 所有现有场景 | 跟随系统 | 不强行进入、禁用或增加自定义触发条件 |
| 跨自动亮度开关、锁屏、重启、永久保持记忆 | 均关闭 | 模型清除、超时与重建继续按原机规则 |
| 自定义记忆失效和超时条件 | 均关闭 | 不修改原机记忆有效期 |
| 手动记忆强度 | 100%，原生输入直通 | 在原生锚点入口保留原亮度参数；设为 0 会阻止原机记忆，因此不能把“关闭”当作原机默认 |
| 主屏手动亮度入口 | 可用 | 只有用户发起手动接管命令才写亮度；入口可用不等于自动运行 |
| 暂停自动亮度名单 | 空 | 不自动暂停任何应用的自动亮度 |
| 控制中心节点映射 | 关闭，入口仍隐藏 | 不改写亮度条映射 |
| 临时常亮 | 未启用 | 仅用户在手动面板明确开启后临时持有，按原退出条件清理 |

“睡前保持”“暗光少动”“强光优先”等是主动选择的预设，不是安装默认值。默认关闭不能使这些按钮失效；“睡前保持”应明确开启锁定，普通构造器和缺省解析均不能偷偷开启。

`memory_restore_same_scene`、`memory_restore_replace` 等为恢复条件；保持功能默认关闭时这些条件不生效，不能为了消除所有 `true` 而去掉安全校验。自动深色模式、日志自动滚动、自检和教程属于界面或诊断行为，也不等于亮度增强。

原生 / 移植辅助接口修复按实际 OEM 策略、空槽和用户作用域执行，属于既有兼容路径，不因修改增强默认值而删掉。它不表示新增强制亮度功能；具体设备仍按实际接口与运行证据核验。

本轮排查见 [默认行为复审](../reviews/default-behavior-audit-20261019.md)。这些默认约束由配置、模式控制、阈值 Hook 及既有完整回归共同验证，主机验证不等于所有机型真机完全一致。
