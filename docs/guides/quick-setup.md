# 快速设置

当前行为随4.1.0正式版交付，沿用Beta 08的最终方案。设置首页“光感输入与场景”上方的可选入口，每次手动点击均显示邀请，确认开始后才进入。首次进入设置首页且本机曲线已就绪、没有其他弹窗时，邀请一次；选择暂不设置或关闭后不强制重现。记录使用原有独立稳定偏好文件，不依赖桌面图标组件，不复用旧用户须知或欢迎页完成标记。

每页一题，不选择即可直接下一步并保留该分类的当前值；没有显式保留选项，再点已选项可取消。底部始终提供取消，第二页起另有上一步，顶栏无退出。最后以单张清单汇总六项，只显示分类与选择，未选择标为未修改，可返回对应问题。答题不保存配置、不更新曲线、不启动传感器或控制进程。确认时先通过原有只读状态请求刷新当前设备，核对基准与实际能力，再组合草稿并走原有保存应用；取消后到达的刷新回执不会提交。全部未选则只退出，不提交配置或启用引擎。已有未保存设置一并提交会在汇总页说明。

每项以实际已报告能力为准，不新增机型 / OS 判断，不切换任何底层兼容路线。不能选择的项目显示原因；确认时能力消失则不修改当前草稿。没有选择修改的分类及无关配置保留。旋转 / 重建保存答题进度与当前页，恢复前须重新连接并核对亮度基准，基准变化则要求重开；不把旧屏幕的选择直接套到新基准。
