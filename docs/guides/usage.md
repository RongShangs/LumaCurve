# 使用与亮度机制

当前说明适用于 HyperLux 4.3.1 正式版。安装与下载见 [项目首页](../../README.md)。

需求、完整亮度机制、技术路线与实现边界见根目录 [详细项目文档](../../PROJECT.md)。

## 首次欢迎与教程

首次进入 APP 仅显示“下一步”，依次浏览五页教程后再开始使用，分别介绍启用、曲线与记忆、暗光与户外、状态与兼容、BUG 与兼容反馈。欢迎页无顶部名称及灰色说明，欢迎语无标点，HyperLux 用蓝色强调。教程顶部仅标题与页码，底部显示导航和重看位置提示。欢迎页 Logo 轻微浮动，遵循系统动画设置，切到后台或离页即停止。没有倒计时；设置 → 运行状态与界面 → 再次查看使用教程可从欢迎页重看，返回保留原页面位置与未保存的设置。第 5 页说明可在之后通过关于页群号入群反馈，或通过 GitHub Issues 提交问题，不提供外跳按钮；两种方式都应附上分析包与必要的设备 / 问题说明。查看教程不会更改亮度参数，也不会重置旧设置或确认记录。

兼容路线与选择边界见 [路线管理](compatibility-routes.md)，具体可用功能以本机独立自检为准。

## 控制顺序

主辅光感输入 → 系统滤波与场景 → 基础曲线及手动记忆 → 户外目标与范围 → 温控等保护 → 实际输出。显示的节点值、系统换算 nit 和仪器测量亮度不是同一个量。

蓝色表示基础曲线，绿色表示手动记忆实际改变后的曲线。觉得某种环境始终偏亮或偏暗，修改基础曲线；日常短时不合适可用系统亮度条，手动记忆按本机能力学习。绿色曲线可以保存为新的蓝色基础，也能恢复设备原始基础。

## 当前默认行为

| 设置 | 默认与边界 |
| --- | --- |
| 手动记忆强度 | 100%，沿用本机记忆能力 |
| 跨重启保存、亮屏恢复 | 默认关闭；既有显式开启值保留，不因升级擅自改写 |
| 普通暗光稳定、户外增强、温控调整 | 默认关闭，按需求启用 |
| 暗光锁定 | 新配置默认开启：主辅均 ≤10 lux 持续 1 分钟进入；任一侧 ≥50 lux 持续 1 秒退出。旧配置缺开关时保留旧行为 |
| 手动调整后退出锁定 | 默认关闭；调整后按新亮度继续锁定，实际满足退出条件后恢复自动 |
| 户外 nit 上限 | 0 表示不额外限制；需本机可可靠换算 |
| 强制达到节点上限 | 默认关闭，独立节点目标默认本机真实上限；跟随户外增强会话，不另加时限 |
| 应用自动亮度名单 | 默认空；匹配主用户主屏实际可见任务，小窗与分屏切焦点不解除暂停 |
| 现有场景自定义 | 默认跟随系统；只约束现有识别，不创建新的命名场景 |

旧配置与预设可改变实际默认状态，界面以已保存并应用的配置为准。具体范围见当前设置，不照搬他人或其他机型的配置。

## 本地 Beta 04：保持记忆

手动记忆页面将跨自动亮度开关、锁屏和重启保持统一分组，三个范围可独立选择。“永久保持”同时开启三种范围，不因时间或照度变化而过期；新手动调整仍继续学习，主动清除或修改基础曲线仍优先。仅锁屏或跨开关保持使用本次运行缓存，重启保持才写入存档。新选项默认关闭，旧选择按原有效行为迁移。此功能尚未正式发布，见 [Beta 04 日志](../releases/3.1.1-beta04.md)。

## 应用名单与保护

名单内 APP 仍在主屏可见时继续暂停自动亮度；全部不可见后恢复。用户主动开启自动亮度后，其当时可见名单应用仍可见期间不再次关闭。原先就是手动亮度的不接管；手动面板、锁屏、用户及主副屏隔离继续优先。没有完整多窗口接口时设置明确提示焦点回退。

户外和节点增强保留温控、电量、HDR、高亮预算及系统接管退让。节点目标不是 nit，不保证特定面板亮度。强制节点增强需相应户外选项与当前系统输出条件均满足。

## 状态、诊断和恢复

本地 4.0.0 的“功能自检与兼容路线”位于日志页“运行与兼容”，打开为独立页面。每项先显示实际采用路线和检测依据，展开可看本版已实现的其他路线及未采用原因。“接口可用”不表示功能已开启或效果已经实测；未确认与不支持分开说明。展开不会切换路径或试调亮度；检测失败保留旧结果并提示，点击重新自检获取新快照。顶部显示固定检测时刻及启动 / 手动 / 就绪补检来源，普通查看和前台恢复不会重检。简要条目可点击展开完整依据。支持 HyperOS 3 / 4 的实际兼容接口，不同固件的可用功能以本机检测为准。

0 lux 可以是有效暗光；横线表示暂无有效值，不能互相替代。场景标签表示系统实际判定，不用单个光感值猜遮挡。状态页说明对应输入、曲线和输出保护，蓝色文字可跳转。

异常从日志页导出分析包，并记录发生时间；恢复后尽快导出，重启可能丢失 logcat。已导出的 ZIP 会保留。请私下提供设备资料，不直接上传公开仓库。

停用并恢复需等待系统确认，或在 LSPosed 停用并重启。覆盖正式版或 Beta 后需重启一次；普通参数修改保存并应用即可。

## 本地Beta 03：更新提醒

当前源码改为每次进入APP后，仅在状态页自动提醒一次，切换页面不重复；未忽略的版本下次进入仍可提醒。关于页只保留更新文字及手动检查入口。点击“忽略此版本”长期跳过该版本的自动提醒，仍可主动检查查看详情。按钮分两排并允许文字换行增高，日志单独滚动。此调整自4.1.1 Beta 03起纳入本地测试包，尚未正式发布。

## 4.3.0 控制中心节点控制与主题曲线

在设置的主屏手动亮度页面选择控制中心模式。完整节点控制拖动即关闭自动亮度、退出暗光锁定并保持节点，不参与记忆；重新开启自动结束保持。分区下75%普通区间在自动开启时保留原调节与记忆，首次到顶松手后3秒内快速再次上滑进入增强区；可自定增强上限和返回后恢复自动/继续手动。普通上限由实际原机接口和标定换算，设备上限由真实节点读取，75%仅为显示比例。使用需Root节点写入和LSPosed系统界面作用域，更新后重启并打开一次APP。可用范围以设备自检为准。

深色模式独立基础曲线默认关闭，开启后分别保存两套基础，并可选择切换清除、共用或两主题独立记忆，默认仍为清除。独立模式的手动记忆面板随系统主题显示，分别转存基础或清除当前手动记忆。只有开启重启保持才恢复磁盘存档。恢复系统默认撤销亮度定制并清记忆，保留自定义预设、界面偏好和教程记录。
