# 1.0.0 本地交付与发布准备

版本 1.0.0，versionCode 10000，模块 ID luma_curve，维护者酷安@戎Shang，GPL-3.0。

模块管理器简介和关于页简介均按现有实现重写，不在简介中提及原作者。上游基础工程贡献继续保留于关于页底部与来源文档。作者信息后放自愿打赏，随后是博客、酷安主页与协议。

module/core_status.sh 核验 pidof 返回的单一 PID、kill -0 和 /proc/PID/exe 是否等于当前模块 daemon 路径，拒绝其他模块同名进程、无效 PID 和多实例。它仅表示进程存在，不推断传感器健康。描述采用临时文件、校验原元数据未变化、原子替换，避免只为改描述而覆盖并发升级中的版本。只有描述变化才写入；每 10 秒检查，服务数据维护周期仍为 60 秒。控制脚本操作完成后同步状态，关于页进入及可见期间每 10 秒读取，普通浏览器展示预览状态。

版本仅更新当前源文件；旧对照夹具仍由原 SHA-256 固定，测试编译其副本时仅同步版本字面量，业务与状态对照仍保持原范围。

验证包括核心状态 10 项受控进程/文件测试、WebUI 状态桥/排序/外链测试、安装/回滚、兼容性、完整主循环与双光感回放。独立源码包同时使用 Python 构建和 Android NDK CMake 构建；报告见 docs/validation 和本地 dist/delivery-manifest.json。

新增渐进式偏好学习，默认开启、可以独立关闭；直接编辑偏移也可重置为 0。设置提供完整锚点曲线编辑与命名预设，状态页采用相同曲线模型显示原始光感、确认输入和平滑输入。引擎控制位于设置最顶部；新日志附带设备时间，日志页保留向上阅读位置或持续跟随最新行。机制、配置字段和平台识别边界见 [偏好学习与可编辑曲线实施](偏好学习与可编辑曲线实施.md)。

本轮增加 5 个语义负向测试、201 个 C/JavaScript 曲线样本对照、7 个完整主循环偏好/曲线场景；WebUI 验证扩展至 44 项，包含真实 Shell 的配置和预设原子保存。旧基线对照关闭新学习，双侧/时域行为另测；不将这些受控 IO 回放描述为实机或原 ELF 的全行为验证。

本轮验证没有连接 Android 实机；已有用户实机反馈属于此前版本体验，不能代替本次安装和状态标记验收。用户已要求暂缓发布：目前仅本地交付，没有推送代码、创建标签或发布 GitHub Release。将来发布时提供安装包、完整对应源码、SHA256SUMS.txt 和 update.json。
