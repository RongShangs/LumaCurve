# 局部曲线学习与预设

版本 1.0.0 / 10000。长期偏好与曲线合并，不再提供独立的全局偏移调节。

## 学习规则

`preference_learning=1` 默认开启，开关在曲线卡片中；关闭停止学习但保留曲线。编辑锚点、恢复默认或载入预设后，需要保存并应用。

核心只接受主显示器新的 `BrightnessEvent` 明确标记 `(user_set)`、自动亮度及亮屏状态。首次读取建立历史基线，系统自行修改亮度设置或背光不能证明用户操作，厂商缺少事件接口时不会猜测。

依据：[AOSP BrightnessEvent](https://android.googlesource.com/platform/frameworks/base/+/main/services/core/java/com/android/server/display/brightness/BrightnessEvent.java)、[AutomaticBrightnessStrategy](https://android.googlesource.com/platform/frameworks/base/+/main/services/core/java/com/android/server/display/brightness/strategy/AutomaticBrightnessStrategy.java)。

记录调节时参与控制的平滑照度，在 `log(lux+1)` 空间寻找最近锚点。连续拖动合并，停止后等待 8 秒。更新比例为 `clamp(log(新亮度/原亮度) × 0.02, -0.005, +0.005)`，小于 0.0005 的比例忽略。只改一个锚点，每次最多改变该点高度的 **0.5%（相对值）**，不是最大背光的 0.5 个百分点。例如 6.6% 的锚点最多变为 6.633%。

有效更新至少间隔 60 秒。累计修正限制在基础值 ±20%，还受 0.1%–100% 和邻点高度限制，曲线不会逆序。期间照度移到另一个锚点或 `lux+1` 变化超过 1.5 倍，丢弃候选。传感器保持、无有效照度、极端温控、阳光/HBM 增强、可疑零照度或突亮限幅、唤醒观察、其他控制者和非自动模式不学习。实际背光仍受昼夜、电量、温控、阳光、防抖和执行器约束。

## 曲线与持久化

手动编辑的幅度与学习分开：每个点均可在 0.1%–100% 自由调整。抬高时联动右侧较低点，降低时联动左侧较高点；界面显示联动数量，避免倒挂而不限制在原先狭小的邻点范围内。自动学习仍仅更新一个点且速度很慢。

14 个固定照度点：0、1、5、10、50、100、500、1000、2000、5000、9000、10000、35000、100000 lux。百分比有限、不下降，在点间使用对数照度插值及 `2.2/gamma` 指数。

`curve_custom`、`curve_points` 存基础曲线，`preference_revision` 标识明确重设。独立记录 `/data/local/tmp/luma_curve_preference` 使用格式 2：基础点、学习后点、样本数、配置引用。百分比保留六位小数，0600 临时文件，检查写入与关闭后原子替换，失败保留旧记录并重试；无关设置不会清空学习。

旧格式 1 的全局偏好作为兼容值保留，新手势只训练局部点。界面将旧值折入显示曲线，明确编辑或保存预设时转成完整锚点；应用时兼容偏移归零。恢复默认同样归零。损坏、截断、重复、非有限值、配置引用不符的记录不能作为学习曲线使用。

灰色是设定基础，蓝色是学习后，金色虚线是满足阳光条件后的增强。状态图使用快照中的实际曲线与昼夜系数；温控、电量、确认与过渡可能使实际目标暂不在基础线上。比例是硬件背光刻度，不等同感知亮度或 nit。

最多 16 个命名预设，保存当前完整曲线、学习开关、形状和阳光参数，不保存硬件路径。载入只改表单，仍需应用。预设在 `/data/local/tmp/luma_curve_presets.json`，原子保存并检查并发修改。配置、学习和预设纳入升级备份。

## 状态诊断与验证

温控卡片区分：已关闭、等待扫描、未找到温度源、节点不可读、辅助温度、可信温度。电池/机身等保留原可信白名单；屏幕类仅是辅助，电流/电压告警节点继续排除。“变化确认”是目标防抖，等待稳定或允许调节，不代表已到达目标亮度。核心温控源选择与保护逻辑本轮保持，未把缺温度当作低温。

验证覆盖单点学习、速度、间隔、单调边界、关闭保留、重启、无关重载、旧记录升级、五种 IO 失败和场景/保护拒绝；5 个语义破坏必须失败；201 个生产 C/JS 曲线样本一致。完整主流程包括 37 个旧基线、38 个时域、12 个双光感和 7 个曲线/学习场景。界面检查覆盖温度分类、合并学习、预设、保存、外链、键盘与日志。报告见 `docs/validation`。

本地测试不代替实机验证，尤其厂商用户事件格式与温度节点。官网由维护者自行部署，源码推送不等于自动部署或 GitHub Release。

官网资源数据由作者提供：内存约 30 MB，平均 CPU 0.02%。没有提供采样时长与设备型号，因此明确标注为作者设备实测，不作为所有设备保证。
