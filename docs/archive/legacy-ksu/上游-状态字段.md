# 命名状态字段与单位

所有字段使用原版初始值（state.c），状态随 daemon 进程创建，重置由 ios_reset_data 完成。配置加载修改 cfg_*，传感器/调度字段在轮次中维护，learn 单元经显式文本协议持久化。信号请求四个字段是 volatile int32，回调只赋值。参考布局断言用于测试比对，生产没有 RAM 镜像执行器。

固定字符串区和时间/数组的特殊含义以恢复算法及协议文档为准；下表明确单位已确定的字段，不为未知枚举杜撰语义。
