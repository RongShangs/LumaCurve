# 浮点与融合乘加

原 main 的 ARM64 FMADD 对应恢复源码中显式 `fmaf`。构建使用 `-ffp-contract=off`，防止编译器把其他乘加擅自融合；主机测试启用 FMA。普通 `a*b+c` 的两次舍入可能不同于原 FMADD，不能只比较最终整数亮度。

| 原地址 | 恢复语义 |
|---|---|
| 8110 / 833c / 924c | 曲线比例 × 最大亮度 + 0.5 |
| 8c58 / c078 | 低照度上界 × 1.2 + 2、× 3 + 6 |
| 903c | 平滑 EMA |
| 9438 / 9514 / 955c | 学习加权累计、全局偏移、修正亮度取整 |
| 9784 / 9e68 / a010 | 热保护底限与退出恢复 |
| a4f8 / a4fc / a538 / a53c / a660 | 唤醒变化限幅、稳定亮度边界、低照度上升上限 |
| a758 / a7ac / bb9c / c1f0 | 防抖阈值与步长 |
| a8b4 | 相对亮度迟滞插值 |
| b028 / b260 | 调整值到 slider 的换算、调度步长 |
| ba54 / bd9c / bdfc | 阳光 boost 与最低比例 |
| bf1c / bf48 / bf58 | 已有学习单元的 slider、lux、confidence 更新 |

总计 30 处指令；同一 threshold 函数覆盖多个原位置。slider 的最终 +0.5 在原指令中是单独相加，不能并入前一个 fmaf。学习累计 pending_5/pending_6 是浮点值；将其当整数会出现轨迹相同但状态字节不一致。连续两次提交场景用于覆盖已有单元更新。
