# LumaCurve 1.0.0 正式版

适配 HyperOS 4 的亮度引擎。包含自学习可编辑的亮度曲线，场景感知，平滑调节与手动偏好保持。

## 核心功能

- 14 点曲线，长期使用缓慢学习附近锚点，支持关闭学习、自由编辑和预设。
- 正面光感优先、背面参考，区分双侧变化、单侧变化与短暂遮挡。
- 系统框架输出与时间过渡，手动选择保持到明显场景变化或锁屏；硬保护优先。
- HyperOS 4 接口与坐标检查、输出反馈守卫、整组升级释放和配置应用确认。
- 日志页运行兼容概览；导出本次开机日志与设备状态，或完整只读分析包，保存至手机 `/sdcard/`，显示阶段进度。
- 官网、详细 README、对应源码及感谢名单同步更新。

## 安装与范围

ARM64、Root、HyperOS 4、KernelSU 兼容模块管理环境。不同固件仍需实机确认，系统更新可能影响隐藏显示接口；当前版本不直接写 HBM 节点，不承诺所有设备全范围输出。模块永久免费，GPL-3.0 开源。

已经使用同为 1.0.0 / 10000 的测试包，请手动安装此正式包并重启；相同版本代码不会自动提示更新。后续更高版本代码会在进入 WebUI 时提示。

## 验证

完成当前生产后端的 C/Java 回归、语义负向测试、安装与升级回滚、采集导出、WebUI 和静态官网浏览器检查；正式安装包、源码包及官网校验值统一。独立源码可构建，不依赖原程序 ELF。主机测试不替代新固件的设备验收。
