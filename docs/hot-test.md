# 不重启手机测试核心

安装过模块的设备可以在 root 终端运行仓库的 `tools/hot_test_android.sh`。
把脚本和本地测试 ZIP 放进设备 Download 目录，然后执行：

```sh
su
sh /sdcard/Download/hot_test_android.sh /sdcard/Download/luma_curve-1.0.0.zip
```

脚本先核对模块 ID，并运行新核心的只读能力检查。通过后暂停引擎，
备份当前核心，原子替换运行目录的核心，再启动引擎。启动失败时尝试回滚。
原本由用户暂停的引擎保持暂停，需要时在设置页恢复。
配置、学习数据和 WebUI 不替换，本脚本适合这轮核心测试。
WebUI 的普通“重启引擎”本身不会把安装器的待应用文件复制进运行目录。
管理器中另外存在的待应用版本可能在下次整机重启覆盖这个测试核心。

当前测试构建标识为 `20260929-test02`，可从启动日志、详细读数 `core_build`
或运行 `luma_curve_daemon --build-info` 核对。
详细读数额外提供执行器写入尝试/成功次数、失败阶段、errno、请求值、字节数和节点路径。
这些字段用于分辨未调用执行器、写入失败和写后读回冲突，不能把“引擎运行中”当成写入成功。
